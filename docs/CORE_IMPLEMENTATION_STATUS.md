# 플레이 데모 구현 현황

## 1. 문서 목적

이 문서는 `하강 승인: 제0균열`에서 현재 실제로 플레이 가능한 범위와 아직 구현하지 않은 범위를 구분한다. 기획 규칙의 원본은 `PRD.md`와 각 상세 문서이며, 이 문서는 구현 상태를 추적하는 기준으로 사용한다.

현재 버전은 임시 2D 시각 요소를 사용해 10층부터 8층까지의 전체 진행, Pencil·손가락 입력, 턴제 전투와 7층 도달 엔딩을 직접 플레이할 수 있다. Blender와 RealityKit 결과물은 이후 임시 무대를 교체하는 방식으로 연결한다.

## 2. 현재 구현 범위

### 2.1 도메인과 콘텐츠

- 정규화 좌표, 획, 말소 구역과 입력 방식 모델
- 주문 카테고리, 주문서 등급, 주문 효과와 문양 정의
- 플레이어, 적, 방어막, 턴 자원과 전투 이벤트 모델
- 층, 장면, 체크포인트, 튜토리얼, 숙련도와 저장 진행 모델
- 주문 5종 데이터
  - 잔광 말소
  - 균열 절단
  - 방벽 관통
  - 초급 방벽
  - 봉인 해제
- 적 3종 데이터
  - 9층 기록 관리자
  - 8층 관측 잔류체
  - 8층 관측 관리자
- 9층과 8층의 두루마리 후보 데이터

### 2.2 마법진 판정

`GlyphEvaluator`는 UI가 전달한 획의 점 배열을 아래 기준으로 판정한다.

- 주문별 1획 또는 2획 제한
- 시작점과 종료점 허용 반경
- 필수 노드의 순서 통과
- 선택 노드 누락 시 등급 상한 적용
- 기준 경로와 실제 경로의 거리 오차
- 2획 주문의 교차점 확인
- 실제로 그린 경로 길이에 비례한 마나 소모
- 말소 구역 안에서 그린 경로의 마나 가중치
- 거절, 미완, 승인, 정밀, 완벽의 시전 등급

문양은 단순한 도형 분류가 아니라 주문마다 서로 다른 서명형 기준 경로를 가진다. 강한 주문일수록 획 수, 경로 길이, 필수 노드와 교차 조건이 복잡하다.

### 2.3 턴제 전투

- 플레이어 턴 시작 시 마나 100과 최대 2획 회복
- 실제 시전 경로에 따른 마나와 획 소비
- 남은 자원 안에서 공격과 방어 주문을 한 턴에 연속 시전
- 시전 등급에 비례한 공격 피해
- 고정 수치 방어막과 최대 중첩 제한
- 일반 방어막의 피해 흡수
- 방벽 관통의 일반 방어막 무시
- 절대 방어막의 공격 및 효과 무효화
- 봉인 해제의 절대 방어막 1회 제거
- 적 행동 예고, 적 행동 해결, 승리와 패배 처리
- 적이 쓰러진 경우 예정된 적 행동 취소

### 2.4 적 패턴

| 적 | 구현 패턴 |
| --- | --- |
| 기록 관리자 | 일반 공격과 일반 방어막을 번갈아 사용 |
| 관측 잔류체 | 일반 공격, 강공격 예고, 강공격 반복 |
| 관측 관리자 | 절대 방어막, 일반 공격, 강공격 예고, 강공격 반복 |

기록 관리자는 HP가 절반 이하가 되면 말소 구역을 한 번 생성한다. 관측 관리자는 전투 시작 시 절대 방어막을 가지며, HP가 절반 이하가 되면 절대 방어막을 한 번 다시 생성한다.

### 2.5 층 진행과 보상

다음 순서를 건너뛸 수 없는 상태 전이로 구현했다.

1. 10층 회의실과 사무실 조사
2. 잔광 말소 습득 및 훈련
3. 균열 절단 습득 및 훈련
4. 10층 하강문 승인 후 9층 진입
5. 기록 관리자 전투
6. 두루마리 3개 중 하나 선택
7. 어떤 9층 후보를 골라도 방벽 관통 습득
8. 8층 진입 시 HP 30 회복
9. 보호실에서 초급 방벽 습득
10. 관측 잔류체 전투 후 봉인 해제 습득
11. HP 20 회복 및 최소 HP 60 보정
12. 봉인 해제로 관측실 문 개방
13. 관측 관리자 전투
14. 8층 두루마리 보상 연출용 후보 선택
15. 7층 하강문 승인 후 데모 종료

같은 적을 두 번 처치하거나 같은 층의 보상을 두 번 선택할 수 없다. 잘못된 장면에서 주문 습득, 전투 완료 또는 문 승인을 요청하면 오류를 반환한다.

### 2.6 저장과 복원

- JSON 기반 `GameProgress` 저장
- 메모리 저장소와 파일 저장소 제공
- 원자적 파일 쓰기
- 저장 파일 삭제와 새 게임 복원
- 미래 버전의 저장 파일 차단
- 층, 장면, 체크포인트, HP와 습득 기록의 교차 무결성 검사
- 앱 비활성화 및 백그라운드 전환 시 진행 상태 재저장
- 장면, 체크포인트, HP, 습득 주문, 처치한 적, 읽은 기록, 튜토리얼, 주문 숙련도와 선택 보상 저장

전투 도중의 획과 현재 적 턴은 저장하지 않는다. 앱을 다시 열면 마지막 체크포인트의 전투 시작 상태로 복구하는 구조다.

### 2.7 통합 세션

`DemoGameSession`은 화면 계층이 사용할 단일 진입점이다.

- 탐색과 진행 명령 처리
- 현재 장면에 맞는 적 전투 생성
- Apple Pencil 또는 손가락에서 수집된 획 데이터 제출
- 판정 결과를 전투 효과로 연결
- 성공한 주문의 숙련도 기록
- 승리 시 해당 층의 진행 상태 자동 갱신
- 패배 시 현재 체크포인트 전투를 HP 100으로 재시작
- 진행 상태 저장 및 복원

UI는 `DemoCommand`를 전달하고 `DemoSessionEvent`를 받아 화면과 연출을 갱신하면 된다.

### 2.8 Pencil 및 손가락 입력

- 자동, Apple Pencil 전용, 손가락 전용 입력 모드
- 입력 설정의 `UserDefaults` 저장 및 복원
- 손상되거나 미래 버전인 설정의 자동 복구
- Pencil과 손가락 모두 완벽 등급 허용
- 손가락 입력의 노드, 경로와 교차 반경 소폭 보정
- 캔버스 좌표를 `0...100` 백분율 좌표로 정규화
- 비정상 좌표, 시간 역행 샘플과 과도한 중복점 제거
- 손가락 입력의 제한적인 3점 스무딩
- 최대 2획, 획 취소, 되돌리기와 전체 지우기
- coalesced touch 기반 UIKit 입력 수집
- 자동 모드의 Pencil 우선권 및 팜 터치 차단
- SwiftUI 캔버스 브리지
- 홈 화면에서 열 수 있는 입력 설정 화면
- 선택한 입력 방식으로 직접 그려보는 입력 확인 영역

### 2.9 런타임 서비스와 플레이 편의

- Game Center 로컬 플레이어 인증과 시스템 인증 화면 연결
- 임시 업적 8개와 누적 업적 진행률 계산
- 플레이어별 성공 보고 기록과 오프라인 업적 원장
- Game Center 업적 대시보드 진입
- 주문, 피격, 방벽, 승패, 보상과 하강 이벤트 햅틱
- 실제 음원 파일을 교체할 수 있는 효과음 및 반복 배경음 계층
- 효과음, 배경음, 햅틱, 번쩍임 감소와 동작 감소 설정
- 버전 1 입력 설정을 버전 2 피드백 설정으로 마이그레이션
- 일시정지, 설정, 타이틀 복귀 확인과 현재 체크포인트 표시
- 전투 중 체크포인트 HP 재시작과 패배 후 HP 100 재도전 분리
- iPad 가로 방향 고정
- 동일한 전투 이벤트가 연속 발생해도 누락하지 않는 이벤트 배치 번호
