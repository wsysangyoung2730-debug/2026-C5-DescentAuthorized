# 오디오 에셋 연결 명세

## 현재 상태

게임 이벤트, 햅틱, 음향 설정과 오디오 재생 계층은 구현되어 있다. 실제 음원 파일은 아직 포함하지 않으며, 파일이 없어도 게임은 오류 없이 진행된다.

음원을 추가할 때 Xcode 앱 타깃의 `Resources/Audio` 그룹에 아래 이름의 `.m4a` 파일을 넣으면 별도 코드 수정 없이 연결된다.

## 효과음 파일

| 파일명 | 사용 시점 |
| --- | --- |
| `cast-success.m4a` | 승인·정밀 등급 주문 시전 |
| `cast-perfect.m4a` | 완벽 등급 주문 시전 |
| `cast-rejected.m4a` | 주문 판정 거부 |
| `enemy-hit.m4a` | 적 HP 피해 |
| `player-hit.m4a` | 일반 피격 |
| `player-hit-strong.m4a` | 강공격 피격 |
| `barrier-applied.m4a` | 일반 방벽 생성 |
| `absolute-negated.m4a` | 절대 방벽이 공격 무효화 |
| `barrier-dispelled.m4a` | 봉인 해제로 절대 방벽 해제 |
| `battle-victory.m4a` | 전투 승리 |
| `battle-defeat.m4a` | 전투 패배 |
| `scroll-selected.m4a` | 주문서 선택 |
| `descent-approved.m4a` | 하강문 승인과 층 이동 |

## 배경음 파일

| 파일명 | 사용 시점 |
| --- | --- |
| `tower-ambience.m4a` | 앱 실행 중 반복되는 기본 탑 환경음 |

배경음은 반복 재생되며 기본 볼륨은 45%다. 앱의 오디오 세션은 다른 앱의 소리를 강제로 끊지 않는 `ambient` 범주를 사용한다.

## 설정 연동

- 효과음: 모든 사건 기반 효과음을 켜거나 끈다.
- 배경음: 반복 환경음을 재생하거나 정지한다.
- 햅틱: 시전, 피격, 방벽, 승패 반응을 켜거나 끈다.
- 번쩍임 줄이기: 피격 시 붉은 화면 효과의 강도를 낮추고 강공격 테두리를 숨긴다.
- 동작 줄이기: 전투 결과와 피격 피드백의 SwiftUI 애니메이션을 즉시 전환으로 바꾼다.
