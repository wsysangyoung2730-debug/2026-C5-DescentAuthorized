# 층별 진행 및 튜토리얼 명세

> 문서 상태: MVP 기준선 보관본 · 내용 수정 금지
> 기준 구현: `develop @ dd2f8e2` (`#74` 포함)
> 보관일: 2026-09-01
> 최신 문서: [`../../LEVEL_FLOW.md`](../../LEVEL_FLOW.md)

## 1. 문서 목적

이 문서는 데모의 10층, 9층, 8층에서 플레이어가 어떤 장면을 어떤 순서로 경험하는지 정의한다. 공간 이동, 조사, 주문 습득, 전투, 보상, 하강문과 튜토리얼 노출 시점을 하나의 흐름으로 관리한다.

## 2. 진행 설계 원칙

- 자유로운 3D 이동보다 고정된 2.5D 장면 사이를 선택해 이동한다.
- 각 장면에는 한 가지 주요 목적만 둔다.
- 설명창보다 환경, 시스템 메시지와 실제 행동으로 규칙을 가르친다.
- 플레이어가 직접 한 번 실패하거나 효과를 체감한 뒤 필요한 대응법을 보여준다.
- 이미 학습한 기능은 반복해서 강제 설명하지 않는다.
- 필수 진행 물체와 선택 조사 물체를 시각적으로 구분하되 과도한 마커는 사용하지 않는다.
- 층 하나는 `탐색 → 규칙 학습 → 검증 → 하강`의 작은 완결성을 가진다.

## 3. 장면 이동 방식

### 3.1 기본 조작

- 화면 좌우 또는 공간 안의 문을 눌러 인접 장면으로 이동한다.
- 조사 가능한 물체를 누르면 카메라가 가까이 이동하고 조사 UI를 연다.
- 중요한 물체는 주변광, 미세한 입자 또는 관리국 표시등으로 유도한다.
- 플레이어 캐릭터를 직접 조종하는 가상 스틱은 사용하지 않는다.

### 3.2 장면 상태

| 상태 | 의미 |
| --- | --- |
| 미방문 | 아직 진입하지 않은 장면 |
| 방문 | 장면을 확인했지만 필수 행동이 남음 |
| 완료 | 필수 행동을 마쳐 다음 진행이 가능 |
| 잠금 | 주문, 전투 또는 문양 조건이 필요 |

### 3.3 필수와 선택 조사

- 필수 조사: 진행, 주문 습득 또는 전투 진입에 필요
- 선택 조사: 세계관, 주인공 과거와 창밖 이스터에그 제공
- 선택 조사를 놓쳐도 전투 난이도와 엔딩은 달라지지 않음
- 읽은 기록은 이후 기록 보관함에서 다시 확인 가능

## 4. 데모 전체 흐름

```text
10층 폐쇄된 사무실
  기상 → 잔광 말소 학습 → 균열 절단 학습 → 하강문

9층 기록실
  진입 → 기록 관리자 전투 → 주문서 선택 → 하강문

8층 균열 관측실
  전초 구역 → 초급 방벽 학습 → 관측 잔류체
  → 봉인 해제 습득 → 본실 개방 → 관측 관리자
  → 보상 → 7층 문 → 데모 종료
```

## 5. 튜토리얼 공통 규칙

### 5.1 안내 우선순위

1. 공간 안에서 무엇을 눌러야 하는지 보여준다.
2. 행동의 목적을 한 문장으로 알려준다.
3. 플레이어가 직접 행동하게 한다.
4. 성공 또는 실패 결과를 즉시 보여준다.
5. 필요한 경우에만 원인을 한 문장으로 설명한다.

### 5.2 안내 표현

- 관리국 시스템 메시지
- 입력판 위의 시작점과 가이드
- 주문 카드 또는 HUD의 짧은 강조
- 적 행동 예고의 아이콘과 애니메이션
- 환경 안의 문서, 표적과 장비

긴 튜토리얼 팝업과 캐릭터가 시스템을 대신 설명하는 방식은 피한다.

### 5.3 안내 단계

| 단계 | 표시 |
| --- | --- |
| 최초 노출 | 짧은 문구 + 관련 UI 강조 |
| 첫 실패 | 실패 원인 표시 |
| 두 번째 실패 | 핵심점 또는 필요한 카드 강조 |
| 세 번째 실패 | 가이드 경로와 진행 방향 강화 |
| 반복 실패 | 건너뛰기가 아니라 완화된 연습 조건 제공 |

### 5.4 튜토리얼 저장

- 기능별로 최초 안내 확인 여부를 저장한다.
- 전투를 재시작해도 이미 본 기본 설명은 반복하지 않는다.
- 설정에서 튜토리얼 안내를 초기화할 수 있다.
- 필수 시스템 경고는 튜토리얼 여부와 관계없이 표시한다.

## 6. 10층: 폐쇄된 사무실

### 6.1 층 역할

- 세계와 주인공의 첫인상 제공
- 조사와 장면 이동 학습
- 주문 카드 선택과 1획 드로잉 학습
- 정확도에 따른 공격 차이 체감
- 공격 주문 2종 습득
- 문 개방 문양과 하강 절차 학습
- 9층의 전투 위협 암시

### 6.2 공간 구성

```text
[10-A 회의실]
      ↓
[10-B 폐쇄 사무 구역] ↔ [10-C 문양 자료실]
      ↓
[10-D 훈련 벽면]
      ↓
[10-E 9층 하강문]
```

### 6.3 10-A 회의실: 기상

#### 진입 상태

- 새 게임 시작
- 주인공은 바닥에 쓰러져 있음
- HUD와 주문 카드는 숨김

#### 필수 흐름

1. 검은 화면에서 형광등 소리와 함께 장면이 나타난다.
2. 주인공의 손에 있는 문양이 짧게 빛난다.
3. 플레이어가 화면을 눌러 몸을 일으킨다.
4. 카메라가 회의실과 닫힌 문을 보여준다.
5. `신원 조회 실패`와 `하강 절차 중단` 메시지가 잠깐 나타난다.
6. 문 옆의 관리국 패널을 조사하면 사무 구역으로 이동할 수 있다.

#### 선택 조사

- 이름이 지워진 출입증
- 끝부분이 말소된 회의록
- 창밖에서 같은 불이 반복해서 켜지는 건물

#### 완료 조건

- 관리국 패널 조사
- 사무 구역 이동 해금

### 6.4 10-B 폐쇄 사무 구역: 입력 발견

#### 필수 흐름

1. 바닥의 미완성 마법진이 손의 문양에 반응한다.
2. 벽면 봉인 표적 하나가 약하게 점등된다.
3. 바닥 자료를 조사하면 첫 주문 카드가 나타난다.
4. `잔광 말소`의 이름과 공격 카테고리가 공개된다.
5. 훈련 벽면 장면이 해금된다.

#### 튜토리얼

- 주문 카드의 위치를 한 번 강조한다.
- `문양 자료를 해독했습니다`만 표시하고 세계관 설명은 길게 하지 않는다.

#### 선택 조사

- 전원이 꺼진 직원 단말기
- 10층 도면에서 지워진 계단
- 창문에 비친 주인공 뒤의 두 번째 실루엣

### 6.5 10-D 훈련 벽면: 잔광 말소

#### 첫 시전

1. 잔광 말소 카드만 활성화한다.
2. 카드를 누르면 입력판이 바닥에서 올라온다.
3. 시작점, 핵심점과 가이드가 표시된다.
4. 마나 게이지와 획 아이콘을 처음 공개한다.
5. 플레이어가 1획 문양을 그린다.
6. 판정 등급을 표시한다.
7. 불완전 승인 이상이면 봉인 표적에 공격이 발동한다.

#### 실패 처리

- 시전 반려: 표적은 유지되고 마나와 획을 즉시 초기화한다.
- 첫 실패: 놓친 핵심점 표시
- 두 번째 실패: 움직이는 가이드 표시
- 시간 제한과 HP 손실 없음

#### 성공 후

- 표적 외피가 깨지지만 핵은 남는다.
- 정확도에 따라 균열 크기와 타격음이 달라진다.
- `시전 기록 확인` 메시지 뒤 자료실이 활성화된다.

### 6.6 10-C 문양 자료실: 균열 절단

#### 필수 흐름

1. 손상된 문양 자료 여러 장을 보여준다.
2. 그중 온전한 한 장만 푸른빛으로 반응한다.
3. 주인공이 아래층에 대비해야 한다는 짧은 독백을 한다.
4. 자료를 해독해 `균열 절단`을 등록한다.
5. 카드 두 장을 비교해 볼 수 있다.
6. 훈련 벽면으로 돌아간다.

#### 학습 목표

- 같은 1획이라도 주문 길이와 난이도가 다름
- 강한 주문이 마나를 더 많이 사용함
- 주문 카드를 바꾸면 가이드가 즉시 바뀜

### 6.7 10-D 훈련 벽면: 두 번째 시험

1. 잔광 말소와 균열 절단 카드를 모두 활성화한다.
2. 남은 표적 핵에 균열 절단을 사용하도록 요청한다.
3. 마나가 더 많이 줄어드는 것을 보여준다.
4. 성공하면 표적이 완전히 파괴된다.
5. 9층 하강문의 전력이 복구된다.

균열 절단에 반복 실패하면 잔광 말소로 표적을 파괴할 수 없다. 두 번째 주문을 최소 한 번 성공해야 하강문이 열린다.

### 6.8 10-E 하강문

#### 흐름

1. 하강문 위 관리국 상징이 점등된다.
2. `하강 문양을 제출하십시오`를 표시한다.
3. 전투와 분리된 문 개방 입력판을 연다.
4. 쉬운 1획 문양을 그린다.
5. 성공하면 `문양 검수 완료`와 `9층 접근 임시 승인`을 표시한다.
6. 문이 열리기 직전 아래에서 금속을 긁는 소리가 들린다.
7. `9층 관리자 응답 없음`을 표시한다.
8. 플레이어 확인 후 9층으로 하강한다.

#### 문양 실패

- `문양 불일치. 재제출 필요` 표시
- 마나와 시도 횟수 제한 없음
- 두 번 실패하면 경로를 더 밝게 표시

#### 체크포인트

- 공격 주문 2종 습득
- 10층 필수 튜토리얼 완료
- 9층 진입 가능

## 7. 9층: 기록실

### 7.1 층 역할

- 첫 실제 턴제 전투
- 플레이어와 적 HP 학습
- 적 행동 예고 학습
- 한 턴 최대 2획과 연속 시전 학습
- 일반 방어막과 말소 구역 학습
- 보스 보상 선택 학습

### 7.2 공간 구성

```text
[9-A 기록실 입구]
      ↓
[9-B 중앙 기록실 / 보스전]
      ↓
[9-C 보존 금고 / 주문서 보상]
      ↓
[9-D 8층 하강문]
```

### 7.3 9-A 기록실 입구

#### 필수 흐름

1. 문이 뒤에서 닫히고 층 표기가 `9F`로 고정된다.
2. 바닥 문서의 글자가 실시간으로 사라진다.
3. 중앙 기록실에서 도장 소리와 종이 넘기는 소리가 들린다.
4. 전투 진입 전 플레이어 HP를 100으로 초기화한다.
5. 두 공격 주문 카드와 현재 마나·획을 확인할 수 있다.

#### 선택 조사

- 실종자 이름이 비어 있는 명단
- 주인공 필체와 닮은 승인 서류
- 모든 층이 9층으로 표시된 창밖 건물

### 7.4 9-B 중앙 기록실: 기록 관리자

#### 등장

1. 서류와 잉크가 중앙으로 모인다.
2. 기록 관리자가 형체를 만들고 붉은 승인 핵을 드러낸다.
3. 적 이름과 HP를 공개한다.
4. 첫 행동 `기록 찌르기`를 예고한다.
5. 전투 HUD를 완전히 활성화한다.

#### 첫 턴 안내

- 적 행동 예고 영역을 한 번 강조한다.
- 플레이어가 주문 한 개를 시전하면 남은 획 1개를 강조한다.
- 두 번째 주문을 사용할 수 있다는 짧은 문구를 표시한다.
- 플레이어가 바로 턴 종료를 선택해도 막지 않는다.

#### 일반 공격 학습

- 기록 찌르기가 실행되면 플레이어 HP 감소를 크게 보여준다.
- 피해 후 HP 영역을 한 번 강조한다.
- 별도의 긴 설명은 표시하지 않는다.

#### 일반 방어막 학습

1. 다음 행동으로 `문서 방벽`을 예고한다.
2. 행동 실행 후 적 HP 위에 청백색 방어막을 표시한다.
3. 플레이어의 다음 일반 공격은 방어막에 먼저 적용된다.
4. `피해 일부가 방벽에 보존됨` 메시지를 한 번 표시한다.

#### 말소 구역 학습

1. 기록 관리자 HP가 50% 이하가 되면 입력판 한쪽에 검은 말소 도장이 찍힌다.
2. `경로 일부 말소` 메시지를 표시한다.
3. 구역을 피해 그릴 수 있도록 선택한 주문 가이드 전체를 확인시킨다.
4. 구역을 지나면 마나 소모 증가와 선 소실을 직접 보여준다.
5. 첫 통과 때만 `획 일부 말소됨`을 표시한다.

#### 승리 조건

- 기록 관리자 HP 0
- 예고 행동 취소
- 붉은 승인 핵 파괴
- 보존 금고 문 개방

#### 패배와 재시작

- 중앙 기록실 입장 직전부터 재시작
- HP 100, 적 상태 초기화
- 본 튜토리얼 설명은 반복하지 않고 핵심 UI 강조만 유지

### 7.5 9-C 보존 금고: 주문서 선택

1. 기록 관리자의 잔해에서 두루마리 3개가 떠오른다.
2. 선택 전에는 이름 일부, 공격 카테고리와 등급만 표시한다.
3. 낡은 주문서 두 개는 동일한 푸른빛 계열로 보여준다.
4. 봉인 주문서 또는 금서는 실제 획득 불가능한 후보 외형으로 등장할 수 있다.
5. 하나를 선택하면 확인 없이 바로 펼쳐지지 않고 1초간 선택 상태를 보여준다.
6. 선택을 확정하면 나머지 두 개는 말소되듯 사라진다.
7. 데모에서는 어떤 후보를 골라도 `방벽 관통`을 등록한다.
8. 2획 문양이라는 정보와 전체 가이드를 처음 공개한다.

보상 선택은 되돌릴 수 없다. 다만 데모 저장을 삭제하거나 새 게임을 시작하면 다시 체험할 수 있다.

### 7.6 9-D 하강문

- 기록 검수 서명처럼 보이는 1~2획 문양 사용
- `기록 검수 완료`
- `8층 관측실 접근 권한 임시 승인`
- 문 개방 후 플레이어 HP 30 회복
- 8층 진입 체크포인트 저장

## 8. 8층: 균열 관측실

### 8.1 층 역할

- 방어 주문 학습
- 잔류체 전투를 통한 강공격 예고 학습
- 해제 주문 습득과 비전투 사용
- 절대 방어막 체감
- 공격, 방어, 해제를 모두 사용하는 종합 보스전
- 아래층이 더 남았다는 데모 결말

### 8.2 공간 구성

```text
[8-A 관측실 전초]
      ↓
[8-B 보호 절차실]
      ↓
[8-C 관측 잔류체 전투]
      ↓
[8-D 본실 봉인문]
      ↓
[8-E 균열 관측 본실 / 보스전]
      ↓
[8-F 7층 하강문 / 데모 종료]
```

### 8.3 8-A 관측실 전초

1. 깨진 모니터에 기억침식 수치가 반복된다.
2. 본실 봉인문이 금색 잠금 상태임을 보여준다.
3. 보호 절차실에서 비상등이 켜진다.
4. 플레이어가 보호 절차실로 이동한다.

선택 조사:

- 제0균열 관측 보고서 일부
- 다른 탑 내부처럼 보이는 관측창
- 주인공 권한으로 작성된 장비 설계도

### 8.4 8-B 보호 절차실: 초급 방벽

1. 보호 절차용 문양 자료를 조사한다.
2. `초급 방벽` 카드와 청백색 가이드를 공개한다.
3. 안전한 연습 입력판에서 한 번 그린다.
4. 성공하면 플레이어 HUD에 방어막 20이 생성된다.
5. 방어막이 HP와 별도 자원임을 시각적으로 보여준다.
6. 관측 장비가 파손되며 잔류체 전투 장면으로 연결된다.

연습에서 실패해도 HP와 획 제한은 없으며 성공할 때까지 재시도한다.

### 8.5 8-C 관측 잔류체

#### 등장

- 깨진 렌즈와 마나가 뭉쳐 작은 관측 잔류체가 생성된다.
- 보호 절차실에서 만든 방어막은 전투 시작 상태로 유지한다.

#### 패턴 학습

1. 유리 파편으로 약한 공격을 경험한다.
2. 다음 행동 `초점 고정`이 표시된다.
3. 초점 고정 실행 후 붉은 집중 효과와 `강공격 준비`를 표시한다.
4. 다음 턴에 초급 방벽 카드를 한 번 강조한다.
5. 플레이어가 방어하거나 공격에 집중할 수 있게 선택권은 유지한다.
6. 집속 파편이 실행되면 방어막과 HP의 피해 분배를 보여준다.

#### 승리 후

1. 렌즈 핵에서 금색 잠금 문양 조각이 나온다.
2. 주인공이 문양을 해독한다.
3. `봉인 해제` 카드를 등록한다.
4. HP 20을 회복하고, 현재 HP가 60 미만이면 60으로 보정한다.
5. 본실 봉인문으로 이동한다.

### 8.6 8-D 본실 봉인문

1. 금색 잠금 문양과 봉인 횟수 아이콘을 보여준다.
2. 공격 주문을 선택하면 대상에 효과가 없다는 경고를 카드에 표시한다.
3. 봉인 해제를 선택하면 입력판의 핵심점과 문 잠금이 연결된다.
4. 성공하면 봉인문이 안쪽으로 접히며 열린다.
5. 실패하면 잠금은 유지되고 무제한 재시도한다.

이 장면은 보스 전에 봉인 해제의 문양 자체를 안전하게 연습하는 역할을 한다.

### 8.7 8-E 균열 관측 본실: 관측 관리자

#### 등장

1. 관측창 너머 기괴한 도시와 제0균열의 흔적을 보여준다.
2. 케이블과 관측 장비가 인간형 실루엣을 만든다.
3. 관측 렌즈가 열리며 관측 관리자가 등장한다.
4. 금색 절대 방어막을 가진 상태로 전투를 시작한다.

#### 절대 방어막 체감

1. 첫 행동에서는 공격 카드만 일반 밝기로 보여 공격을 유도한다.
2. 플레이어 공격이 금색 격자에서 흩어지고 피해 0을 표시한다.
3. `절대 방어막: 공격 효과 무효`를 표시한다.
4. 봉인 해제 카드와 방어막 횟수 아이콘을 강조한다.
5. 다음 플레이어 행동에서 봉인 해제를 성공하면 본 전투가 이어진다.

강제 실패는 한 번만 사용한다. 재도전 시 이미 절대 방어막의 규칙을 학습했다면 모든 카드를 처음부터 정상적으로 보여준다.

#### 강공격 대응

1. 파편 조사로 일반 공격을 경험한다.
2. 초점 고정이 다음 강공격을 예고한다.
3. 붉은 렌즈, 조준선과 HUD 아이콘으로 위험을 보여준다.
4. 플레이어는 초급 방벽을 사용하거나 공격으로 처치를 노릴 수 있다.
5. 균열 조사광이 방어막을 먼저 파괴하고 초과 피해를 HP에 준다.

#### 중간 전환

- HP 50% 이하에서 관측 관리자가 절대 방어막을 다시 생성한다.
- 해당 행동은 예정 행동보다 먼저 실행한다.
- 추가 설명 없이 봉인 해제 카드와 금색 방어막 표시만으로 복습하게 한다.

#### 승리 후

1. 관측 렌즈와 푸른 핵이 깨진다.
2. 관리자의 마지막 문장이 중간에 끊긴다.
3. 관측창 밖의 제0균열이 잠깐 선명해졌다 다시 흐려진다.
4. 두루마리 3개 보상 연출을 진행한다.
5. 이번 보상의 실제 신규 주문은 데모에서 등록하지 않아도 된다.
6. 7층 하강문이 활성화된다.

### 8.8 8-F 7층 하강문: 데모 종료

1. 이전보다 복잡한 2획 문 개방 문양을 표시한다.
2. 플레이어가 시간과 마나 압박 없이 문양을 제출한다.
3. `7층 하강 권한 일부 승인`을 표시한다.
4. 문은 완전히 열리지 않고 절반만 열린다.
5. 아래에서 여러 종류의 소리와 희미한 조명이 올라온다.
6. `잔여 절차: 미완료`를 표시한다.
7. 주인공이 아직 층이 남았다는 사실만 확인한다.
8. 타이틀과 `데모 종료`를 표시한다.

전체 탑의 반복 구조와 다른 10층 탑의 진실은 이 시점에서 공개하지 않는다.

## 9. 체크포인트

| 체크포인트 | 저장 내용 |
| --- | --- |
| 10층 시작 | 새 게임 기본 상태 |
| 10층 하강문 개방 | 공격 주문 2종, 튜토리얼 완료 |
| 9층 전투 직전 | HP 100, 공격 주문 2종 |
| 9층 승리 | 기록 관리자 처치, 보상 대기 |
| 8층 진입 | 방벽 관통 습득, 회복 적용 |
| 잔류체 전투 직전 | 초급 방벽 습득 |
| 잔류체 승리 | 봉인 해제 습득, 회복 적용 |
| 관측 관리자 직전 | 주문 5종, HP 최소 60 |
| 관측 관리자 승리 | 보상 및 하강문 대기 |
| 데모 종료 | 읽은 기록, 최고 판정과 완료 상태 |

보상 선택 도중 앱이 종료되면 선택 전 화면에서 다시 시작한다. 선택 확정 직후 저장해 중복 획득을 막는다.

## 10. 예상 플레이 시간

| 구간 | 목표 시간 |
| --- | ---: |
| 10층 | 8~12분 |
| 9층 | 8~12분 |
| 8층 전초 및 잔류체 | 6~9분 |
| 8층 관측 관리자와 엔딩 | 10~15분 |
| 전체 | 32~48분 |

선택 기록을 모두 읽지 않는 플레이어는 약 30~35분, 천천히 조사하는 플레이어는 약 45분을 목표로 한다.

## 11. 플레이 테스트 확인 항목

- 10층에서 별도 설명 없이 카드 선택과 드로잉을 이해하는가
- 두 공격 주문의 난이도와 위력 차이를 체감하는가
- 9층에서 남은 1획으로 두 번째 주문을 사용할 수 있음을 발견하는가
- 말소 구역을 피해 그릴 수 있다고 이해하는가
- 주문서 선택 전 효과가 숨겨져 있다는 사실을 자연스럽게 받아들이는가
- 관측 잔류체의 강공격 예고를 보고 방벽을 선택하는가
- 관측 관리자의 절대 방어막에 봉인 해제를 연결하는가
- 데모 종료가 완결이 아니라 아래층의 존재를 암시한다고 느끼는가
- 필수 진행을 놓쳐 장면 안에서 오래 헤매는 구간이 없는가
