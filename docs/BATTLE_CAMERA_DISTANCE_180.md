# 전투 카메라 거리 소폭 확대

- 브랜치: `fix/#180-battle-camera-distance`
- 기준: `origin/fix/#180-battle-visibility-validation` (`e49313f`)

현재 전투 구도가 너무 붙어 보인다는 피드백에 따라 몬스터 높이 대비 카메라 거리 계수를 2.45에서 2.65로 늘렸다. 기존 거리보다 약 8.16% 뒤로 이동하며 같은 시야각에서 몬스터의 화면상 크기는 약 7.5% 줄어드는 수준이다.

기존 주시점·좌우 배치·시야각과 전용 조명 설정은 유지한다. 원래 방에 설정된 카메라 거리보다 뒤로 가지 않도록 기존 상한을 유지한다. 기본 시점 복귀도 새 거리의 전투 스냅샷을 사용한다.

9~1층 몬스터 21종의 공통 전투 구도에 적용된다. 10층은 몬스터가 없는 훈련판 구도이며 이 함수의 대상이 아니다. 조사·보상·하강 화면도 이번 거리 변경 대상이 아니다.

## 확인

- 21개 장면의 원본 카메라·적 배치·목표 높이로 새 거리가 원래 거리 상한 안에 있음을 확인했다.
- iPad 시뮬레이터 Debug 빌드 성공.
- 대표 6개 장면(8층 관리자, 7층 잔류체, 4·3·2·1층 관리자): 장면 로드 및 행동 예고·방어막·회전 검사 90건 통과.
- 기본 시점 복귀 행렬 최대 오차 7.45e-9, 시야각 오차 0.
- 기본/행동 예고/최대 아래 회전 캡처에서 후퇴한 구도와 여백을 확인했다.
- 이번 변경은 시뮬레이터 중간 품질의 대표 장면 검증이며, 실기기 전체 플레이는 수행하지 않았다.
