# #112 8층 보스방 배경 움직임

브랜치: `feat/#112-floor8-ambient-motion`

## 구현

- 센서 본체 5개는 유지하고 별도 추가된 `F08B_Sensor_Lens*` 원판을 내부 계층까지 찾아 제거한다. 원본 Blender 및 USD 자산은 수정하지 않는다.
- 센서는 원래 위치 주변에서 좌우 최대 18cm, 앞뒤·상하 최대 12cm 이동하며 약 5도 이내로 천천히 회전한다.
- 유리 파편 13개는 서로 다른 위상과 주기로 상하 7~16cm 움직인다. 매 프레임 난수를 사용하지 않아 순간 이동이나 떨림이 없다.
- 파편 하나와 금속 테두리 3개를 같은 그룹에 넣어 함께 이동한다.
- 방 로컬 Z-up 좌표에서 원래 변환을 기준으로 계산하므로 누적 위치 오차가 없다.
- 단일 30Hz 타이머가 18개 그룹 변환만 갱신한다. 추가 텍스처·물리·메시 재생성은 없다.
- 앱 비활성 또는 화면 미표시 때 변환 갱신을 건너뛴다. 방 해제 시 타이머를 취소한다.
- 동작 줄이기 설정은 타이머를 취소하고 원래 변환으로 복원한다.

## 확인

- Debug iOS Simulator 빌드 성공.
- iPad Pro 13인치 시뮬레이터의 medium 자산에서 원판 제거를 실제 화면으로 확인.
- 실행 진단에서 남은 원판 0개, 움직이는 센서 5개와 파편 13개 확인.
- 서로 다른 두 시점에 18개 그룹 위치가 달라지고, 그룹 내부 자식 변환은 유지됨을 확인.
- 파편 상하 이동 범위 및 동작 줄이기 설정의 원위치 복원 확인.
- 실기기 FPS·장시간 성능 측정은 이번 범위에서 수행하지 않음.

## 개발용 재확인

Debug 앱 실행 인수:

```
--floor9-preview --floor8-boss --boss --graphics-medium --ambient-diagnostics
```

전용 미리보기 카메라에서 2개 화면과 위치·자식 변환·동작 줄이기 결과를 앱 Documents/AmbientDiagnostics에 저장한다. 실제 플레이 카메라와 저장 데이터에는 적용하지 않는다. 진단 기능은 Release에서 제외된다.
