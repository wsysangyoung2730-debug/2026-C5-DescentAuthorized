# #148 방 진입 로딩·보스 지속 효과 경량화

브랜치: `perf/#148-boss-room-loading`

## 범위

현재 앱에 포함된 USDC 리소스의 준비·재사용 경로를 개선한다. 모델 다운로드 서버나 전체 층 메모리 상주는 추가하지 않는다. 앱에 파일이 있어도 디코딩, 장면 설치, GPU 준비 비용은 남으므로 다운로드 완료와 즉시 렌더링 가능 상태를 구분한다. Blender 원본, 텍스처 해상도, 그림자 품질, 전투 규칙은 변경하지 않는다.

## 변경

1. 방과 함께 해당 장면의 적·공용 보상 장치·보상 두루마리를 비동기로 준비한다. 방과 보상 의존성이 준비되면 설치하고, 적은 기존 준비 완료 조건을 유지한다. 9층의 숨겨진 적은 기존처럼 탐색 시작을 차단하지 않는다.
2. 보상 장치 설치 중 수행하던 동기 `Entity.load` 두 곳을 제거했다. 준비된 원본을 복제하여 설치하므로 보상 교체·배치가 캐시 원본을 변형하지 않는다.
3. 사전 준비 캐시는 다음 방 하나와 선택된 장면의 보조 자산(적 하나, 보상 원본 최대 두 개)만 유지한다. 다음 장면 선택 시 불필요한 보조 항목을 제거하고 적은 사용 시 캐시에서 소비한다. 활성 장면 및 진행 중 구독이 소유하는 리소스는 별개이므로 이 개수는 전체 앱 메모리 상한이 아니다.
4. 메모리 경고 시 방·보조 자산·환경 캐시를 비운다. 실패한 사전 로딩은 다시 준비할 수 있다. 캐시가 비어 있으면 일반 비동기 로딩으로 진행한다.
5. 기존 10→9층·9→8층·8층 잔류체→보스 사전 로딩에 보조 자산 준비가 함께 적용된다. 7~5층은 중간문 단계에서 보스방, 7~6층 보상/하강 단계에서 다음 층 잔류체 방을 준비한다. 전투 단계에서는 새로운 추측성 로딩을 시작하지 않는다. 앞 단계에서 이미 시작한 준비는 이어질 수 있다. 4~1층의 현재 2D 경로는 바꾸지 않는다.
6. 지속 전투 상태의 고리를 32개 선 모델에서 단일 고리 모델로 바꾼다. 같은 반지름의 메시를 재사용하고, 나머지 선도 단위 박스 메시를 공유한다. 색상·위치·투명도는 효과별로 독립적이다. 고리 메시 생성 실패 시 기존 선 표현으로 대체한다. 이는 모델 엔티티 수 감소이며 실제 GPU 드로콜 수 보장은 아니다.
7. 상태 갱신 때마다 맥동 작업을 취소·재생성하지 않는다. 일시정지·동작 줄이기·초기화는 계속 중단 처리하고, 이전 취소 작업이 새 작업의 참조를 지우지 않도록 세대를 확인한다.

## 진단 로그

`SceneLoading` 범주에서 `room.begin`, `room.decoded`, `room.dependenciesReady`, `room.installCPU`, `actor.begin`, `actor.ready`, `room.ready`를 비교한다. `room.installCPU`는 동기 설치 구간이며 GPU 완료나 첫 프레임 표시 시간을 뜻하지 않는다. 다른 seconds 로그는 각 시작점 기준 경과 시간이므로 단순 합산하지 않는다. 사전 로딩 시간은 사용자가 읽기·선택 단계에서 보내는 시간에 겹쳐진다.

## 검증 및 한계

- iOS Simulator arm64 Debug 빌드 성공 (2026-09-24). 기존 `loadAsync` 등 사용 중단 예정 API 경고는 남아 있다.
- `ExpansionSceneRouteTests`, `CombatPresentationTimelineTests`, `CheckpointReplayTests` 기존 코어 테스트 14개 통과, 실패 0개. 코어 테스트는 RealityKit 캐시·메시의 실행 검증을 대신하지 않는다.
- 코드 검토: 보상 동기 로딩 제거, 캐시 교체 중 구독 소유권, 실패 재준비, 효과 작업 취소/재시작 흐름.
- 실기기 로딩 시간·프레임 시간·최대 메모리와 변경된 고리의 시각 검증은 미실시. 따라서 로딩 초 단축이나 FPS 개선 수치를 제시하지 않는다.

## 후속 실기기 비교 절차

동일 기기·화질·세이브로 기준 커밋과 이 브랜치를 각각 실행한다. 냉시작, 방 재진입, 즉시 문 해제, 충분히 기다린 문 해제를 나누어 각각 3회 이상 측정한다.

- 7~5층 잔류체→보스: 준비 중 문을 즉시 해제해도 정상 진입하며 보스·보상 장치 누락이 없는지 확인.
- 7→6→5층: 보상 선택과 하강, 체크포인트 재시작, 화질 변경, 메모리 경고 후 재진입 확인.
- 9층 탐색: 숨겨진 적 로딩 중에도 기존 탐색이 가능한지 확인.
- 보스전: 강화·방벽·예약 피해를 겹쳐 켜고 소비·정화·만료·재활성화, 일시정지·동작 줄이기 전환 확인.
- Instruments에서 메인 스레드 긴 작업, GPU 프레임 시간, 메모리 최고점을 비교. 장면 설치·충돌 생성·GPU 업로드가 여전히 크면 별도 프로파일링 후 나누어 처리한다.
- 고리의 두께·방향·가림·카메라 회전 시 형태 확인. 고리 단면은 기존 박스 연결과 약간 다를 수 있다.
