# 5층 두 방 배치 · v041

5층 잔류체 방과 보스방을 기존 5층 기물 20종으로 구성한 Blender 작업 기록이다.

## 최종 반영

- 잔류체 방: 아치 천장, 기록 보관·반향 재생 기물, 낮은 필적 대조 책상과 기록 상자. 보스 스테이지 및 원형 테두리는 제거하고 중앙을 평평하게 확보했다.
- 보스방: 격자 천장과 가면·신원 대조·기억 추출 기물. 보스 스테이지는 유지했다.
- 좌우 측면에 두 방 각각 23개 기물을 추가했고, 70도·90도 회전 시점에서 배치와 모서리를 확인했다.
- 보상 두루마리 모델 3개를 제거하고 비표시 슬롯 기준점은 유지했다.
- 장식용 문을 실제 이동 통로에서 분리하고 보상대·하강 비석·발판의 시야를 확보했다.
- 다른 층과 5층 보스방의 최종 배치 보존, 기물 겹침, 중앙 등장 시야, 텍스처 누락 검사를 통과했다.
