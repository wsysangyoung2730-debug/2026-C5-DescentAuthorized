## 원인

- Blender 곡선이 USD BasisCurves로 남아 RealityKit에서 구조물 일부가 표시되지 않았다. 원본 파일을 수정하지 않고 평가된 곡선 표면을 메시로 가져왔다. 저·중품질 파일은 기본 파일을 상속하므로 중복 구조물을 추가하지 않았다.
- 1층 천장은 외부를 향한 면만 있었으며 돔과 벽 사이에 틈도 있었다. 내부 면과 마감부를 추가했다. 2층 카메라는 방의 앞 경계 밖에 있어 실내로 옮겼다.
- 공격 문양에 기존 색상 이미지가 사용되고 화면별 색 정의도 달랐다. 실제 문양 경로와 공통 공격 색을 사용한다.
- 하층 보상 경로는 세 두루마리 트랙만 별도 슬롯으로 옮겨 재생하여 받침대 뚜껑과 승강부가 빠졌다. 공통 장치 계층과 13개 원본 트랙을 함께 재생한다.

## 검증

- `ExpansionProgressTests`, `LowerFloorNarrativeTests`: 10개 성공, 실패 0개.
- iOS 시뮬레이터 Debug 빌드 성공.
- 1·2층 여섯 방: 기본/좌우 상단 회전 화면 확인. 1층 보스 돔 틈은 마감 후 재확인했다.
- 보상 대표 장면: 7·4·3·2층에서 받침대와 세 두루마리 표시 확인. 4층 상단 잘림 발견 후 시야각 최소 55도로 수정하고 재확인했다.
- 7·4·3·2·1층 진단: 뚜껑 3개와 승강부 이동, 닫힌 자세 복귀, 동작 줄이기 완료, 받침대 너비 양수 확인. 1층은 기존 보상 후보가 0개인 최종층이므로 두루마리를 새로 지급하지 않는다.
- 수치 결과는 `validation-183-186.json`에 기록했다. 7층과 1층 보상 결과는 시야각 보정 전 기록이며 장치 동작 검증에 사용했다.
- 전체 플레이 및 실제 기기 성능 검증은 수행하지 않았다.
