## 이미지

기존 8~9층 로딩 배경과 같은 1448×1086 PNG 3장을 생성 원본 그대로 에셋 카탈로그에 등록했다. 이미지에 문구를 합성하지 않고 기존 로딩 안내와 진행 표시를 사용한다.

| 층 | 에셋 | 장면 |
| --- | --- | --- |
| 7 | `LoadingFloor07` | 좌표 교정 관리자, 청록색 복층 측량실 |
| 6 | `LoadingFloor06` | 인과 검증 관리자, 호박색 돔과 시간 장치 |
| 5 | `LoadingFloor05` | 원본 기억 관리자, 가면과 기억 보관실 |

## 연결 범위

- 공통 `LoadingScreenContext`에서 7·6·5층별 배경을 선택한다.
- 각 층의 잔류체방·관리자방 로딩에 적용한다.
- 전투 재시작, 체크포인트 이동, 하강 봉인 재시작도 같은 공통 배경 선택을 사용한다.
- 시작 시 이미지 준비 목록에 새 배경 3장을 추가했다.
- 10~8층과 홈 시작 화면은 기존 배경과 레이아웃을 유지한다.
- 아직 지원하지 않는 확장 층은 기존 `LoadingMain`으로 대체한다.
