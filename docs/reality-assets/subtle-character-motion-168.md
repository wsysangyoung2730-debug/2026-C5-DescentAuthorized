# #168 캐릭터 미세 모션 및 7층 대화 복구

## 구현

- 전체 21종 캐릭터를 관절 변형 대신 모델 전체의 미세 이동/회전으로 표시한다.
- 대기는 약 ±0.23도 회전만 사용하며, 수직 부유나 크기 변화는 없다.
- 공격/피격은 모델 높이의 최대 1% 이내에서 움직이고 원래 위치로 복귀한다.
- 소멸은 투명도 페이드로 처리하며, 일시 정지·동작 줄이기·전투 재시작을 반영한다.
- 런타임 USD의 스켈레톤/스키닝 바인딩을 제거했다. 메시 정점·UV·재질을 보존하고, 원본 GLB와 Blender 리그는 변경하지 않았다.
- high/medium/low 63개 변형 모두 같은 정적 모델 표시 정책을 사용한다. medium/low는 high 원본을 참조한다.
- 최종 배경이 설치된 경우에도 7~5층 조우/처치 대화를 선택하도록 라우팅을 수정했다. 배경만 남는 원인은 최종 방 연결의 조기 반환이 대화 단계를 일반 화면으로 분류했기 때문이다.
- 4~1층의 전용 대화 패널 경로는 유지한다.

## 검증 범위와 인계

사용자가 직접 테스트하기로 하여 진행 중이던 테스트를 중단했다. 중단 전 시뮬레이터 빌드는 성공했으며 일부 모션 진단이 완료되었지만, 전체 동작과 대화 전환 검증 완료를 의미하지 않는다. 최종 수동 테스트는 사용자에게 인계한다.

확인할 화면: 9·8층 보스의 대기/공격, 7층 잔류체와 관리자 조우 대화, 소멸 후 재시작. 같은 대화 경로를 사용하는 6·5층도 확인 대상이다.
