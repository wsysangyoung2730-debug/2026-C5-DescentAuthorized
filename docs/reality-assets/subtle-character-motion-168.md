# #168 캐릭터 미세 모션 및 7층 대화 복구

## 구현

- 전체 21종 캐릭터를 관절 변형 대신 모델 전체의 미세 이동/회전으로 표시한다.
- 대기는 #135 기준 4초 주기, 0.018 rad(약 ±1.03도)의 작은 회전을 사용하며, 수직 부유나 크기 변화는 없다.
- 일반/강공격은 모델 높이의 1.5%/2% 이내에서 움직이고 원래 위치로 복귀한다. #139의 충격 시점인 0.46초/0.62초에 움직임이 최대가 된다.
- 피격은 #139의 `sin(πt) × exp(-2t)` 감쇠 곡선과 0.8초 복귀 시간을 적용한다. 관절 대신 전체 모델의 짧은 후퇴와 회전으로 표현하며, 후퇴 최대치는 높이의 약 2.7% 이내다.
- 소멸은 투명도 페이드로 처리하며, 일시 정지·동작 줄이기·전투 재시작을 반영한다.
- 런타임 USD의 스켈레톤/스키닝 바인딩을 제거했다. 메시 정점·UV·재질을 보존하고, 원본 GLB와 Blender 리그는 변경하지 않았다.
- high/medium/low 63개 변형 모두 같은 정적 모델 표시 정책을 사용한다. medium/low는 high 원본을 참조한다.
- 최종 배경이 설치된 경우에도 7~5층 조우/처치 대화를 선택하도록 라우팅을 수정했다. 배경만 남는 원인은 최종 방 연결의 조기 반환이 대화 단계를 일반 화면으로 분류했기 때문이다.
- 4~1층의 전용 대화 패널 경로는 유지한다.

## 검증 범위와 인계

사용자가 직접 테스트하기로 하여 진행 중이던 테스트를 중단했다. 중단 전 시뮬레이터 빌드는 성공했으며 일부 모션 진단이 완료되었지만, 전체 동작과 대화 전환 검증 완료를 의미하지 않는다. 최종 수동 테스트는 사용자에게 인계한다.

확인할 화면: 9·8층 보스의 대기/공격, 7층 잔류체와 관리자 조우 대화, 소멸 후 재시작. 같은 대화 경로를 사용하는 6·5층도 확인 대상이다.

현재 브랜치: `fix/#168-subtle-character-motion` (기존 #167 수정에서 분기). develop/main에는 병합하지 않았다.

## 사용자 지정 기준 반영

참조 브랜치:

- `origin/feat/#135-legacy-actor-motion-projectile` (`b02f8b7`): 대기 주기와 보수적인 동작 크기.
- `origin/feat/#139-enemy-attack-defeat-motion` (`ed8465f`): 피격 감쇠 곡선, 발사체 충돌에 맞춘 반응, 공격 충격 시점.

#135의 관절별 움직임은 정적 모델 전체의 작은 움직임으로 옮겼다. 기존에 깨졌던 스키닝을 재활성화하거나 과거 브랜치 전체를 되돌리지 않았다. 전 층 21종과 모든 그래픽 품질에 동일한 재생 프로필을 사용하며, 개별 에셋에 남은 관절 클립 길이 때문에 리듬이 달라지지 않는다.

#139의 발사체 크기/속도, 충돌 잔광과 파편 소멸, 플레이어 피격 플래시/화면 흔들림, 방어 반응은 현재 구현에도 유지되어 있어 그대로 사용한다. 방벽 충돌에는 몸 반동을 적용하지 않으며, 실제 적 피격 충돌 콜백에만 반동을 연결한다. 이후 추가된 하층 전투 규칙과 7~5층 대화 복구는 보존한다.

이번 기준 조정 후에는 사용자 요청에 따라 빌드, 자동 테스트, 시뮬레이터 실행을 하지 않았다.
