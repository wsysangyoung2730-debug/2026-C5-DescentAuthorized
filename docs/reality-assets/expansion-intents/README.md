# 5~7층 행동 예고

기준 브랜치: `feat/#135-legacy-actor-motion-projectile` (`b02f8b7`).
작업 브랜치: `feat/#136-expansion-intent-vfx`.

최신 `DA_F05_F06_F07_F08_F09_F10_Combined_v051_combat_intents_cleaned.blend`의 EXPORT 컬렉션 7종을 사용한다. 원본 장면과 미리보기 갤러리는 수정하지 않았다.

| 문양 | 게임 행동 | 연기 색 |
|---|---|---|
| OpeningWait | 7층 좌표 붕괴·재측량, 실제 예약 집행이 없는 대기 | 청록 |
| Amplify | 6층 잔류 증폭·인과 증폭 | 주황 |
| DamageReservation | 6층 결과 각인·집행 등록, 5층 기록 압축 | 금색 |
| ScheduledExecution | 대기 행동 중 현재 적 턴에 도래한 예약이 있을 때 | 붉은 주황 |
| MemoryRecord | 5층 기억 붙잡기·원본 채취 | 보라 |
| MimicAttack | 5층 모사 할퀴기·원본 대조 | 붉은 자홍 |
| SpellSeal | 5층 보관 명령, 선택 주문이 확정된 봉인 행동 | 자홍 |

일반 공격·강공격·일반 방벽·절대 방벽은 기존 문양을 유지한다. 일반 행동과 함께 발생하는 예약 피해의 상세 정보는 기존 예약 HUD에 유지되며, 주 문양은 그 턴의 행동을 표시한다. 예약 집행 여부는 행동 이름이 아니라 현재 예약 큐의 `dueEnemyTurn <= turnNumber`로 결정해 삭제·지연 주문을 반영한다.

## 표현

기존 적 머리 위 배치와 방벽 간격 보정을 사용한다. 모든 예고 문양 뒤에 동일한 경량 입자 연기를 붙이고 색을 행동별로 바꾼다. 방의 Z축을 따라 올라오며 크기가 커지고 투명해진다. 문양 중심을 덮지 않도록 +Y 뒤쪽에 배치한다. 입자 이미지는 앱에서 부드러운 방사형 그라데이션을 한 번 생성해 공유한다.

행동 변경·처치·재시작·장면 해제 시 문양과 연기도 함께 제거된다. 일시정지 시 입자 시뮬레이션을 정지한다. 동작 줄이기에서는 움직이는 연기 대신 정적인 색상 후광을 표시한다.

## 에셋 재생성

Blender 백그라운드 실행으로 원본을 연 뒤 `export_intents.py -- --output <임시 출력 폴더>`를 실행한다. 그 결과에 기존 `optimize_portable_exports.py`를 적용하면 2048/1024/512 텍스처와 이식 가능한 USD가 생성된다. 런타임은 기존 전투 효과와 동일하게 기본 USDC를 사용한다.

## 최소 검증

- 7종 × 3화질의 기준 객체·메시·텍스처 경로·약 1.15m 크기 확인 (`validation.json`).
- iOS 시뮬레이터 Debug 빌드 성공.
- 실제 플레이에서 문양 방향·가림·연기 강도와 기기 성능은 사용자 확인 예정.
