# #134 조우·처치 이미지 비율 및 보상 두루마리 등급 정합성

## 변경 목적

7~5층 조우·처치 장면의 16:9 이미지와 iPad 화면 사이에서 생기던 검은 여백을 줄이고, 8·9층의 4:3 구도와 표시 방식을 적용한다. 보상 장치의 두루마리 외형은 실제 선택 후보의 주문 등급과 일치시킨다.

## 이미지

- 7·6·5층 잔류체/관리자 조우·처치 12장을 기존 이미지를 참조해 재생성.
- 목표 크기는 기존 8·9층과 동일한 1448×1086.
- 캐릭터·층별 방·문구를 보존하고, 하단 대화창 뒤에 바닥이 이어지도록 재구성.
- 관리자 정보판을 오른쪽에 유지하며 잔류체에는 정보판을 추가하지 않음.
- 공통 `BossNarrativeView`의 표시를 8·9층과 동일한 fill/center로 통일.
- 생성 방식: 내장 image_gen. 개별 프롬프트와 원본/결과 경로는 `narrative-artwork-134-prompts.json`에 기록.

## 두루마리

층 번호와 슬롯별 등급을 따로 하드코딩하지 않고 `RewardCatalog.candidates(forFloorNumber:)`의 순서와 `tier`를 사용한다.

| 층 | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| 7 | 축선 절단 · 각인 | 기준점 수호 · 봉인 | 결과 말소 · 봉인 |
| 6 | 집행 지연 · 봉인 | 선행 판결 · 각인 | 인과 완충 · 봉인 |
| 5 | 기억 절단 · 각인 | 기억 봉합 · 봉인 | 모사 금지 · 금기 |

각인 모델은 기존 RewardScroll 에셋에서, 봉인/금기 모델은 공용 RewardDevice에서 재사용한다. 원래 8층 장치의 왼쪽 모델은 낡은 주문서이므로 각인 모델로 간주하지 않는다. 템플릿을 먼저 복제한 뒤 슬롯의 표시 모델만 교체한다. HoleAnchor/Appear/Idle, 받침대, 13개 모션 트랙 및 상승·선택 흐름은 유지한다. 고/중/저 화질 설정을 모두 따른다.

## 최소 검증

- iOS Simulator Debug 빌드 성공.
- 세 화질의 두루마리 메시가 Z-up, 밑면 0, 높이 약 1의 동일 기준을 사용하는지 확인.
- 생성 결과의 크기와 제목/정보판/대화 영역 구도를 확인.
- 실제 기기 플레이 및 애니메이션 체감 검증은 수행하지 않음.
