## 171

최종 방은 `rewardMotionAsset`을 nil로 반환해 8층의 66프레임/30fps 모션 대신 임의의 0.44 상승과 0.68배 확대를 사용했다. 이제 8층의 HoleAnchor/Appear/Idle 계층 모션을 합성하고 종료 자세를 기준으로 각 슬롯에 재배치한다. 받침대 경계 상단을 사용한 강제 높이 보정도 제거해 저작된 슬롯 위치를 따른다. 받침대는 움직이지 않는다. 선택 후 부유·말소는 공통 플레이어 경로를 쓴다.

## 172

4~1층 보상도 8층과 동일한 공통 선택·상세 열람·확정·습득 화면을 사용한다. 하층에만 있던 선택 전 시험 각인 버튼과 연습 시트를 제거했다. 선택 후 필수 문양 학습은 8층과 동일하게 유지한다. 보스 전 기록 보상은 같은 UI 틀 안에서 제목을 `조사 기록 해독`으로 구분한다.
