## 171

최종 방은 `rewardMotionAsset`을 nil로 반환해 8층의 66프레임/30fps 모션 대신 임의의 0.44 상승과 0.68배 확대를 사용했다. 이제 8층의 HoleAnchor/Appear/Idle 계층 모션을 합성하고 종료 자세를 기준으로 각 슬롯에 재배치한다. 받침대 경계 상단을 사용한 강제 높이 보정도 제거해 저작된 슬롯 위치를 따른다. 받침대는 움직이지 않는다. 선택 후 부유·말소는 공통 플레이어 경로를 쓴다.

## 172

4~1층 보상도 8층과 동일한 공통 선택·상세 열람·확정·습득 화면을 사용한다. 하층에만 있던 선택 전 시험 각인 버튼과 연습 시트를 제거했다. 선택 후 필수 문양 학습은 8층과 동일하게 유지한다. 보스 전 기록 보상은 같은 UI 틀 안에서 제목을 `조사 기록 해독`으로 구분한다.

## 173

9·10층의 분절된 구형 하강문을 7층 최신 문짝/문틀 에셋으로 교체했다. 기존 방의 문 위치·회전·크기 및 비석/발판은 보존한다. 세 그래픽 품질별 공유 문을 참조하고 최신 문짝 컨트롤러로 열림을 연결했다. 원본 7층 재질과 텍스처 참조를 재사용한다. 실행 재현 스크립트: `replace_upper_descent_doors.py`.

## 174

잔류체 A 처치 후 독립 저장 지점인 중앙문 승인 단계를 추가했다. 승인 후에만 B방 조사로 이동하며 재실행 시 승인 앞에서 재개한다. 7~1층 중간문은 층별 한붓 문양을 사용하고, 4~1층 A→B 문양은 같은 층 관리자 진입 문양과도 다르게 배치한다. 하층 진행·저장 복원·문양 판정 테스트 19개 통과.

## 175

조사 기록을 읽으면 같은 자리에서 8층 공통 진입 패널이 나타난다. 시작 버튼은 가방을 열며, 가방 확정은 유효한 준비 상태에서 바로 전투로 이동한다. 기존 조우 화면을 추가 클릭하던 단계를 제거하고 저장된 준비 지점에서도 같은 패널을 사용한다. 진행은 하나의 명령으로 처리해 중간 상태 저장을 방지한다.

## 176

4~1층은 8층의 하강 기록/점 연결 입력/실패/재시도/문 열림 화면을 그대로 사용한다. 층마다 서로 다른 3개 패턴을 제공하고 승인 저장은 각 단계마다 유지한다. 두 번 실패하면 같은 게임오버 흐름을 거치며 기존 자유 각인 전용 UI는 제거했다.

## 177

4층 A/B방에 기록 조사용 카메라를 추가했다. 중앙 통로에서 각 방의 조사 책상을 눈높이로 바라보며, 전투 시작 시 기존 전투 카메라로 돌아간다. B방 조사는 A방이 아니라 B방을 선택한다. 세 그래픽 품질 모두 동일한 카메라를 포함한다.

## 178

9층 기록 관리자와 8층 관측 관리자의 기존 스킨 데이터는 실제 5개 뼈(0~4)보다 큰 관절 번호(최대 40)를 참조했다. #165에서 바인딩을 활성화하면 잘못된 관절 변형이 표면 전체와 긴 장비를 끌어당겼다. #168에서 제거한 바인딩은 유지한다. 다른 모델도 다리/무릎을 구분하지 않는 5개 뼈라 그대로 전신 쓰러짐을 구동하기 어렵다.

대기 움직임은 #135 수준, 공격/피격 시간과 반동은 #139 수준을 유지했다. 소멸은 0.65초간 완만하게 기울어진 후 0.95초간 앞으로 쓰러지고, 바닥에 머문 뒤 0.65초 동안 사라진다. 매 프레임 원래 자세와 고정된 바닥 기준으로 계산하므로 누적 회전이나 관절 늘어남이 없다. 전체 모델을 기울이는 방식이며 무릎을 굽히는 새 관절 애니메이션은 아니다. 모션 감소 설정은 회전을 생략한다.

## 179

추가 요청에 따라 4~1층 전투를 상층과 동일한 최상위 공통 BattleView 경로에 연결했다. 하층 전용 진행 뷰에서 중첩한 전투 대신 같은 시점 입력 수명주기를 사용한다. 방 로딩이 카메라 조작 허용 상태를 초기화하는 문제를 방지하기 위해 로드 완료와 드래그/핀치 시작 시 현재 전투의 허용 상태를 재적용한다.

공통 제한값(좌우 ±60°, 상하 ±25°, 시야 배율 0.85~1.10), 드래그·핀치 조작, 기본 시점 복귀 버튼을 재사용한다. 문양 입력판 터치는 카메라 제스처에서 제외하며 일시정지·피격 연출·패배 중에는 기존 입력 차단을 유지한다.
