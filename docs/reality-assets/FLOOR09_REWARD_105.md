# #105 — 9층 카메라와 두루마리 출현

브랜치: `feat/#105-floor9-reward-motion`

## 적용 범위

9층 씬만 v020 Blender 결과로 교체했다. 8층과 10층 에셋 및 8층 보상 재생 방식은 유지한다.
원본: `DA_F08_F09_F10_Combined_v020_f09_right_scroll_fix.blend`, 씬 `DA_F09_Archive_Redesign`.

- 보스: `F09_iPad_MainCamera`
- 두루마리: `CAM_F09_RewardSelection` (뒤로 물러난 30mm 시점)
- 하강문: `CAM_F09_DescentDoor`
- 컨셉용 네 번째 카메라는 게임 에셋에서 제외했다.

## 모션 연결

기존 코드는 장면 원점에서 떨어진 HoleAnchor 전체를 축소/이동했다. 이 방식은 뚜껑과 중앙 리프트를 재생하지 않고, 두루마리가 슬롯에서 솟는 대신 기준점에 따라 이동하게 만든다.

새 `floor09_reward_motion.json`은 Blender 1~66프레임, 30fps의 13개 객체의 부모 기준 행렬을 저장한다. `matrix_local`을 사용하여 Blender의 parent inverse까지 포함한다. Swift는 행렬을 위치·회전·크기로 나누어 보간하며 약 2.167초 동안 재생한다. USD에는 시간 샘플을 넣지 않아 중복 재생을 막는다.

13개 트랙: 중앙 리프트, 뚜껑 3개, 두루마리 HoleAnchor/Appear/Idle 각 3개. 실제 위쪽 뚜껑을 사용하는 오른쪽 슬롯은 최대 40도까지 열리고 최종 35도로 정착한다. 두루마리 출현은 보상 카메라 전환과 로딩 완료 뒤 시작하고, 선택 UI는 실제 재생 완료를 기다린다. 선택 후 움직임은 두루마리의 Idle 그룹을 기준으로 수행한다.

다시 재생하면 첫 프레임으로 복원한다. 화면 이탈/씬 해제 시 대기와 재생을 취소한다. 동작 줄이기에서는 최종 자세로 즉시 전환한다.

## 내보내기 주의

USD는 66프레임의 정적 메시와 계층으로 내보낸 뒤 로딩 직후 모션 첫 프레임을 적용한다. 닫힌 하강문 계층은 1프레임, 열린 하강문 계층은 열린 상태를 보존하며 기존 게임 상태에서 토글한다.

두루마리 UV는 face-varying 값을 풀어서 저장하고 메시/텍스처에 9층 고유 이름을 사용했다. 시뮬레이터에서 왼쪽 두루마리 표면이 깨져 보이던 현상은 이 정리 이후 사라졌다. 정확한 RealityKit 내부 원인은 확정하지 않았다.

바닥 콘크리트·벽 석고·철재·표시선의 절차적 재질은 2048px 색상/거칠기/탄젠트 노멀 맵으로 베이킹했다. 160개 표면 메시의 월드 평면 UV에 8m 단위로 연결했다. 재질은 v022 원본에서 읽었으며 카메라/배치/모션은 #105 에셋을 유지했다. 최초 적용 당시 천장 보조 조명은 4개였다. 후속 #106 작업에서 원본의 조명 12개 배치에 맞춰 보완했다. Blender의 면광원·간접광·AgX 톤매핑과 RealityKit 실시간 렌더는 동일하지 않다.

## 빠른 확인

Xcode Debug 실행 인수에 `--floor9-preview`를 추가하면 9층 전용 미리보기가 열린다. 보스/두루마리/하강문 버튼과 다시 보기, 동작 줄이기를 제공한다. `--boss` 또는 `--descent`로 시작 시점을 바꿀 수 있다. Release 빌드에는 진입점이 없다. 미리보기는 진행도를 변경하지 않고 생명주기 자동 저장 및 Game Center 인증을 실행하지 않는다.

검증:
- iOS Simulator Debug 빌드 성공.
- 기존 Swift 패키지 테스트 156개 통과.
- iPad Pro 13-inch (M5), iOS 26.5 시뮬레이터에서 세 카메라와 출현 완료 자세 확인.
- `validate_floor09_motion.py`: 3개 카메라, 13×66 유효 변환, USD/모션 좌표 일치, 중복 애니메이션 없음, 텍스처 참조, 오른쪽 최종 35도 검증.
- 실제 iPad 성능과 보스전부터 보상 선택까지 전체 플레이는 별도 확인이 필요하다.

검증 스크립트는 pxr/numpy가 있는 Python에서 저장소 루트를 인자로 실행한다. 이 개발 환경에서는 Blender 번들 Python을 사용했다.
