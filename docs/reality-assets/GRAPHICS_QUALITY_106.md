# #106 그래픽 품질 설정

브랜치: `feat/#106-graphics-quality-settings`.
105번 질감 적용 커밋 `15e929d`에서 분기했다.

설정 → 화면 효과 → 그래픽 품질에서 낮음/보통/높음을 선택한다. 기본값은 보통이다.

| 품질 | 9층 배경 텍스처 | 천장 그림자 |
|---|---|---|
| 낮음 | 512×512 | 없음 |
| 보통 | 1024×1024 | 2개 조명 |
| 높음 | 2048×2048 | 4개 조명 |

색상·거칠기·노멀의 12개 맵을 품질별로 제공한다. 낮은 품질에서도 얼룩과 표면 질감은 유지한다. 소품/보스/두루마리 텍스처는 이번 품질 설정에서 변경하지 않는다.

품질별 USD 오버라이드는 같은 원본 씬을 참조하며 텍스처 경로만 교체한다. 낮음으로 시작할 때 높은 해상도 배경 텍스처를 먼저 로드하지 않는다. 현재 공간의 텍스처는 다음 공간 로딩/앱 재시작 시 적용한다. 설정 변경 때문에 카메라나 진행 상태를 리셋하지 않는다. 그림자와 후처리 옵션은 즉시 반영한다. 낮음에서는 피사계 심도/접지 그림자도 비활성화하고 HDR 밝기와 UI 해상도는 유지한다. 실제 화면 렌더 배율 변경은 포함하지 않는다.

설정 저장 버전은 4이다. 이전 버전이나 알 수 없는 품질 값은 보통으로 읽고 나머지 설정은 유지한다. 저장 실패 시 기존 선택을 유지한다.

## 검증

- Debug iOS Simulator 빌드 성공.
- Swift 패키지 159개 테스트 통과: 이전 설정 마이그레이션, 품질 저장/복원/초기화, 저장 실패 동작 포함.
- 각 품질의 12개 텍스처 크기 및 참조, 3개 카메라와 13개 모션 객체 보존 검증.
- 시뮬레이터에서 질감 적용된 9층 보스 시점, 낮음 품질의 두루마리 완료 자세 확인.
- 실기기 FPS/메모리는 측정 전이므로 특정 성능 향상 수치를 보장하지 않는다.

Debug 미리보기 실행 인수: `--floor9-preview --graphics-low` 또는 `--floor9-preview --graphics-high`. 인수가 없으면 저장된 설정을 사용한다. 미리보기 인수는 설정 저장값을 덮어쓰지 않는다.

정적 에셋 검증: pxr가 설치된 Python으로 `docs/reality-assets/validate_graphics_quality.py <저장소 루트>` 실행.
