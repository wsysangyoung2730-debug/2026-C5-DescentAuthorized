# C5 6–10층 공간 배치 · v038

## 반영 내용

- 6층 잔재방: 낮은 기록 보관실, 좌우 증거·릴 보관장, 중앙 통로와 출입문.
- 6층 보스방: 팔각형 외곽과 원형 바닥 회로. 전투 화면을 가르던 기둥을 외곽으로 이동.
- 7층 잔재방: 낮은 좌표 작업실, 측량 장비·보관장·파티션 배치.
- 7층 보스방: 높은 천장과 좌우 복층. 복층 끝을 하강 구역 앞에서 마감.
- 6층 보스방 천장: 보스 스테이지 바로 위에 원형 개구부와 완만한 돔. 반지름 6.7m, 상승 높이 3.2m, 곡선 보강대 12개.
- 8층 보스방: 기존 평천장과 관측 링을 유지하고, 주변 기물 시야 간섭만 조정.
- 6–10층: 제공된 GLB 104종을 모두 활용. 실제 전투 카메라 위치에서 좌우 70도 회전 시야를 점검하고 측면 배치를 보강.
- 6–9층 두루마리 선택: 등장 완료 상태를 기준으로 주변 기물과 상단 여백 점검.
- 6–10층 하강: 문·비석·바닥 발판이 함께 보이도록 카메라와 주변 배치 조정.
- 10층 기존 책상 상호작용은 유지. 이 장면에는 원래 두루마리 보상 장치가 없음.

## 산출물

- `DA_F06_F07_F08_F09_F10_Combined_v038_floor6_dome.blend`: 최종 Blender 통합 작업 파일.
- `review_v038/index.html`: 층별 전체·좌우·상호작용 카메라 검토 갤러리.
- `AUDIT_v038.json`: 기물 사용·텍스처·카메라 범위·두루마리 등장 검증 결과.
- `ASSET_USAGE_v038.md`: 제공 GLB별 배치 장면 목록.

Blender 파일과 전체 검토 갤러리는 작업 공간의 `outputs/`에 보관한다. 저장소에는 수정 스크립트, 검증 결과, 대표 검토 이미지를 기록한다. 원본 GLB·PNG·동기화 자료는 수정하지 않는다. 이전 구조 중 숨김 처리된 항목은 되돌리기용으로 보존한다.

## 재현 순서

스크립트는 기존 통합 v034 장면을 전제로 하며 단계별로 한 번씩 적용한다. 재실행 시 추가 기물이 중복될 수 있다.

1. `redesign_f06_f07_v035.py`: `run('common')`, `run('residual7')`, `run('residual6')`, `run('boss7')`, `run('boss6')`.
2. `refine_f06_f07_v035.py`, `finish_f06_f07_v035.py`.
3. `dress_sides_and_interactions_v036.py`.
4. `dome_and_clearance_v037.py`, `refine_camera_views_v037.py`, `final_sightlines_v037.py`.
5. `correct_dome_to_floor6_v038.py`: 최종 6층 돔 및 8층 천장 복원.
6. `audit_all_floors_v038.py`, `render_review_v038.py`, `build_review_gallery_v038.py`.

## 범위

이번 결과는 Blender 장면 수정과 카메라 검토다. 앱용 모델 내보내기·앱 연결·기기 성능 검증은 이번 산출물에 포함하지 않는다. Tripo 유료 생성은 실행하지 않았으며, 추가 기물 없이 기존 자산으로 배치했다.
