# 작은 오라와 직선 마법 발사

기준: `feat/#136-expansion-intent-vfx` (`1daf296`).
작업: `fix/#137-compact-aura-straight-projectile`.

- 행동 예고 뒤의 연기를 넓게 올라가는 기둥에서 작은 오라로 축소했다. 발생 폭 0.75→0.38m, 입자 크기 0.36→0.19m, 수명 1.7→1.15초, 상승 속도 0.48→0.13m/s, 초당 발생 22→10개다.
- 입자 투명도와 최종 확산을 낮추고, 짙은 숯색에 행동별 색상을 약하게 섞었다. 동작 줄이기의 정적 후광도 함께 축소했다.
- 공격 비행에서 포물선 오프셋을 제거했다. 카메라 오른쪽 손 위치에서 충돌 지점까지 직선으로 이동하며, 거리에 따라 0.12~0.19초가 걸린다.
- 충돌 효과 배율은 0.82→0.48로 축소했다. 잠시 부착된 뒤 떨어지는 기존 마무리는 유지한다. 충돌 뒤에는 작은 검은 연기 입자 9개만 한 번 발생하고 사라진다.
- 3D 공격의 시전음은 실제 모델 준비 후 발사 순간에, 피격음은 도착 순간에 직접 재생한다. 기존 전역 음향 큐의 해당 소리는 제외해 중복을 막는다. 비공격 주문과 2D 화면의 소리, 음소거 설정, 기존 햅틱은 유지한다.
- 효과 로딩 실패 시에는 소리를 대신 재생하고, 장면 초기화로 취소된 공격은 소리를 재생하지 않는다.

참고 요청: https://www.youtube.com/watch?v=ZhAxeK8jxpU
영상 기본 조회에 실패했고 별도 분석 요청도 대기 상태여서, 영상과 동일한 연출을 확인한 것으로 간주하지 않았다. 사용자가 설명한 작은 검은 연기와 빠른 직선 발사를 기준으로 조정했다.
