# 5~7층 지속 상태 효과

기준 브랜치: `fix/#137-compact-aura-straight-projectile`.
작업 브랜치: `feat/#138-combat-status-effects`.

`RealityCombatStatusRenderer`가 현재 `BattleState`를 읽어 적의 지속 상태를 표시한다. 이벤트 이름에 의존하지 않으며 전투 갱신·초기 설치·체크포인트 복원에서 같은 경로를 사용한다. 적 머리 위 행동 예고와 기존 방벽은 유지한다.

| 상태 | 표현 |
|---|---|
| 인과 증폭 | 등 뒤의 주황 동심원과 상승선. 예약 등록 시 예약 표식 방향으로 수렴하며 소멸 |
| 교정 방벽 유지 | 몸 앞쪽의 청록 축선. 방벽이 없어지면 소멸 |
| 원본 보존 | 몸 주변의 작은 연보라색 조각 8개 |
| 출력 저하 | 가슴 앞의 청록 억제 고리 |
| 모사 기록 | 어깨 옆의 실제 기록 주문 문양. 재사용 시 더 선명하게 맥동 |
| 모사 금지 | 기록 위치의 보라색 교차 봉인선 |
| 예약 피해 | 가까운 집행 순서로 작은 모래시계 최대 3개. 임박 시 빨강, 지연 시 청록 고리 |
| 플레이어 약화 | 시전 손 쪽의 보라색 균열과 공격 카드의 점선 테두리 |
| 주문 봉인 | 해당 카드의 교차 사슬과 자물쇠. 기존 선택 제한 유지 |
| 플레이어 피해 감소·다음 턴 방벽 | 시전 손 쪽의 청록 보호선 |
| 연쇄 공격 강화 | 시전 손 쪽 주황 불빛과 공격 카드 테두리 |

정확한 피해·턴·주문명 및 3개를 초과한 예약은 기존 상태 UI에서 확인한다. 지속 효과는 작은 범위에서 낮은 밝기로 맥동하며, 새로 생길 때 나타나고 사라질 때 짧게 수렴한다. 상태 변경 직후 재등장하면 제거 중인 객체를 복구한다. 일시정지 및 동작 줄이기에서는 맥동을 중지한다. 승리·패배·준비 상태·장면 초기화에서는 3D 상태 객체와 작업을 정리한다. 플레이어 효과는 입력을 가로채지 않는다.

검증 범위: 시뮬레이터 Debug 빌드, 변경 파일 형식 확인. 실제 플레이에서 보스별 가림·카메라 회전·상태 중첩·모바일 성능 확인은 후속 시각 검토 대상이다.
