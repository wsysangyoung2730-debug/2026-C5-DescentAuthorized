## 1. 확정 방향과 상세 시험안

4~1층은 이미 배운 전투 규칙을 조합하며 주인공의 책임과 자발적 봉인을 밝혀 가는 후반부다. 각 층은 잔류체 두 개체와 차례로 싸운 뒤 관리자를 상대한다. 하강 승인은 층의 업무에 맞는 문양 세 단계를 거친다.

| 구분 | 상태 |
|---|---|
| 층마다 서로 다른 잔류체 2개체와 순차 전투 | 사용자 확정. 동시 2체 전투 아님 |
| 각 층 잔류체 2회 + 관리자 1회, 총 12전 | 확정된 순차 전투를 적용한 구성안 |
| 하강문 독립 문양 3개, 층마다 다른 특징 | 사용자 재확인. 각 단계 성공 개별 저장 |
| 플레이어 턴당 획수 증가 + 보스 체력·공격 패턴 강화 | 사용자 확정. 두 가지를 함께 적용 |
| 4~1층 모두 턴당 3획 | 사용자 재확인. 잔류체·관리자 전투 모두 적용 |
| 전투에 가져가는 금서 최대 2종 | 사용자 재확인. 전체 출전 6칸 안에 포함하며 추가 슬롯 아님 |
| 학습한 금서는 보관, 전투 준비에서 최대 2종 선택 | 출전 제한을 적용하는 운영 기준. 봉인 주문서는 금서 제한에 포함하지 않음 |
| 신규 2획 공격·방어와 봉인 주문서 추가 | 사용자 보완 요청 반영. 개별 명칭·효과·수치는 시험안 |
| 책임 심사 → 자발 격리 → 봉인 유지 → 최종 승인 | 서사·미술 콘셉트 제안. 사용자 선택 전 |

문서의 신규 명칭·수치·보상 배치는 모두 제안이다. 사용자 확정 항목과 기존 기준을 제외한 내용은 실제 구현 상태를 뜻하지 않는다.

## 2. 확인한 기존 기준과 충돌 방지

- GitHub의 [7~5층 임시안](https://github.com/wsysangyoung2730-debug/2026-C5-DescentAuthorized/blob/develop/docs/releases/1.0/FLOORS_7_5_PROVISIONAL.md)에도 4~1층은 잔류체 2종·관리자 1종·하강 승인 3단계라는 방향이 있다. 다만 해당 문서는 임시안이며 4~1층 상세 기획이 확정되었다는 뜻은 아니다.
- 진행·편성은 [7~5층 플레이 기준 v3](https://github.com/wsysangyoung2730-debug/2026-C5-DescentAuthorized/blob/develop/docs/expansion/Floors_7_5_Gameplay_Design_v3.md)를 이어받는다. 최대 6종, 봉인 해제 필수, 공격·방어 최소 1종, 전투 중 교체 없음, 기본 대응 주문 보호가 기준이다. 이 문서의 2획 규칙은 5층까지의 기준이며, 여기서는 4층 이후 변경을 별도 제안한다.
- 기존 주문과 금서 ‘모사 금지’는 [주문 20종 명세 v2](https://github.com/wsysangyoung2730-debug/2026-C5-DescentAuthorized/blob/develop/docs/expansion/Spell_Catalog_20_Proposal_v2.md)를 유지한다. 오래된 PRD의 편성 규칙이나 주문 효과로 되돌리지 않는다.
- [서사 명세](https://github.com/wsysangyoung2730-debug/2026-C5-DescentAuthorized/blob/develop/docs/NARRATIVE.md)의 핵심인 ‘주인공의 자발적 봉인’, ‘탑은 균열을 분산·지연’, ‘1층 다음은 다른 탑의 10층’을 유지한다. 제0균열을 지하 0층으로 해석하지 않는다.

초안 작성 때 근거 문서를 2026-09-22 GitHub `develop`에서 읽었으며, 이번 보완은 보관된 초안과 로컬 문서를 기준으로 한다. 원격의 최신 변경을 다시 검증한 것은 아니다. 서사 문서는 초기 데모 중심이므로 후반 층의 구체적인 적 이름·업무 구역은 본 문서에서 제안한다. 기존 확장 범위가 5층 보상과 4층 진입까지라는 점과, 4층 전투가 이미 완성되었다는 주장을 구분한다.

## 3. 공통 진행과 성장

### 3.1 층별 흐름

층 진입·짧은 기록 → 잔류체 A 준비·전투 → 짧은 조사·회복 → 잔류체 B 준비·전투 → 중간문 해제 → 관리자 준비·전투 → 보상 → 하강 승인 1·2·3 → 다음 층.

- 두 잔류체는 별도 조우다. 각 조우 직전 편성을 변경할 수 있고, 전투 시작 후에는 고정한다.
- 잔류체 A는 그 층의 판단 하나를, B는 다른 판단 하나를 보여준다. 관리자는 둘을 조합한다.
- 잔류체 방은 한 공간을 두 조사 구역으로 나누는 구성을 우선한다. 두 번 싸운다고 보스방처럼 큰 방을 두 개 추가하지 않는다.
- 보스방으로 가는 중간문은 하나만 둔다. 잔류체 A·B를 모두 해결해야 해제 가능하다. 잔류체 방에 하강문·하강봉인석·보상 받침대를 추가하지 않는다.
- 4·3층의 잔류체 이후 추가 주문 선택은 조사한 기록의 해독 화면으로 제공한다. 보스방의 두루마리 선택 받침대와 구분한다.
- 보스방에는 입력판, 두루마리 선택 받침대, 하강봉인석, 봉인된 하강문을 둔다. 1층 받침대는 신규 전투 주문 대신 최종 기록을 전달한다.

### 3.2 확정 획수와 보스 강화 시험값

4층 진입 때 턴당 기본 획수를 2획 → 3획으로 늘린다. 이후 1층까지 3획을 유지하며 잔류체와 관리자 전투에 동일하게 적용한다. 사용자 재확인으로 확정한 진행 규칙이다.

3획으로 가능해지는 대표 판단은 ‘2획 공격 + 1획 방어’, ‘해제 + 공격 + 방어’, ‘공격 연계 2회 + 방어’다. 모든 턴에 반드시 세 주문을 제출해야 한다는 뜻은 아니다. 추가 획은 턴 시작 기본 한도이며 성공 보상으로 획을 환급하는 시스템이 아니다.

마나도 함께 검토해야 한다. 기존 권장 문양 예산으로 집속 파열 85 + 초급 방벽 32 = 117이어서, 획만 3으로 올리고 마나를 100으로 유지하면 기대한 연계가 막힐 수 있다. 따라서 4층부터 턴당 마나 150을 시험값으로 제안한다. 이 증가는 사용자 확정 사항이 아니며, 실제 소모는 고정 주문 가격이 아니라 그린 선 길이에 따른다.

| 층 | 잔류체 A / B HP 시험값 | 관리자 HP 시험값 | 관리자 목표 경험 |
|---|---:|---:|---|
| 4층 | 190 / 220 | 600 | 3획 연계 입문, 반격을 피할지 감수할지 선택 |
| 3층 | 210 / 240 | 660 | 일부 주문이 제한되어도 남은 구성으로 연계 |
| 2층 | 230 / 260 | 720 | 복수 피해·강화·반격의 도착 순서 판단 |
| 1층 | 250 / 280 | 800 | 익숙한 규칙의 최종 종합, 세 업무 단계 전환 |

위 HP는 밸런스 시작점일 뿐 확정값이 아니다. 초안 작성 때 확인한 `feat/#139-enemy-attack-defeat-motion`의 5층 관리자 HP 450을 비교점으로 삼았다. 일반적인 공격·방어 혼합 구성에서 관리자 약 9~12턴을 우선 목표로 검토하고, HP만 높여 같은 패턴을 오래 반복하게 되면 HP부터 낮춘다. 약한 초기 주문 위주 구성의 장기전도 따로 확인해야 한다.

균열 절단 두 번으로 턴당 56~80 피해를 주는 단순 계산에서는 HP 600은 약 8~11턴, HP 800은 약 10~15턴이다. 실제로는 해제·방어막 대응 턴이 더해지므로 특히 2·1층 HP는 하향 조정 가능성이 있다. 방어막 상한은 일반 40을 유지하며, 필수 생존을 금서 한계 방벽의 60에 맞추지 않는다. 세 번 방어한다고 상한이 세 배가 되지 않는 점도 안내한다.

보스 강화는 큰 예고 공격, 분할 공격, 반응형 추가타, 제한된 주문과 예약의 조합으로 표현한다. 공격력 일괄 배수나 예고 없는 즉사 공격은 넣지 않는다. 필수 해제·방어가 동시에 요구되면 획뿐 아니라 실제 마나까지 해당 턴 안에서 충분해야 한다.

사용자는 ‘획수 증가와 보스 강화’를 함께 적용하고 4~1층 턴당 3획을 사용하는 구성을 재확인했다. 마나 150·위 HP 수치는 아직 시험값이므로 전투 길이와 생존 여유를 확인한 뒤 확정한다.

### 3.3 전투 공정성

- 공격·방어 기본 대응 1종씩과 봉인 해제는 적의 카드 봉인에서 보호한다. 특정 기본 주문 이름을 강제하지 않는다.
- 금서·정화·예약 취소를 선택하지 않은 경로도 통과할 수 있어야 한다. 일반 공격·방어와 빈틈 이용이 기본 해법이다.
- 2획 공격만 장착한 구성에도 공격 가능한 안전한 턴을 제공한다.
- 예약은 등록 시점에 피해와 집행 시점을 공개한다. 취소된 예약 자리에 새 공격을 채워 넣지 않는다.
- HP 단계 전환은 다음 패턴 주기부터 적용한다. 이미 예고된 공격의 수치를 기습적으로 올리지 않는다.
- 반격은 조건과 최대 발동 수를 사전 표시한다. 사용자 입력 도중 갑자기 HP를 깎지 않고 예고된 적 행동 단계에서 처리한다.
- 적을 처치하면 남은 적 행동·예약·모사·반격을 취소한다.
- 3획 집중 공격으로 잔류체가 2~3턴에 쓰러질 수 있다. 핵심 행동은 첫 1~2턴에 배치하고, 빠르게 처치했을 때 강제로 살아남게 하지 않는다. 놓친 안내는 다음 해당 상황으로 이어 간다.
- 보스 강화의 대가로 입력 제한 시간, 화면 뒤집기, 숨겨진 문양 판정 오차를 추가하지 않는다.

## 4. 층별 콘셉트와 전투

### 공통 전투표 읽는 법

- `Pn`은 해당 주기의 n번째 플레이어 행동, `En`은 그 직후 적 행동이다. `P1 → E1 → P2 → E2 … P5 → E5`로 진행하며 관리자 주기는 기본 5턴이다. 실제 전투 턴 번호는 누적한다. 두 번째 주기의 E4는 실제 전투 9턴째다.
- 각 P 시작 전에 해당 E의 즉시 피해, 도착 예약별 피해·순서, 조건부 추가타 최대값을 보여준다. 준비 실행 전에도 다음 턴 봉인 후보·반격 조건·증폭량을 숨기지 않는다.
- 피해 순서는 일반 즉시 공격 → 도착 예약(등록순) → 모사 추가타·반격 → 효과 만료다. `24 + 24`는 두 번의 별도 피해이지 48 한 번이 아니다. 보호 효과·방어막을 각 건마다 계산한다.
- 예약 등록 행에는 즉시 피해가 없으면 `0`으로 표기한다. 예약의 피해·도착 E·분할 건수는 등록 시 고정한다. 이후 적 버프를 지워도 확정 예약은 바뀌지 않는다. 취소된 예약을 다른 공격으로 보충하지 않는다.
- 일반 방어막은 턴 종료로 사라지지 않고 상한 내에서 이월된다. 적 방어막에는 별도로 표기한 만료 시점을 적용한다.
- 4·1층 ‘서명 모사’는 E1에서 P1의 마지막 성공 주문 ID를 기록한다. P2에서 같은 ID를 한 번이라도 성공하면 E2에서 정해진 추가 피해를 한 번 주고 기록은 E2 종료에 소멸한다. P1 성공 주문이 없으면 기록하지 않는다. 원주문 효과·HP 대가를 복제하지 않으며 기존 5층 카테고리별 모사 규칙을 소급 변경하지 않는다.
- 반격은 준비 다음 P에서 공격 주문을 한 번 이상 성공하면 지정 E에서 최대 한 번 발생한다. 다단 공격·반복 시전도 횟수를 늘리지 않는다. 해당 E 전에 모사 금지로 준비를 제거하면 이미 만족한 발동 조건도 취소한다.
- 보호 공격·보호 방어·봉인 해제는 카드 봉인 대상에서 제외한다. 후보가 부족하면 가능한 수만, 0종이면 봉인 없이 진행한다. 봉인 선택에 시간제한을 두지 않는다.
- HP 조건을 P 중 만족해도 현재 주기의 예고를 끝낸 뒤 다음 주기에 강화한다. 4층은 HP ≤300, 3층은 ≤330, 2층은 ≤432에서 강화한다. 2층은 기본 공격 경로에서 강화 구간을 거의 보지 못하는 문제를 줄이려고 초안의 50%에서 60%로 앞당긴 시험안이다.
- 처치 시 모든 적 행동·예약·반격·모사를 취소한다. 단계별 HP 재충전·HP 1 고정·무적으로 조기 처치를 막지 않는다. 강한 구성은 일부 후반 패턴을 보지 않고 승리할 수 있다.
- 현재 예약표는 모두 E4까지 도착하고 집행 지연을 한 번 적용해도 E5까지 처리된다. 지연은 예약당 전투 전체에서 한 번만 허용한다. 이후 확장이나 저장 복원으로 주기 끝에 미래 예약이 남으면 새 주기·단계 시작을 미루고 원래 집행 시점을 유지하는 무피해 정리 턴만 진행한다. 정리 중 새 예약·봉인·즉시 공격을 만들지 않으므로 무한 지연이나 단계 전환에 의한 위협 삭제가 발생하지 않는다.

아래 피해는 방어·감소 적용 전 시험값이다. 공격을 멈추면 피할 수 있는 조건부 반격과 기본 피해를 구분한다. 금서 없는 구성에 60 피해를 반드시 받아내도록 요구하는 설계가 아니다.

### 4층 — 책임 심사실

질문: ‘내가 만든 절차가 누구에게 어떤 책임을 남겼는가?’ 5층에서 되찾은 기억을 업무의 책임과 연결한다. 이미 알려진 ‘설계자였다’를 다시 반전처럼 반복하지 않는다.

- 공간: 검수 창구, 거대한 인장, 반려 문서 운반대, 기울어진 저울. 검은 철·탁한 황동·적색 승인등.
- 새 사실 제안: 봉인을 유지하는 대가로 책임자의 기억이 손실될 수 있는 안전장치를 주인공이 직접 승인했다. 설계자 신원 재확인이 아니라 자신이 승인한 구체적인 대가를 밝힌다. 이 세부 설정은 기존 문서의 확정 사실이 아닌 신규 콘셉트다.
- 기록 예시: “기억 손실 위험 고지 완료. 책임자 승인 유지.”

| 상대 | 가칭 | 패턴과 대응 |
|---|---|---|
| 잔류체 A | 서명 모사 잔류체 | 마지막 성공 주문 기록 → 같은 주문 재사용 시 모사 추가타 → 기록 소멸·빈틈. 다른 주문을 섞거나 방어로 감수한다. 5층 규칙을 3획 연계에 연결한다. |
| 잔류체 B | 반려 집행 잔류체 | 반격 준비 → 다음 플레이어 턴 공격 주문 성공 시 반격 1회 → 집행 후 빈틈. 공격 횟수와 무관하게 추가타는 최대 1회. 방어·준비에 쓰거나 공격 후 받아낸다. |
| 관리자 | 책임 심사 관리자 | 서명 채취 → 원본 대조 공격 → 반격 준비 → 반려 집행 → 판결 정리. HP 절반 이후 다음 주기부터 기본 공격과 반격의 압력을 올린다. 모사와 반격을 처음부터 같은 턴에 겹치지 않는다. |

모사 금지는 모사·반격 준비와 발동을 막는 선택적 해법이다. 일반 공격 전체를 막는 침묵으로 확대하지 않는다. 모사 금지가 없어도 모사 회피와 반격 준비 턴을 활용할 수 있다.

#### 책임 심사 관리자 — HP 600 / 300 이하에서 다음 주기 강화

|---|---|---|---|---|
| E1 | 서명 채취 | 일반 12, P1 마지막 성공 주문 기록 | 일반 16, 동일 기록 | 방어를 포함해 다음 턴과 다른 주문을 마지막에 사용 |

### 3층 — 자발 격리구역

질문: ‘누가 나를 가뒀는가?’에 ‘내가 동의했다’는 답을 준다. 다만 강제된 선택지처럼 연출하지 않고, 왜 동의했는지는 다음 층으로 남긴다.

- 공간: 투명 격리벽, 내부를 향한 잠금쇠, 동의서 보관대, 빈 개인실. 차가운 백색·옅은 청색.
- 새 사실: 외부 강제 수용 명령이 아니라 주인공의 자발적 격리 동의가 있었다.
- 기록 예시: “격리 요청자와 대상자 동일. 외부 강제 명령 없음.”

| 상대 | 가칭 | 패턴과 대응 |
|---|---|---|
| 잔류체 A | 동의 보관 잔류체 | 보호되지 않은 주문 중 2종을 제시 → 플레이어가 1종을 선택해 다음 플레이어 턴 동안 봉인 → 약한 집행. 선택하지 않고 전투를 멈추게 하는 시간제한은 없다. 대상 1종이면 그 1종, 0종이면 봉인 없이 약한 공격만 처리한다. |
| 잔류체 B | 격리 집행 잔류체 | 작은 즉시 공격 → 서로 다른 턴에 도착하는 예약 2건 → 집행 → 무피해 점검. 예약의 순서를 읽고 방어를 나눈다. |
| 관리자 | 자발 격리 관리자 | 동의 대상 제시·카드 봉인 → 집행 예약 → 경고 공격 → 예약 집행 → 봉인 해제·기록 정리. HP 절반 이후 다음 주기부터 일부 예약 2건이 같은 단계에 도착하도록 사전 예고한다. |

동의 선택은 전투 자원 선택이지 엔딩 분기 선택이 아니다. 정화로 봉인을 먼저 풀 수 있지만 필수는 아니다. 보호 주문이 남아 있으므로 금서나 해제 보상이 없어도 방어할 수 있어야 한다.

#### 자발 격리 관리자 — HP 660 / 330 이하에서 다음 주기 강화

| 순서 | 행동 | 전반 피해·효과 | 강화 후 피해·효과 | 기본 대응 |
|---|---|---|---|---|
| E1 | 동의 대상 제시 | 피해 0. 보호 외 장착 순서 앞의 최대 2종 중 1종을 플레이어가 선택, P2~P4 봉인 | 동일 | 보호 역할은 남김. 대상 1종이면 그 주문만 선택 가능 |

봉인은 E1 직후 시작해 P2·P3·P4에 적용하고 E4 종료에 해제한다. 예약을 지연해도 봉인 만료는 연장하지 않는다. 전반 A를 지연하면 E4에 16+16, 강화 후 B만 지연하면 E4에 20·E5에 24가 도착한다. 집행 무효는 같은 단계의 두 예약을 취소하지만 전투당 성공 1회·HP 10 대가가 있어 매 주기 필수 해법으로 삼지 않는다.

### 2층 — 봉인 유지기관

질문: ‘왜 스스로 남았는가?’ 탑이 균열을 없애는 장치가 아니라 분산·지연하는 장치이며, 주인공의 승인 절차가 유지에 필요함을 확인한다.

- 공간: 깊은 배관, 균열 에너지 분배기, 균형추, 봉인 유지 코어. 검은 금속·청록 냉각광·주황 과부하광.
- 새 사실: 주인공의 승인이 있어야 유지 업무를 다음 구간에 인계할 수 있다.
- 기록 예시: “균열 폐쇄 불가. 책임자 승인 후 분산 유지.”

| 상대 | 가칭 | 패턴과 대응 |
|---|---|---|
| 잔류체 A | 과부하 잔류체 | 출력 증폭 버프 → 강화 예약 등록 → 누출 공격 → 예약 집행. 등록 전 강화 제거와 등록 후 예약 대응이 다름을 재확인한다. |
| 잔류체 B | 역류 차단 잔류체 | 보통 방어막과 반격 준비 → 방어막이 남으면 역류 공격 강화 → 냉각 빈틈. 방벽 파괴, 반격 차단, 방어 중에서 선택한다. 준비 행동 자체에는 피해가 없다. |
| 관리자 | 봉인 유지 관리자 | 출력 분배 → 큰 예약 확정 → 작은 즉시 공격 → 예약 집행 → 냉각. HP 60% 이하의 다음 주기부터 단일 강타와 2연타를 번갈아 예고하며, 집행 직전 구간에 반격 준비를 넣는다. |

증폭은 무한 누적시키지 않는다. 예약에 반영된 수치는 이후 버프를 지워도 소급해서 낮아지지 않는다. 큰 타격과 작은 선행 타격을 구분해 피해 감소가 어디에 소비되는지 보여준다. 모사 금지를 택했던 진행은 역류 반격에 계속 활용할 수 있다.

#### 봉인 유지 관리자 — HP 720 / 432 이하에서 다음 주기 강화

| 순서 | 행동 | 전반 피해·효과 | 강화 후 피해·효과 | 기본 대응 |
|---|---|---|---|---|
| E1 | 출력 분배 | 피해 0. 다음 등록 예약 묶음 총피해 +8 | 피해 0. 총피해 +12 | 다음 P2에 정화 가능, 없는 구성은 강화값에 대비 |
| E2 | 큰 예약 확정 | 피해 0. 기본 32→증폭 시 40을 E4에 등록 | 첫 강화 주기 단일 기본 36→48. 다음은 기본 18+18→24+24. 이후 교대, 모두 E4 도착 | 예약 건수·종류·최종 피해 공개 |
| E3 | 누출 경고 | 일반 8 | 일반 8 + 반격 준비, P4 공격 성공 감시 | 작은 공격 뒤 방어막 잔량 확인 |
| E4 | 유지 집행 | 예약 40 또는 정화한 경우 32 | 예약 합계 48 또는 정화 시 36, 이후 공격 성공 시 반격 12. 최대 60 | 공격을 쉬면 반격 없음. 일반 방어막 40이면 강화 예약 HP 손실 8 |
| E5 | 냉각 | 피해 0 | 동일 | 집중 공격·방어 비축 |

증폭은 E2 예약 묶음에 한 번 적용하고 소모하며, 남아도 E2 종료에 소멸한다. 분할 묶음은 +12를 두 건에 +6씩 적용한다. 버프는 정화 대상이며 중첩하지 않는다. 반격 준비는 E4 종료에 소멸한다. 강화 주기의 홀짝은 단계 진입 시 단일로 시작하고 완료 주기마다 뒤집으며 예약 취소 여부와 무관하다.

강화 후 E4의 ‘48+12’는 공격했을 때만 발생한다. 기본 경로는 P4를 방어에 사용해 48을 받고 무피해 E1·E2·E5에 공격한다. 별도 주문은 이를 공격적으로 바꾸는 선택이지 생존 필수 조건이 아니다. 출력 저하는 단일 48에는 전부 적용되지만 24+24에는 첫 24에만 적용되므로 예고를 구분할 이유가 생긴다.

### 1층 — 최종 승인청

질문: ‘이제 나갈 수 있는가?’ 외부로 이어지는 듯한 질서 정연한 로비에서, 실제로는 다음 탑으로 업무가 인계된다는 반전을 마무리한다.

- 공간: 출구 표식, 비어 있는 접수석, 정렬된 문서함, 하강문 틈의 창백한 빛. 상층보다 단정한 공간이 주는 이질감.
- 새 사실: 이 탑의 하강 완료는 탈출이 아니라 다음 탑으로의 인계다. 문이 열리기 전 대사로 먼저 누설하지 않는다.
- 문 개방 이후 기록 예시: “인계 완료. 제10층에서 절차를 재개하십시오.”

| 상대 | 가칭 | 패턴과 대응 |
|---|---|---|
| 잔류체 A | 신원 대조 잔류체 | 모사 기록과 공격을 번갈아 사용. 마지막 전투에서 쓸 주문 순서를 확인한다. |
| 잔류체 B | 퇴거 심사 잔류체 | 일반 방어막 준비 → 강타 예약 → 집행 → 무피해 정리. 문 해제·방어막·예약을 혼동하지 않는지 확인한다. |
| 관리자 | 최종 승인 관리자 | 하나의 HP 막대 안에서 신원 심사 → 유지 심사 → 인계 심사로 전환한다. HP 70%·35% 이하에서 각각 다음 주기부터 전환하며 HP를 재충전하지 않는다. |

관리자의 세 업무 단계:

1. 신원 심사: 모사와 반격을 교대로 사용한다. 두 잔류체보다 피해와 조합 판단을 강화한다.
2. 유지 심사: 예약 피해와 보호되지 않은 주문 1종 봉인을 조합한다. 절대 방어막은 이 단계 시작에 한 번만 만들며, 생성 행동에는 피해를 주지 않고 별도의 해제 기회를 제공한다.
3. 인계 심사: 예고한 분할 공격과 단일 강타를 교대한다. 봉인 대상은 최대 2종이지만 보호 주문은 그대로 남는다. 신규 규칙·신규 자원을 더하지 않는다.

#### 최종 승인 관리자 — HP 800 / 560·280 이하에서 다음 주기 전환

| 단계 | E1 | E2 | E3 | E4 | E5 |
|---|---|---|---|---|---|
| 1. 신원 심사 | 일반 12 + P1 마지막 성공 주문 기록 | 일반 20 + 조건부 모사 8 | 피해 0, 반격 준비 | 일반 24 + P4 공격 성공 시 반격 16, 최대 40 | 피해 0, 기록 정리 |
| 2. 유지 심사 | 피해 0, 보호 외 주문 1종 봉인. 이 단계 최초 E1에만 절대 방어막 1중첩 생성 | 피해 0, 예약 A 16·B 16을 E4에 등록 | 일반 8 | 예약 A 16 → B 16, 합계 32 | 피해 0, 기록 정리 |
| 3. 인계 심사 | 피해 0, 보호 외 주문 최대 2종 봉인 | 일반 분할 24 → 24, 합계 48 | 피해 0, 중간 점검 | 일반 단일 44 | 피해 0, 최종 기록 정리 |

- 단계 전환은 순차적으로 1→2→3이며 HP를 회복하지 않는다. 한 주기에 두 문턱을 모두 넘겼다면 다음 주기는 2단계, 그 다음 완료 주기부터 3단계다. 그 전에 처치하면 그대로 승리한다.
- 1단계 모사·반격의 조건·만료는 4층과 같다. 2·3단계 봉인 대상은 E1 예고를 만들 때 보호 외 장착 순서 앞의 1종/2종으로 고정해 P1 시작 전에 보여준다. 무작위 변경하지 않는다. 적용 기간은 P2~P4, E4 종료 해제다.
- 2단계 최초 E1의 절대 방어막은 1중첩이다. 다음 P2에는 즉시·도착 피해가 없으므로 보호된 봉인 해제 1획으로 제거하고 남은 2획으로 공격·방어할 수 있다. 미해제 방어막은 유지되지만 재생성·단계 전환 자동 삭제는 없다.
- 2단계 예약 두 건은 등록 시 모두 예고한다. 집행 지연으로 E5에 남아도 등록 순서를 유지하며 E5 집행을 마친 다음에만 새 단계를 시작한다. 예외적인 미래 예약은 공통 정리 규칙을 적용한다.
- 3단계는 방어막 40만으로 분할 공격에서 HP 8, 단일 강타에서 HP 4, 한 주기 최대 12를 감수하는 시험 설계다. 금서 두 개가 필수인 것이 아니라 무피해 E1·E3·E5의 공격과 이미 배운 방어·감소 주문 활용을 요구한다.
- HP 280 이하인 3단계에서 2획 최소 피해 34 주문을 무피해 턴마다 한 번만 사용해도 한 주기 102, 최대 세 주기에 처치 가능하다. 이 구간만의 보수적 강제 피해 상한은 36이며 전반에서 소모한 HP와 별도로 계산한다. 전체 생존·전투 길이 검토는 아래 산술 항목으로 구분한다.

### 잔류체 8종 — 독립 전투 시험 수치

잔류체에는 HP 단계 전환을 넣지 않는다. 아래 번호는 각 조우의 주기 안에서 반복한다. 처치하면 남은 예약·반격을 즉시 취소하고 다음 조우로 넘기지 않는다.

| 층·상대 | HP | 반복 주기 | 지속·상한 |
|---|---:|---|---|
| 4A 서명 모사 | 190 | E1 피해 0·P1 마지막 성공 주문 기록 → E2 일반 12+조건부 모사 8 → E3 정리 0 | E2 종료 기록 소멸, 추가타 최대 1회 |

| 3A 동의 보관 | 210 | E1 보호 외 장착 순서 앞의 최대 2종 중 1종 선택 봉인·피해 0 → E2 일반 14 → E3 정리 0 | P2에만 봉인, E2 종료 해제 |

잔류체의 짧은 주기는 무조건 장기전으로 만들지 않는다. 핵심 규칙을 먼저 보여주고 3획 연계로 일찍 처치하는 것을 허용한다. 두 조우를 연속으로 통과하는 과정과 A·B 사이 회복은 별도 플레이 검증 대상이다.

### 수치 검토의 범위 — 산술 경로와 플레이 테스트 구분

플레이어 3획·마나 150, 시작 HP 60, 초급 방벽 성공 최소값 20·이월 상한 40, 기본 공격만 사용하는 경로를 검토한다. 금서·정화·예약 취소·출력 저하·신규 봉인 주문은 사용하지 않는다. 모사는 매번 발동하는 불리한 경우로 두고, 매 턴 HP 손실 최소 → 가능한 공격 횟수 최대 → 잔여 방어막 최대 순으로 행동한다. 봉인 해제는 1층 절대 방어막 직후에 1획 사용한다.

| 공격 구성 | 4층 턴/HP 손실 | 3층 턴/HP 손실 | 2층 턴/HP 손실 | 1층 턴/HP 손실 |
|---|---:|---:|---:|---:|
| 균열 절단 최소 성공: 1획·28 | 11 / 0 | 10 / 4 | 11 / 8 | 13 / 8 |
| 잔광 말소 최소 성공: 1획·18 | 17 / 0 | 15 / 4 | 17 / 8 | 20 / 12 |
| 방벽 관통 최소 성공: 2획·34 | 20 / 0 | 20 / 8 | 25 / 24 | 24 / 8 |

이 결과는 실패 없는 단순 산술 경로이며 게임 엔진·입력·UI·실기기 테스트가 아니다. 보호 역할이 봉인되지 않는다는 전제로 비보호 주문 봉인은 단순화했고, 감소 효과가 없으므로 분할 피해는 생존 합계로 계산했다. HP 대가·사용 횟수 제한·특수 주문 편성 효과는 아직 검증하지 않았다.

- 기본 공격·방어만으로 생존하는 경로가 있어 금서가 필수는 아니라는 출발점은 확인한다. 다만 실패·선 길이 초과를 여러 번 해도 충분히 버틴다는 보장은 아니다.
- 초기 공격이나 약한 2획 공격만 사용하는 경우 15~25턴으로 길어진다. 표준 목표 약 9~12턴과 다르므로 전투 길이 적정성은 미완료다. 실플레이에서 지나치게 지루하면 HP부터 낮추며 공격을 더 위험하게 보상 조정하지 않는다.
- 강한 2획 공격과 새 봉인 방어 경로, 금서 1종/2종 경로, 저HP 재편성 경로는 별도로 비교한다. 위 표를 전체 밸런스 검증 통과로 표시하지 않는다.

## 5. 하강 승인 문양 — 각 층 3회

세 문양은 각각 독립된 입력이다. ‘3단계 승인’과 ‘턴당 3획’은 다른 규칙이다. 문양 한 개는 1~2획을 우선하고 전체를 하나의 긴 문양으로 이어 그리게 하지 않는다.

| 층 | 1단계 | 2단계 | 3단계 | 도형 콘셉트 |
|---|---|---|---|---|
| 4층 | 서명 대조 | 책임 계승 | 집행 승인 | 대칭 축 → 저울의 두 접점 → 아래쪽 인장 닫기 |
| 3층 | 대상 확인 | 격리 동의 | 잠금 인계 | 열린 사각 경계 → 안으로 들어가는 선 → 경계 닫기 |
| 2층 | 분산 접속 | 기준 고정 | 유지 인계 | 갈라지는 흐름 → 중앙 고정점 → 세 흐름 재접속 |
| 1층 | 신원 승인 | 퇴거 승인 | 최종 인계 | 익숙한 상층 기호 복원 → 출구 방향 연결 → 마지막 승인 인장 |

- 도형은 시각 콘셉트다. 최종 좌표·획순·허용 오차는 별도 문양 명세에서 확정한다.
- 각 단계 첫 진입 때 패드에 정답 획순을 한 번 시연하고 사용자가 그리기 시작하게 한다. 시작점·방향·다음 획 시작을 구분한다.
- 정확한 핵심점을 지날 때 기존 효과음·시각 피드백을 사용한다. 같은 점에서 떨며 중복 음이 나지 않게 한다.
- 성공 단계는 즉시 저장한다. 3단계 실패나 앱 재실행 때문에 1·2단계를 다시 그리지 않는다.
- 실패는 현재 문양만 초기화하며 HP·마나를 차감하지 않는다. 시간제한 없음. 시연 다시 보기 제공.
- 완료한 문은 자동으로 다시 잠기지 않는다. 1층은 세 단계 완료 후 다른 탑의 10층을 보여주며 이번 완결 구간을 끝낸다.

## 6. 신규 주문·등급·보상

금서는 공격·방어·해제·디버프와 별개의 다섯 번째 분류가 아니라 기존 네 분류에 속하는 희귀 등급이다. 기존 20종에 금서 4종과 봉인 주문서 4종을 더해 전체 카탈로그 28종을 제안한다. 한 진행에서 28종을 전부 얻는다는 뜻은 아니다.

### 6.1 금서 출전 최대 2종 — 확정 제한

- 배운 금서는 잊거나 버리지 않고 보관한다. 제한은 출전 주문 최대 6종 중 금서 최대 2종이다.
- 봉인 주문서는 별도 등급이므로 금서 2종 제한에 포함하지 않는다. 다만 동일한 전체 출전 6칸을 사용한다.
- 세 번째 금서를 장착하려면 교체할 기존 금서를 사용자가 고른다. 자동 교체·자동 소각 없음.
- 봉인된 금서나 사용 횟수가 소진된 금서도 해당 전투의 장착 수에는 포함한다.
- 전투 중 교체 없음. 잔류체 A·B·관리자는 별도 전투이므로 각 전투 준비에서 재편성 가능하다.
- 금서 공격·방어도 기존 최소 역할 조건에 포함한다. 특정 일반 주문을 새로 강제하지 않는다.
- 다만 HP 대가형 주문만 해당 역할로 편성하면 낮은 HP에서 사용할 수 없으므로 준비 화면에서 ‘일반 공격/방어도 함께 준비 권장’을 표시한다. 보호 지정은 카드 봉인을 막을 뿐 HP 대가까지 없애지 않는다.
- 저HP에서 필수 역할이 사용 불가능한 구성의 난이도는 별도 검토 대상이다. 금서 선택을 필수 공략 조건으로 삼지 않는다.

### 6.2 금서 효과 — 기존 1종 유지·신규 4종

표의 마나는 문양 제작 시 선 길이 예산이다. 고정 시전 가격을 뜻하지 않는다. 신규 수치는 전부 시험값이다.

| 금서 | 분류 / 획수 / 예산 | 성공 효과 | 대가·한계 |
|---|---|---|---|
| 모사 금지 — 기존 유지 | 디버프 / 1 / 38 | 현재 모사·반격 준비 제거, 이번을 포함한 적 행동 2회 동안 모사·반격 차단 | HP 6. 일반 공격·예약·카드 봉인·단계 전환을 막지 않음. 재사용은 기간 갱신, 중첩 없음 |
| 혈인 관통 — 신규 | 공격 / 1 / 46 | 일반 방어막을 무시하고 HP 피해 34~46 | HP 8. 적의 방어막 자체는 남음. 절대 방어막은 관통 불가 |
| 한계 방벽 — 신규 | 방어 / 1 / 50 | 방어막 40~50 추가. 이번 적 행동 단계까지 방어막 상한을 일시적으로 60으로 변경 | HP 8. 해당 적 행동 종료 시 잔여 방어막도 최대 40으로 축소. 반사·회복 없음 |
| 집행 무효 — 신규 | 해제 / 2 / 58 | 이미 등록되어 같은 적 행동 단계에 도착할 예약 피해 최대 2건 취소 | HP 10, 전투당 성공 1회. 한 건만 취소해도 같은 대가. 일반 공격·미등록 미래 공격에는 영향 없음 |
| 직격 금지 — 신규 | 디버프 / 1 / 44 | 다음 일반 즉시 공격의 피해 1건을 0으로 변경 | HP 8, 전투당 성공 1회. 이번을 포함한 적 행동 2회 내 미발동 시 소멸. 예약·모사 추가타·반격·카드 봉인에는 영향 없음 |

집행 무효는 취소 가능한 집행 시점과 예약 묶음을 선택 전에 보여준다. 취소할 예약이 없으면 선택 불가다. 직격 금지는 해당 일반 공격의 피해 1건만 막으며 동반 버프·봉인 같은 다른 효과까지 취소하지 않는다. 한계 방벽의 반복 사용은 방어막을 합산하되 일시 상한 60을 넘지 않고 효과 종료 시점을 연장하지 않는다.

공통 처리:

- 현재 HP가 대가보다 클 때만 사용 가능. 대가만으로 사망하는 시전은 허용하지 않는다.
- 성공 시 HP를 직접 소모한다. 방어막·피해 감소로 이 대가를 막지 못한다. 성공 후 효과 적용 전에 대가를 처리한다.
- 문양 실패는 그린 선과 획을 소비하지만 HP 대가나 성공 사용 횟수는 소모하지 않는다.
- 새 전투 시작 시 사용 횟수·임시 효과는 초기화한다. 조우 변경 자체로 HP가 100이 되지는 않는다.
- ‘집행 무효 + 직격 금지’는 예약과 일반 공격을 동시에 막는 강력한 3획 선택이지만 HP 18과 전투당 횟수를 지출한다. 새로운 3획 규칙에서는 이 조합을 포함해 평가한다.
- 새 금서에 공격 연동 회복·대가 환급·획수 환급을 넣지 않는다. 기존 기억 봉합의 전투당 성공 2회 제한도 유지한다.

### 6.3 신규 봉인 주문서 — 2획 공격 2종·방어 2종

봉인 주문서는 금서와 다른 등급이다. 네 주문 모두 HP 대가가 없고 금서 2종 제한에 포함되지 않는다. 보상 선택 후 기존 시험 각인·학습 절차를 완료하면 사용할 수 있으며, 등급 이름 때문에 별도의 봉인 해제 퍼즐을 추가하지 않는다.

| 이름 | 분류 / 획수 / 길이 예산 | 성공 효과 | 핵심 선택 |
|---|---|---|---|
| 책임 절단 | 공격 / 2 / 78 | 일반 피해 48~62. 이번 적 행동 단계의 다음 모사 추가타 또는 반격 피해 1건을 50% 감소 | 반격을 없애지 않고 일부 감수하며 공격 |
| 격리 방벽 | 방어 / 2 / 82 | 방어막 20~28. 이미 등록된 예약 피해 1건을 지정해 50% 감소 | 여러 예약 중 위험한 한 건에 방어 배정 |
| 축압 방출 | 공격 / 2 / 92 | 현재 자기 방어막 최대 16 소비. 일반 피해 42~56 + 실제 소비량의 2배 | 방어 자산을 공격으로 전환할지 결정 |
| 인계 방벽 | 방어 / 2 / 86 | 방어막 22~30. 이번 적 행동 단계의 첫 양수 피해 1건 처리 직후 방어막 18~24를 한 번 추가 | 단일 강타보다 연속 피해에 대응 |

모든 범위는 판정 등급에 따른 시험값이다. 여러 범위가 있는 주문은 같은 시전 판정 등급을 함께 적용한다. 선 길이 예산은 고정 마나 가격이 아니다.

**공통 처리**

- 두 획을 모두 완성해 성공해야 전체 효과를 적용한다. 1획만 그린 상태에는 피해·방어막·감소·전환 효과가 없다. 실패 시 이미 그린 선과 획만 소비한다.
- 공격은 적 일반 방어막부터 깎고 초과분만 HP에 적용한다. 일반 방어막을 관통·자동 삭제하지 않는다. 적 절대 방어막이 있으면 두 공격의 부가 효과와 자기 방어막 전환도 적용하지 않는다.
- 방어 주문은 적의 절대 방어막과 무관하게 자신에게 사용할 수 있다. 현재·추가 방어막 모두 일반 상한 40을 지킨다. 금서 한계 방벽을 함께 사용한 경우에만 그 주문의 일시 상한 60을 따른다.
- 신규 50% 감소가 다른 비율 감소와 겹치면 신규 효과는 기존 비율 감소가 적용된 피해에 50%를 곱한다. 예: 출력 저하 25%와 함께 적용하면 원피해 × 0.75 × 0.5. 같은 신규 주문의 감소를 여러 겹 쌓을 수는 없다. 비율 감소 → 고정 감소 → 0 이상 제한·반올림 → 방어막 → HP 순서를 유지한다.
- 새로운 감소 효과는 지정된 피해 1건에서만 소비한다. 일반 공격, 예약, 모사, 반격의 종류를 혼동하지 않는다. 공격 전체를 취소하거나 동반 봉인·버프까지 제거하지 않는다.
- 전투 종료 시 미사용 임시 효과를 제거한다. 카드 봉인은 이후 시전만 막으며 이미 성공해 만든 자기 보호 효과를 소급 취소하지 않는다.

**책임 절단**

- 현재 적에게 즉시 피해를 주고 자기 보호 효과를 등록한다. 이번 적 행동 단계에서 먼저 도착한 모사 추가타 또는 반격 1건만 절반으로 줄인다. 해당 피해가 없으면 그 단계 종료 시 소멸한다.
- 같은 주문을 재사용하면 피해는 다시 주지만 보호 횟수는 합산하지 않고 갱신한다. 이미 모사·반격이 발동 조건을 만족했어도 해당 적 단계의 피해 계산 전에 보호를 적용한다.
- 일반 즉시 공격·예약 피해에는 감소가 없다. 반격 준비를 제거하지 않으므로 모사 금지와 구별된다.
- 집속 파열의 무조건 피해 62~82보다 낮다. 반응형 공격이 없는 턴에는 집속 파열의 공격 가치가 남는다.
- 문양 콘셉트: 1획은 두 서명을 대조하는 대칭 꺾은선, 2획은 그 사이를 가르는 책임 서명선. 획마다 시작점·진행 화살표를 따로 표시한다.

**격리 방벽**

- 주문을 그리기 전에 이번 또는 다음 적 행동 단계에 도착할 예약 피해 한 건을 지정한다. 도착 턴과 감소 전후 예상 피해를 표시한다. 지정 가능한 예약이 없으면 방어막 생성만으로 사용할 수 있다.
- 지정 예약에 한 번 적용하거나 이번을 포함한 적 행동 단계 2회가 끝나면 소멸한다. 동일 주문 재사용 시 즉시 방어막은 상한까지 더하고 지정 대상·기간은 교체한다.
- 지정 예약을 말소하면 보호도 제거한다. 집행 지연으로 유효 기간 밖에 도착하게 되면 보호 기간을 자동 연장하지 않는다. 예약 두 건에 동시에 적용하지 않는다.
- 인과 완충은 1획으로 이번 단계 첫 예약을 줄이고, 격리 방벽은 2획으로 이번·다음 단계의 특정 예약을 고른다. 단일 예약의 완전 취소는 결과 말소가 더 유리할 수 있다.
- 문양 콘셉트: 1획은 열린 격리 경계, 2획은 선택 지점을 감싸며 경계를 닫는 안쪽 선.

**축압 방출**

- 적용 가능한 적을 상대로 시전에 성공하면 자기 방어막 `min(현재 잔량, 16)`을 먼저 소비하고 실제 소비량 × 2를 피해에 더한다. 방어막 0이면 42~56, 16 이상이면 74~88 피해다.
- 소비는 피격이 아니며 피해 감소나 인계 방벽 추가 생성을 발동시키지 않는다. 판정이 높다고 소비 상한 16이 늘어나지 않는다. 부족한 방어막은 있는 만큼만 소비하고 부족분을 HP로 내지 않는다.
- 성공 후 저장되는 강화나 예약은 없다. 실패하거나 적 절대 방어막 때문에 적용이 막히면 자기 방어막을 소비하지 않지만 사용한 획·선 길이는 돌아오지 않는다.
- 집속 파열보다 마나 예산이 크고 방어막을 소비해야 높은 피해를 낸다. 준비 없는 무조건 상위 공격으로 만들지 않는다.
- 문양 콘셉트: 1획은 중심으로 모이는 배관, 2획은 중심에서 바깥으로 빠지는 방출선.

**인계 방벽**

- 이번 적 행동 단계에서 피해 감소 후 0보다 큰 첫 적 피해 1건을 방어막·HP에 모두 처리한 뒤, 플레이어가 생존했다면 추가 방어막을 한 번 생성한다. 그 피해의 초과분을 소급해서 흡수하지 않는다.
- 첫 방어막이 반드시 깨져야 하는 조건은 두지 않는다. 이 조건을 넣으면 방어막이 더 많은 높은 판정이 오히려 연속 공격에 불리해지는 역전이 생긴다.
- 일반 즉시 공격·예약·모사·반격 모두 첫 피해 조건에 포함한다. 직격 금지 등으로 피해가 0이 된 건은 추가 생성 대기를 소비하지 않는다. 작은 첫 타격이 먼저 소비할 수 있음을 예상 피해 목록에 표시한다.
- 같은 주문의 추가 생성 대기는 한 건만 유지하며 재사용은 갱신한다. 해당 적 단계에 발동하지 않은 대기는 소멸한다. 이미 생성한 실제 방어막은 통상 규칙대로 남는다.
- 축압 방출의 소비·금서 HP 대가·적 해제·한계 방벽 상한 복원은 발동 원인이 아니다. 추가 방어막 생성 자체가 다시 추가 생성을 일으키지 않는다.
- 문양 콘셉트: 1획은 앞쪽 방벽을 닫는 선, 2획은 뒤쪽 방벽으로 이어지는 인계 고리.

최종 좌표·핵심점·획별 선 길이 배분·허용 오차·전용 에셋은 후속 문양 제작 범위다. 이 표가 실제 마법진 데이터 구현까지 완료했다는 뜻은 아니다.

### 6.4 획득 시점과 일반 주문의 선택 가치

| 시점 | 금서 후보 1종 | 봉인 후보 1종 | 기존 일반 주문 후보 1종 |
|---|---|---|---|
| 5층 관리자 — 기존 유지 | 모사 금지 | 기억 봉합 | 기억 절단 |
| 4층 잔류체 B 이후 기록 해독 | 혈인 관통 | 책임 절단 | 미학습 방어 우선 |
| 4층 관리자 이후 | 한계 방벽 | 격리 방벽 | 미학습 해제 우선 |
| 3층 잔류체 B 이후 기록 해독 | 집행 무효 | 축압 방출 | 미학습 방어 우선 |
| 3층 관리자 이후 | 직격 금지 | 인계 방벽 | 미학습 공격 우선 |
| 2층 관리자 이후 | 놓친 금서 1종 | 놓친 신규 봉인 1종 | 기존 미학습 일반 주문 1종 |
| 1층 관리자 이후 | 신규 전투 주문 없음 | 최종 기록 | 세 단계 최종 승인으로 연결 |

- 4~2층의 각 지점에서 서로 다른 3종 중 1종만 획득한다. 학습 완료 전에는 소유로 등록하지 않는다. 새 주문은 얻은 뒤의 전투부터 계산하며, 해당 보상을 주는 보스의 최초 공략 필수 수단으로 삼지 않는다.
- 위 표의 ‘일반’은 금서가 아닌 낡은·각인·봉인 등급을 모두 포함한다. 봉인 후보 칸과 기존 일반 후보 칸에 같은 주문을 중복 제시하지 않는다.
- 기존 후보는 현재 장착 목록이 아닌 영구 학습 목록으로 결정한다. 지점별 우선 역할에서 미학습 주문을 먼저 찾고, 없으면 해제 → 방어 → 공격 → 디버프 순으로 찾는다. 같은 역할에서는 기존 20종 카탈로그의 번호가 작은 미학습 일반 주문을 우선한다.
- 2층 금서 재제안 순서: 모사 금지 → 집행 무효 → 한계 방벽 → 직격 금지 → 혈인 관통. 앞서 제시했지만 배우지 않은 첫 금서를 선택한다. 금서를 전부 배웠다면 이 칸도 기존 일반 주문 규칙으로 채운다.
- 2층 신규 봉인 재제안 순서: 책임 절단 → 격리 방벽 → 축압 방출 → 인계 방벽. 모두 배웠다면 기존 봉인 주문서 중 미학습을 카탈로그 번호순으로 고르고, 없으면 기존 일반 주문 규칙을 사용한다.
- 후보 생성은 금서 칸 → 봉인 칸 → 기존 일반 칸 순이다. 이미 선택한 후보를 제외하며, 기존 일반 칸은 먼저 전역 역할 보완을 적용한다: 미학습 일반 해제가 남고 학습한 일반 해제가 봉인 해제뿐이면 해제 우선, 아니면 해당 지점의 표에 적힌 역할 우선. 그 밖에는 위의 정해진 순서를 따른다. 기본 공격·방어는 이미 배우므로 보완이 필수 역할을 강제하는 규칙은 아니다.
- 효과·대가·획수·문양을 비교하고 시험한 뒤 확정한다. 보상 화면 첫 진입 때 세 후보를 저장하고 편성 변경·재진입·재실행으로 재추첨하지 않는다. 정상 진행에서 이미 학습했거나 중복된 주문을 후보로 제시하지 않는다.
- 호환 저장 등으로 미학습 주문이 3종 미만이면 남은 고유 후보만 표시하고 빈 칸은 비활성화한다. 0종이면 학습 없이 보상 완료만 저장한다. 정상 28종/15종 보유 경로에서는 발생하지 않는 예외다.
- 2층 재제안은 독립된 마지막 보상 기회다. 모든 미선택 주문이 다시 등장한다고 보장하지 않으며, 과거 선택을 되돌리거나 동일 지점에서 두 번 받지 않는다.
- 5층까지 10종을 배운 경로라면 추가 선택 5회로 1층 진입 시 보유 15종이다. 출전은 최대 6종, 그중 금서는 최대 2종이다. 세 번째 금서를 배워도 자동 출전·자동 교체하지 않는다.
- 5층에서 모사 금지를 고르지 않아도 4·3층에서 금서를 선택하면 최종전 전에 금서 3종 이상 보유가 가능하다. 준비 화면의 2종 제한이 실제 선택으로 작동한다. 금서 0종 경로에는 매번 비금서 후보 2종이 남는다.

### 6.5 전체 카탈로그 및 연계 수량

| 구분 | 기존 5층까지 | 이번 추가 | 보완 후 전체 |
|---|---:|---:|---:|
| 고유 주문 | 20 | 8 | 28 |
| 1획 / 2획 | 17 / 3 | 3 / 5 | 20 / 8 |
| 낡은 / 각인 / 봉인 / 금서 | 6 / 7 / 6 / 1 | 0 / 0 / 4 / 4 | 6 / 7 / 10 / 5 |
| 공격 / 방어 / 해제 / 디버프 | 8 / 6 / 3 / 3 | 3 / 3 / 1 / 1 | 11 / 9 / 4 / 4 |

2획 8종은 방벽 관통·집속 파열·결과 말소·집행 무효·책임 절단·격리 방벽·축압 방출·인계 방벽이다. 하강문 승인 문양은 주문 카탈로그 수량에 포함하지 않는다.

| 3획 연계 예시 | 합산 길이 예산 | 목적 |
|---|---:|---|
| 책임 절단 + 초급 방벽 | 78 + 32 = 110 | 반격 피해 완화와 일반 피해 방어 |
| 격리 방벽 + 균열 절단 | 82 + 42 = 124 | 위험 예약 지정 후 공격 |
| 초급 방벽 → 축압 방출 | 32 + 92 = 124 | 방어 일부를 공격으로 전환 |
| 축압 방출 → 초급 방벽 | 92 + 32 = 124 | 이월 방어를 소비한 뒤 새 방어 확보 |
| 인계 방벽 + 균열 절단 | 86 + 42 = 128 | 연속 피해 대응과 공격 병행 |
| 봉인 해제 + 집속 파열 | 28 + 85 = 113 | 절대 방어막 해제 후 집중 공격 |
| 집행 무효 + 직격 금지 | 58 + 44 = 102 | 금서 정확히 2종. HP 18 및 성공 횟수 소비 |

이는 마나 150 시험값 안에 들어가는 문양 제작 예산 비교다. 실제 그리기에서 선 길이 초과·실패·정화 필요로 연계가 달라질 수 있으며 플레이 테스트 성공을 뜻하지 않는다. 2획 주문 둘을 같은 3획 턴에 연속 시전할 수는 없다.

## 7. 회복·저장·재도전

- 잔류체 A·B 클리어를 각각 별도로 저장한다. B에서 패배해도 A는 반복하지 않는다.
- 회복은 기존 기준을 우선 유지해 각 잔류체 처치 후 HP +20, 결과 최소 60, 최대 100을 시험한다. 보스가 강해진 만큼 B 이후 최소 HP를 더 올릴지는 밸런스 검토 후 결정한다.
- 관리자 이후 다음 층 진입 시 HP +30, 최대 100을 유지한다.
- 패배 재도전은 해당 조우 직전 준비에서 HP 100으로 시작한다. 금서 사용 횟수와 임시 효과를 초기화한다. 성공한 다른 조우·학습·보상은 유지한다.
- 전투 중 종료·재개는 기존 전투 직전 준비 복원 정책을 따른다. 체크포인트 식별에 층 번호뿐 아니라 A·B·관리자 구분이 필요하다.
- 중간문 해제, 각 보상 후보/선택, 하강문 승인 1·2·3, 최종 인계 완료를 별도 기록한다.
- 다음 층으로 이동했다가 재개해도 HP 회복·보상·획수 해금을 중복 적용하지 않는다. 3획은 영구 누적 +1 이벤트가 아니라 해당 진행 구간의 기본값으로 다룬다.

## 8. 확정 사항과 남은 조정

금서 최대 2종 출전 제한은 재확인된 기준이며 다시 미정으로 돌리지 않는다. 세 번째 금서는 전투 전에 교체하며, 신규 봉인 주문서를 금서로 잘못 집계하지 않는다.

후반 콘셉트는 책임 심사 → 자발 격리 → 봉인 유지 → 최종 승인을 이번 상세 설계의 기준으로 유지한다. 기존 결말과 이전 버전 적 이미지는 변경하지 않는다. 개별 주문의 명칭·최종 문양 좌표·판정 허용 오차·피해 밸런스는 제작 및 플레이 검증을 거쳐 확정한다.

사용자가 재확인한 4~1층 매 턴 3획·층별 하강문 독립 문양 3개·금서 출전 최대 2종은 확정 기준이다. 마나 150은 시험값이며 2층에서 다시 4획으로 올리는 단계는 넣지 않는다.

이번 문서의 피해·지속·보상 후보 우선순위는 구현 가능한 시험 규칙으로 구체화하되, 숫자가 기재되었다는 이유만으로 플레이 검증을 통과한 확정 밸런스로 취급하지 않는다. 적 모델이나 이미지의 새 버전을 만들지 않는다.

## 9. 문서 반영과 후속 검토 항목

저장소의 `docs/FLOORS_4_1_GAMEPLAY_DESIGN.md`에 이번 상세 기획을 두고 문서 목차와 변경 이력에서 연결한다. 이 문서의 상태는 ‘출시 목표 작성 중’이며 실제 게임 구현 기준과 구분한다. 확정·구현 단계에서 LEVEL_FLOW·COMBAT_SYSTEM·SPELL_GLYPH_SPEC·NARRATIVE·TUTORIAL·구현 현황을 연결하고 갱신한다. 기존 7~5층 문서를 소급해 3획으로 바꾸지 않는다.

구현 전 검토해야 할 조합:

- 금서 없음 / 금서 1종 / 금서 2종, 낮은 HP의 금서 전용 공격·방어 구성.
- 모사 금지 + 직격 금지, 집행 무효 + 직격 금지, 한계 방벽 반복 시전.
- 책임 절단과 다른 감소의 결합, 격리 방벽 지정 예약의 말소·지연·만료, 축압 방출 실패 시 방어막 보존.
- 인계 방벽의 첫 피해 0 처리·고판정 단조성·사망 시 미발동·후속 생성 1회 제한.
- 2획 공격 + 방어, 해제 + 공격 + 방어의 실제 선 길이 마나 여유.
- 정화·결과 말소를 배우지 않은 진행, 초기 공격 위주 진행의 전투 길이.
- 기본 대응 외 주문이 없을 때 카드 봉인 처리와 1층 단계 전환 시 남은 예약.
- 잔류체 B 패배, 보상 선택 직후 종료, 하강 승인 2단계 이후 재개, 1층 종료 재실행.
- 세 번째 금서 장착 거부·명시적 교체, 카드 봉인/사용 횟수 소진 상태의 금서도 장착 수에 포함, 봉인 주문서는 금서 수에서 제외.
- 보상 3후보 중복 제외·결정적 재제안·기존 저장 호환, 3획 재해금/HP회복/하강 승인 성공의 중복 적용 방지.

이번 작업은 기획 보완·문서 정합성 확인·간단한 산술 검산·문서 커밋까지다. 게임 코드·이미지는 수정하지 않으며 빌드·게임 테스트·GitHub 푸시는 수행하지 않는다. 문양의 최종 좌표 제작과 실플레이 밸런스 검증은 후속 작업이다.
