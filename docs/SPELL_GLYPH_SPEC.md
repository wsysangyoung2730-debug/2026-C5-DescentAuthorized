## 1. 문서 목적

이 문서는 데모에서 사용하는 주문 5종의 문양 구조, 획순, 핵심 점, 허용 오차, 마나 길이, 가이드와 시각 피드백을 정의한다. 좌표는 실제 구현과 아트 제작을 위한 초기 기준이며 기기 테스트 후 조정할 수 있다.

## 2. 문양 설계 원칙

- 문양은 삼각형, 별, 원처럼 완성된 기하 도형을 그대로 사용하지 않는다.
- 멀리서 보면 각 주문의 역할을 떠올릴 수 있지만 가까이서는 서명, 행정 기호 또는 이계 문자처럼 보여야 한다.
- 강한 주문일수록 길고, 핵심 점이 많고, 꺾임과 교차가 까다롭다.
- 난이도는 빠르게 그리는 능력이 아니라 경로를 기억하고 정확히 연결하는 능력에서 나온다.
- 모든 주문은 Pencil과 손가락으로 완주할 수 있어야 한다.
- 작은 손 떨림은 허용하되, 핵심 점의 순서와 주문의 실루엣은 지켜야 한다.
- 주문마다 시작점, 진행 방향과 종점이 시각적으로 구분되어야 한다.

## 3. 좌표와 용어

### 3.1 정규화 좌표

입력판을 가로 100, 세로 100의 정규화 좌표로 취급한다.

- 좌측 상단: `(0, 0)`
- 우측 하단: `(100, 100)`
- 중심: `(50, 50)`
- 실제 화면 크기와 원근 변형은 렌더링 단계에서 변환한다.

### 3.2 핵심 용어

| 용어 | 의미 |
| --- | --- |
| 시작점 | 해당 획이 시작되어야 하는 지점 |
| 종점 | 해당 획이 끝나야 하는 지점 |
| 핵심점 | 반드시 지정 순서대로 통과해야 하는 지점 |
| 보조점 | 경로의 형태를 유도하지만 누락이 즉시 실패는 아닌 지점 |
| 선로 | 정답 경로를 중심으로 형성한 허용 영역 |
| 교차점 | 같은 획 또는 다른 획이 만나야 하는 위치 |
| 방향 조건 | 핵심점 사이를 지정 방향으로 지나야 하는 조건 |
| 권장 길이 | 정답 경로를 따라 그렸을 때 사용하는 선의 양 |

## 4. 공통 가이드 규칙

### 4.1 카드 선택 전

- 입력판에는 현재 전투 환경과 말소 구역만 표시한다.
- 이전 주문의 가이드와 잔여 선은 제거한다.
- 주문 카드는 문양 축소판과 요구 획수를 보여준다.

### 4.2 카드 선택 후

- 시작점은 맥박처럼 천천히 밝아지는 채운 점으로 표시한다.
- 핵심점은 작은 빈 원으로 표시한다.
- 종점은 이중 원으로 표시한다.
- 정답 선로는 매우 옅은 점선 또는 안개 같은 빛으로 표시한다.
- 현재 그려야 할 획만 선명하고 이후 획은 낮은 밝기로 표시한다.
- 주문 카테고리에 따라 가이드 색을 바꾼다.

### 4.3 그리는 중

- 통과한 핵심점은 즉시 채워진다.
- 다음 핵심점이 한 번 밝게 반응한다.
- 실제 선은 Pencil 끝에서 생성되고 시간이 지나도 턴 종료 전까지 유지된다.
- 마나가 낮아지면 선의 중심 광량이 줄고 끝부분에서 불안정한 입자가 튄다.
- 허용 선로를 크게 벗어나도 즉시 실패시키지 않고 선의 가장자리만 붉게 흔들리게 한다.

### 4.4 획 종료 후

- 완료한 획은 입력판에 고정한다.
- 다음 획이 있다면 다음 시작점을 강조한다.
- 모든 획이 끝나면 0.25초 동안 문양 전체를 검수하고 판정 결과를 표시한다.

## 5. 공통 판정 기준

### 5.1 거리 허용 범위

허용 범위는 입력판 짧은 변을 기준으로 한다.

| 난이도 | 핵심점 반경 | 선로 반경 |
| --- | ---: | ---: |
| 쉬움 | 6% | 7% |
| 보통 | 5% | 5.5% |
| 어려움 | 4% | 4.5% |

손가락 모드에서는 핵심점 반경만 1%p 넓힌다. 공격 배율과 최고 등급 조건은 동일하게 유지한다.

### 5.2 시작과 종료

- 시작점 반경 안에서 획을 시작해야 한다.
- 종점 반경 안에서 끝내면 종점 조건을 완전히 충족한다.
- 종점에서 조금 벗어나도 마지막 선분이 올바른 방향이면 점수를 일부 인정한다.
- 시작점을 완전히 놓치면 시전 반려한다.

### 5.3 핵심점 순서

- 핵심점은 문서에 기록된 순서대로 통과해야 한다.
- 다음 점을 먼저 지나간 뒤 되돌아오면 순서 위반이다.
- 보조점은 점수에 영향을 주지만 필수 실패 조건은 아니다.

### 5.4 획과 교차

- 1획 주문은 입력이 끊기면 실패한다.
- 2획 주문은 각 획의 역할과 순서를 바꿀 수 없다.
- 필수 교차점은 교차 반경 안에서 실제 선분끼리 만나야 한다.
- 단순히 가까이 지나가는 것은 교차로 인정하지 않는다.

## 6. 카테고리 색상

| 카테고리 | 기본색 | 중심광 | 실패 경고 |
| --- | --- | --- | --- |
| 공격 | 보라색 | 백보라 | 적색 |
| 방어 | 청백색 | 흰색 | 주황색 |
| 해제 | 옅은 금색 | 백색 | 검붉은색 |

등급 색상과 주문 카테고리 색상은 역할이 다르다. 카드 테두리와 두루마리 외형은 등급색을 사용하고, 실제로 그리는 선과 가이드는 카테고리색을 사용한다.

## 7. 잔광 말소

### 7.1 기본 정보

| 항목 | 값 |
| --- | --- |
| 카테고리 | 공격 |
| 등급 | 낡은 주문서, 푸른빛 |
| 요구 획 | 1획 |
| 난이도 | 쉬움 |
| 기본 피해 | 18 |
| 권장 마나 | 30 이하 |
| 습득 | 10층 첫 주문 |

### 7.2 문양 의도

짧은 말소 표시와 관리자의 승인 서명이 겹친 형태다. 체크 표시처럼 쉽게 시작하지만 끝이 다시 안쪽으로 꺾여 평범한 체크와 구분된다.

### 7.3 경로

```text
S(20,55)
→ N1(37,72)
→ N2(67,28)
→ N3(78,43)
→ E(66,51)
```

- `S → N1`은 짧게 내려가는 말소선이다.
- `N1 → N2`는 주문의 주된 상승 절단선이다.
- `N2 → N3 → E`는 안쪽으로 되감기는 작은 갈고리다.
- 필수점: S, N1, N2, E
- 보조점: N3

### 7.4 판정

- 시작점과 N1, N2 순서를 지키면 형태가 성립한다.
- N1의 각도는 넓게 허용한다.
- 마지막 갈고리를 생략하면 불완전 승인까지만 가능하다.
- 상승선을 반대 방향으로 그리면 시전 반려한다.

### 7.5 가이드와 연출

- 시작점이 먼저 푸른 보라색으로 점등된다.
- N2를 통과하면 표적에 가느다란 잔광이 먼저 생긴다.
- 주문 발동 시 문양의 주 절단선이 적을 스치고 0.2초 뒤 잔상이 폭발한다.

## 8. 균열 절단

### 8.1 기본 정보

| 항목 | 값 |
| --- | --- |
| 카테고리 | 공격 |
| 등급 | 낡은 주문서, 푸른빛 |
| 요구 획 | 1획 |
| 난이도 | 보통 |
| 기본 피해 | 28 |
| 권장 마나 | 42 이하 |
| 습득 | 10층 두 번째 주문 |

### 8.2 문양 의도

한 번의 서명 안에서 균열의 양쪽 면을 번갈아 꿰매고 마지막에 절단하는 형태다. 날카로운 꺾임이 많아 잔광 말소보다 어렵고, 성공했을 때 강한 공격이 된다.

### 8.3 경로

```text
S(18,68)
→ N1(39,25)
→ N2(34,56)
→ N3(68,35)
→ N4(55,75)
→ N5(82,58)
→ E(72,48)
```

- 첫 상승선은 길고 곧게 그린다.
- N1 이후 짧게 되돌아와 N2를 통과한다.
- N2에서 우측으로 가로지른 뒤 아래로 급하게 꺾는다.
- 마지막은 중심을 향해 짧게 되감는다.
- 필수점: 모든 N1~N5
- 교차 필수는 없지만 N2~N4 구간이 첫 상승선 가까이를 지나야 한다.

### 8.4 판정

- N1과 N4의 급격한 방향 전환이 핵심이다.
- N2를 건너뛰면 시전 반려한다.
- N3~N4 구간이 지나치게 둥글면 경로 점수를 크게 낮춘다.
- 모든 점을 통과해도 길이가 권장량의 1.5배를 넘으면 정밀 승인 이상을 받을 수 없다.

### 8.5 가이드와 연출

- 핵심점은 균열 양쪽을 번갈아 점등한다.
- 발동하면 적 앞 공간에 같은 모양의 얇은 균열이 생긴다.
- 마지막 되감기와 동시에 균열이 닫히며 적을 절단한다.

## 9. 방벽 관통

### 9.1 기본 정보

| 항목 | 값 |
| --- | --- |
| 카테고리 | 공격 |
| 등급 | 각인 주문서, 보라색 |
| 요구 획 | 2획 |
| 난이도 | 어려움 |
| 기본 피해 | 34 |
| 권장 마나 | 75 이하 |
| 습득 | 9층 기록 관리자 보상 |

### 9.2 문양 의도

첫 획으로 방벽의 구조를 읽고 약점을 노출한 뒤, 두 번째 획으로 중심을 관통한다. 두 획의 역할이 명확히 달라야 하며 두 번째 획이 첫 획과 교차해야 완성된다.

### 9.3 첫 번째 획: 방벽 해석

```text
S1(24,70)
→ N1(17,43)
→ N2(35,22)
→ N3(59,26)
→ N4(82,45)
→ E1(76,69)
```

- 위쪽이 찌그러진 보호막 외곽을 그린다.
- 완전한 원이나 반원을 만들지 않는다.
- N2와 N3 사이에 작은 비대칭 굴곡을 유지한다.

### 9.4 두 번째 획: 관통

```text
S2(37,82)
→ X(50,52)
→ N5(62,34)
→ E2(73,18)
```

- 아래에서 위로 긋는다.
- 교차점 X는 첫 획의 내부 중심을 지나야 한다.
- 마지막 구간은 첫 획의 외곽을 뚫고 밖에서 끝난다.

### 9.5 판정

- 첫 획을 먼저 완료해야 한다.
- 첫 획이 닫힌 원이 되면 경로 점수를 낮춘다.
- 두 번째 획이 교차점 X를 놓치거나 외곽을 통과하지 못하면 시전 반려한다.
- 두 획 사이의 대기 시간은 제한하지 않는다.
- 절대 방어막 상태에서 문양을 정확히 완성해도 효과는 0이며 주문 판정 등급은 정상 표시한다.

### 9.6 가이드와 연출

- 첫 획 동안 적의 일반 방어막 표면에 분석선이 나타난다.
- 첫 획 완료 후 X가 강하게 점등된다.
- 두 번째 획이 X를 지날 때 Pencil 끝에서 직선형 광창이 만들어진다.
- 발동하면 일반 방어막을 통과해 적의 핵을 가격하고 방어막을 소멸시킨다.

## 10. 초급 방벽

### 10.1 기본 정보

| 항목 | 값 |
| --- | --- |
| 카테고리 | 방어 |
| 등급 | 낡은 주문서, 푸른빛 |
| 요구 획 | 1획 |
| 난이도 | 쉬움 |
| 효과 | 고정 방어막 20 |
| 권장 마나 | 32 이하 |
| 습득 | 8층 전초 구역 |

### 10.2 문양 의도

몸 앞에 임시 보호벽을 세우는 관리국의 안전 절차 기호다. 위쪽은 보호 곡선, 아래쪽은 고정 장치처럼 보여야 한다.

### 10.3 경로

```text
S(22,68)
→ N1(25,42)
→ N2(43,24)
→ N3(62,28)
→ N4(78,50)
→ N5(69,72)
→ E(50,78)
```

- 왼쪽 아래에서 시작해 위를 감싸는 비대칭 곡선을 그린다.
- N4 이후 아래로 내려오며 중심 하단에서 끝낸다.
- 완전히 닫지 않고 왼쪽 아래에 틈을 남긴다.

### 10.4 판정

- S, N2, N4, E가 필수다.
- 작은 흔들림은 넓게 허용한다.
- 문양을 완전히 닫아도 실패하지 않지만 정밀 승인 이상은 받을 수 없다.
- 불완전 승인 이상이면 동일하게 방어막 20을 생성한다.

### 10.5 가이드와 연출

- 그리는 동안 선 바깥쪽으로 얇은 유리막이 자란다.
- 성공하면 문양이 플레이어 HUD 쪽으로 접혀 들어가 청백색 방어막이 된다.
- 높은 판정은 방어량이 아니라 표면의 정교함과 사운드만 강화한다.

## 11. 봉인 해제

### 11.1 기본 정보

| 항목 | 값 |
| --- | --- |
| 카테고리 | 해제 |
| 등급 | 낡은 주문서, 푸른빛 |
| 요구 획 | 1획 |
| 난이도 | 보통 |
| 효과 | 절대 방어막 1회 제거 |
| 권장 마나 | 28 이하 |
| 습득 | 관측 잔류체 처치 보상 |

### 11.2 문양 의도

잠금 핵을 정확히 찾아 통과한 뒤 걸쇠를 반대 방향으로 젖히는 짧은 해제 서명이다. 선은 짧지만 중심점 정확도가 중요하다.

### 11.3 경로

```text
S(25,72)
→ N1(42,57)
→ K(51,48)
→ N2(70,27)
→ N3(62,55)
→ E(81,68)
```

- K는 잠금 핵심점이며 가장 엄격한 반경을 사용한다.
- N2까지 상승한 뒤 아래로 되돌아와 N3에서 걸쇠를 연다.
- 마지막은 우측 바깥으로 밀어낸다.

### 11.4 판정

- K의 판정 반경은 입력판 짧은 변의 3.5%다.
- K를 놓치면 총점과 관계없이 시전 반려한다.
- N2와 N3의 되돌림을 생략하면 실패한다.
- 성공 등급에 따른 기능 차이는 없다.
- 절대 방어막이 없을 때 사용하면 시전은 성공하지만 전투 효과가 없다는 메시지를 표시한다.

### 11.5 가이드와 연출

- 대상의 절대 방어막 핵과 입력판 K가 가느다란 선으로 연결된다.
- K를 통과하면 금색 방어막에 금이 간다.
- 문양 완료 시 금이 전체로 퍼지고 방어막이 안쪽으로 붕괴한다.
- 문 잠금에 사용할 때는 같은 문양이 잠금 패널 위에 겹쳐진다.

## 12. 말소 구역과 문양 상호작용

- 말소 구역은 핵심점과 주문 시작점을 완전히 덮지 않는다.
- 선이 구역 안에 들어가면 해당 구간의 중심광을 약하게 만든다.
- 구역 안에서 마나는 1.75배 속도로 감소한다.
- 구역을 통과한 선로 샘플은 경로 정확도 계산에서 추가 감점을 받는다.
- 구역 통과만으로 즉시 실패시키지 않는다.
- `획 일부 말소됨` 메시지는 한 주문에 한 번만 표시한다.

## 13. 카드 축소 문양

- 실제 문양의 비율과 획 구분을 유지한다.
- 시작점과 핵심점은 카드에서 생략한다.
- 2획 주문은 두 획을 서로 다른 밝기로 표시한다.
- 요구 획수는 카드 하단에 펜촉 아이콘 1개 또는 2개로 표시한다.
- 카테고리는 좌측 상단 아이콘과 실제 문양색으로 구분한다.
- 등급은 카드 테두리와 하단 인장색으로 구분한다.

## 14. 가이드 도움 단계

동일 주문을 반복 실패하면 가이드를 다음 순서로 강화한다.

1. 기본: 핵심점과 옅은 경로
2. 2회 실패: 다음 핵심점 확대
3. 3회 실패: 경로 밝기와 허용 폭 시각화 강화
4. 4회 실패: 움직이는 빛으로 획 진행 방향 표시

도움 단계는 판정 수치나 공격력을 올리지 않는다. 플레이어가 성공하면 다음 시전부터 한 단계 낮춘다.

## 15. 구현 데이터 항목

주문 하나는 최소한 다음 정보를 가진다.

```text
식별자
표시 이름
카테고리
주문서 등급
요구 획수
기본 효과
권장 마나 길이
획별 시작점과 종점
핵심점 배열과 순서
보조점 배열
기준 경로
허용 반경
교차 조건
방향 조건
가이드 색상
발동 효과 식별자
실패 메시지
```

문양 좌표와 밸런스 수치는 코드에 직접 흩어놓지 않고 주문 데이터에서 읽도록 설계한다.

## 16. 문 개방 문양과의 구분

문 개방 문양은 전투 주문 목록에 포함하지 않는다.

- 해당 층의 하강문에서만 표시한다.
- 마나와 HP 위험이 없다.
- 실패 시 무제한 재제출할 수 있다.
- 전투 판정 등급 대신 `승인`과 `재제출`만 사용한다.
- 10층은 쉬운 1획, 9층은 서명형 1~2획, 8층은 2획 문양을 사용한다.

## 17. 아트 및 플레이 테스트 확인 항목

- 다섯 문양이 축소 카드에서도 서로 구분되는가
- 가이드 없이도 숙련자가 문양을 기억할 수 있는가
- 손가락으로 핵심점을 가리지 않고 그릴 수 있는가
- 1획 주문 두 개를 연속으로 그릴 때 피로하지 않은가
- 방벽 관통의 두 획이 역할상 명확하게 느껴지는가
- 봉인 해제가 짧지만 지나치게 쉬워 보이지 않는가
- 말소 구역이 어려움을 만들되 문양을 불가능하게 만들지 않는가
- 완전 각인이 손의 속도가 아니라 정확도에서 나오는가
