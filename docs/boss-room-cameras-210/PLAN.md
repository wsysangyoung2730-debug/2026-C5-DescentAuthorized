## 연출 구조

조우 대사가 끝나면 왼쪽 장치 옆에서 시작해 중앙 공간, 오른쪽 장치 옆을 차례로 보여주고 보스 정면으로 돌아오는 약 12초의 동선이다. 각 구간에서 카메라의 위치와 시선이 함께 변한다. 회전만 하는 파노라마가 아니라 가까운 장치와 뒤쪽 건축물의 시차로 공간 깊이를 보여준다.

| 시간 | 카메라 | 역할 |
| --- | --- | --- |
| 0초 | `CAM_Fxx_Encounter_Left` | 왼쪽 장치에 가까운 전경, 장치 뒤로 방의 깊이 노출 |
| 3.4초 | `CAM_Fxx_Encounter_Wide` | 중앙 통로 쪽으로 후퇴·이동하여 방 전체 구조 노출 |
| 7.2초 | `CAM_Fxx_Encounter_Right` | 오른쪽 장치 쪽으로 전진·이동하여 반대편 공간 노출 |
| 11.2~12초 | `CAM_Fxx_Encounter_Return` | 보스 정면으로 복귀·정지. 1~3층은 방 안쪽 복귀 지점 사용 |

`CAM_Fxx_Encounter_Preview`는 위 네 카메라를 잇는 실제 이동 미리보기다. 30fps, 1~361프레임. 수평선은 기울이지 않고 각 구간의 가감속을 부드럽게 한다. 렌즈는 좌우·전경 24mm를 시작점으로 실제 장면 확인 후 조정한다. 별도 시선 타깃에는 실제 오브젝트 이름을 기록한다. `PREVIEW_Fxx_EncounterSweep` 장면에서는 즉시 재생할 수 있으며 원래 장면의 활성 카메라와 프레임 범위는 유지한다.

1~3층 기존 주 카메라는 방 전면 바닥 경계보다 뒤에 있어 복귀점은 실내 통로로 보정한다. 4~9층은 원래 주 카메라 구도로 돌아온다. 앱 연결 시에는 모든 층에서 실제 런타임 전투 구도까지 추가 연결이 필요하다.

## 이후 앱 연결 계약

현재 내보내기는 등록된 카메라만 남기고 애니메이션을 제외한다. 따라서 이번 Blender 추가만으로 앱에서 연출이 재생되지는 않는다.

나중에 조우 대사의 `onFinished`에서 전투 시작 이벤트를 잠시 보류하고 대사 배경을 내린 뒤 이동 카메라를 재생한다. 종료 시 앱이 보정한 실제 전투 카메라로 연결해야 한다. Blender는 미터/Z-up, 앱은 루트 -90도 X 회전으로 Y-up을 사용한다. 카메라 이름, 실제 참조 오브젝트, 시간별 위치·회전·화각을 JSON으로 함께 전달한다. 일시정지, 건너뛰기와 동작 줄이기는 앱 연결 단계의 범위다.
