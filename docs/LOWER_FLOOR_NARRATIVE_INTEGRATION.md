## 진행

기존 8–5층과 같은 `BossNarrativeView`에서 타자 표시, 자동 진행, 자동 진행 끄기, 탭 넘기기를 사용한다. 가방 준비를 마치면 조우 대화를 보여 주고, 대화 종료 후 전투에 진입한다. 처치 후에도 같은 화면에서 대화를 끝낸 다음 기존 중앙문·보상·최종 기록 단계로 이동한다.

3층 실제 진행은 A=동의 보관, B=격리 집행이다. 이미지 제작 당시 파일 A/B는 반대였으므로 게임의 인물 순서에 맞게 연결했다.

1층 관리자 처치 후 최종 기록을 읽고 기존 출구 승인 3단계를 완료해야 인계 대화가 열린다. 인계 화면은 검은 배경과 ‘다음 탑 / 제10층’ 표식을 사용하며 마지막 대사 이후 타이틀로 돌아간다. 새로운 다음 탑 3D 배경은 추가하지 않았다.
