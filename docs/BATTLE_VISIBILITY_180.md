## 원인과 변경

- 예고의 중심을 머리 위에 배치하면서 아이콘 아래쪽 높이를 빼지 않아 장식과 겹쳤다. 실제 아이콘 높이, 머리/장식 전체 경계, 방어막 위쪽을 계산해 분리한다. 9층의 음수 높이 보정도 제거했다.
- 11종 예고의 원본 크기가 달랐다. 몬스터 높이에 비례하는 공통 표시 높이(0.4~0.85)를 사용한다. 연기와 등장 애니메이션이 배치 계산에 섞이지 않도록 원본 크기를 먼저 저장한다.
- 예고는 게임 정보이므로 천장·배경 구조물에 가려지지 않도록 깊이 검사를 해제하고, 방 조명 영향을 받지 않는 재질로 표시한다. 원본 색상 텍스처는 유지한다.
- 작은 잔류체도 최소 4.6 크기의 방어막을 사용하던 고정값을 제거했다. 몸 크기에 맞추고 선의 불투명도와 뒷면 중첩을 줄였다. 동작 줄이기 설정에서 방어막을 해제한 뒤 예고가 원래 높이로 복귀하지 않던 경로도 수정했다.
- 절대 방벽 행동이 일반 방벽 예고로 연결되어 있던 매핑을 수정했다.
- 실제 전투 HUD가 화면 전체를 20% 어둡게 덮던 처리를 제거하고, 중앙을 비운 가장자리 그라데이션으로 바꿨다.
- 전투 카메라는 불러온 몬스터의 실제 높이를 기준으로 거리·높이·주시점을 계산한다. 전체 장식까지 고려하며 약간 비스듬한 방향으로 배경 중앙 장치와 실루엣이 겹치는 정도를 줄인다. 방 밖으로 후퇴하지 않고 기존 시선 방향을 따라 접근한다.
- 조사·보상·하강 카메라와 전투 카메라 스냅샷을 분리했다. 같은 카메라 이름을 공유해도 전투 진입/이탈 시 올바른 구도로 전환하고 기본 시점 버튼은 전투 구도로 복귀한다.
- 전투 회전은 좌우 12도, 위 6도, 아래 3도이며 확대 시 시야각 하한은 기본의 95%다. 조사 전용 회전 설정은 유지한다. 몬스터가 화면에서 사라질 만큼 주변을 돌아보는 동작을 줄이는 의도적인 변경이다.
- 몬스터 앞쪽과 뒤쪽에 한 쌍의 좁은 조명을 배치하고 크기에 비례해 광량을 보정한다. 방 전체 노출은 올리지 않는다. 기존 품질별 그림자 개수 안에서 주 조명에 그림자 하나를 우선 배정해 접지감을 보완한다.
- 6층 잔류체는 금속 반사 비율을 제한하고 전용 조명을 강화해 어두운 청동 표면과 윤곽을 보완했다. 원본 색상·노멀·거칠기·발광 텍스처는 유지한다.
- 9·10층 최신 문을 외부 참조로 연결한 장면은 OpenUSD에서는 열렸지만 RealityKit 가져오기가 실패했다. 최신 문을 장면에 통합하고 텍스처 경로를 상대 경로로 유지했다. 세 품질 자산과 재생성 스크립트에 반영했다.

## 검증 방법

- iPad Pro 13 M5 / iOS 26.5 시뮬레이터 Debug 빌드.
- 진행 관련 선택 테스트 10개 통과. 최초 기본 Swift 실행은 SDK 버전 불일치로 실패했으며 Xcode 도구로 다시 실행해 통과했다.
- 장면 진단은 실제 저장 데이터를 읽거나 진행시키지 않는 전용 미리보기로 실행한다.
- `docs/reality-assets/validate_battle_visibility.py`: 설치된 Debug 앱에서 22개 방을 순차 캡처한다. 동시에 실행하면 안 된다.
- 몬스터가 있는 21개 방은 11종 예고와 일반·절대 방어막 조합, 최대 아래 회전/확대를 검사한다. 10층은 훈련 장면으로 별도 몬스터가 없으므로 로드와 카메라 복귀를 확인한다.
- 투영된 원본 경계(화면 안으로 잘라낸 터치 영역이 아님), 실제 머리·방어막과의 간격, 복귀 위치/시야각 오차를 JSON으로 남긴다.

4층 잔류체 A와 1층 보스의 실제 전투 HUD에서 예고·몬스터·주문 입력 패드의 배치를 확인했다. `--preview-direct-battle`은 하층의 정상 준비/조우 전이를 이용하는 Debug 전용 경로이며 InMemory 저장소에서만 사용한다. 실기기의 GPU 성능이나 모든 전투의 처음부터 끝까지 플레이한 결과를 뜻하지 않는다.

## 최종 결과

- 22개 장면 로드 성공, 몬스터 21종의 예고/방어막/회전 검사 315건 통과, 실패 0건.
- 기본 시점 복귀 행렬 최대 오차 2.98e-7, 시야각 오차 0.
- 최종 Debug 빌드 성공, 진행·대화 관련 테스트 10개 통과.
- 전체 장면 검증은 medium 품질의 시뮬레이터 기준이다. high/low 문 자산도 수정했으나 해당 품질 전체 실행 검사는 하지 않았다.
- 검증 수치는 예고 배치와 복귀의 기하학적 검사이며, 모든 실기기에서 시각적 가독성이나 성능을 보장하는 수치는 아니다. 실기기 플레이 확인은 남아 있다.
- 재현 결과는 `docs/reality-assets/battle-visibility-validation.json`에 보관한다.
