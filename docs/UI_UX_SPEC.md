# UI/UX 명세

## 1. 문서 목적

이 문서는 `하강 승인: 제0균열` 데모의 화면 구성, 정보 우선순위, 입력 방식, 상태 변화, 화면 전환과 접근성 기준을 정의한다. 기준 기기는 가로 방향 iPad이며 Apple Pencil과 손가락 입력을 모두 지원한다.

## 2. UX 목표

- 플레이어가 적의 다음 행동, 남은 마나와 획을 한눈에 파악한다.
- 주문 카드를 선택하면 어디에 무엇을 그려야 하는지 즉시 이해한다.
- 드로잉하는 동안 UI가 손과 Pencil을 방해하지 않는다.
- 일반 방어막과 절대 방어막을 색상뿐 아니라 형태로 구분한다.
- 공격의 성공과 실패 원인을 텍스트, 빛, 소리와 햅틱으로 동시에 전달한다.
- 행정 오컬트 분위기를 유지하되 반복 플레이를 방해하는 장식은 줄인다.

## 3. 지원 환경

### 3.1 화면 방향

- 데모는 iPad 가로 방향을 기준으로 제작한다.
- 좌우 어느 방향으로 기기를 돌려도 가로 화면을 지원한다.
- 세로 방향 진입 시 가로 회전을 요청하는 화면을 표시한다.

### 3.2 기준 화면

- 기본 설계 기준: 13형 iPad Pro 가로 화면
- 축소 검증: 11형 iPad 가로 화면
- 안전 영역과 홈 인디케이터를 침범하지 않는다.
- UI 크기는 화면 너비에 따라 무한 확대하지 않고 최소·최대 크기를 둔다.

### 3.3 입력 수단

- Apple Pencil
- 한 손가락 드로잉
- 손가락 탭과 드래그
- 키보드와 포인터는 필수 플레이 수단은 아니지만 버튼 탐색을 방해하지 않아야 한다.

| 화면 | 목적 |

| 기록 열람 | 발견한 관리국 기록 확인 |

| 보상 선택 | 두루마리 3개 중 하나 선택 |
| 문 개방 | 하강 문양 제출 |
| 일시정지 | 재개, 설정, 재시작, 타이틀 이동 |

## 5. 디자인 언어

### 5.1 분위기

- 현대 행정 시스템 위에 이계의 마법이 침식된 모습
- 직선형 프레임, 얇은 구분선과 관리국 인장
- 검은 유리, 낡은 금속, 종이, 잉크와 관측 장비 질감
- 중요한 기능만 빛나고 나머지는 낮은 채도로 유지

### 5.2 형태

- 버튼과 패널의 모서리는 작게 처리한다.
- 전투 공간을 큰 패널이나 카드 안에 가두지 않는다.
- 화면 섹션 위에 카드를 다시 겹치는 중첩 구조를 피한다.
- 명령 버튼은 아이콘과 짧은 텍스트를 함께 사용한다.
- 일시정지, 음향, 설정처럼 익숙한 기능은 표준 아이콘을 우선한다.

### 5.3 색상 역할

| 역할 | 색상 방향 |
| --- | --- |
| 배경 | 검정, 중성 회색, 오염된 금속색 |
| 공격 | 보라색과 백보라 중심광 |
| 방어 | 청백색과 유리빛 |
| 해제 | 옅은 금색과 백색 |
| 플레이어 HP | 적색 |
| 적 HP | 어두운 적색 |
| 일반 방어막 | 청백색 |
| 절대 방어막 | 금색 격자와 봉인 인장 |
| 말소 구역 | 검은 잉크와 붉은 말소 도장 |
| 시스템 승인 | 푸른빛 또는 백색 |
| 시스템 반려 | 적색 |

보라색은 마법과 공격의 강조색으로만 사용하고 전체 화면을 한 가지 보라색 계열로 채우지 않는다.

### 5.4 글꼴과 문체

- 제목: 단단하고 좁은 인상의 고딕 계열
- 본문과 수치: 가독성이 높은 시스템 고딕
- 관리국 메시지: 자간을 과도하게 벌리지 않고 짧은 문장 사용
- 작은 UI에서 장식용 영문 대문자를 남용하지 않는다.
- 숫자는 HP와 피해처럼 즉시 비교할 정보에만 사용한다.

## 6. 타이틀 화면

### 6.1 구성

```text
┌──────────────────────────────────────────────┐
│                                              │
│                 하강 승인                     │
│                  제0균열                      │
│        DESCENT AUTHORIZED: Rift Zero         │
│                                              │
│                 [ 이어하기 ]                  │
│                 [ 새 게임 ]                   │
│                 [ 설정 ]                      │
│                                              │
└──────────────────────────────────────────────┘
```

- 실제 탑 내부나 하강문을 배경으로 사용한다.
- 제목은 카드 안에 넣지 않고 공간 위에 직접 배치한다.
- 저장 데이터가 없으면 이어하기를 숨긴다.
- 새 게임 선택 시 기존 저장이 있으면 확인 창을 표시한다.

### 6.2 상태

- 최초 실행: 새 게임, 설정
- 저장 존재: 이어하기, 새 게임, 설정
- 데모 완료: 이어하기 대신 `완료 기록`을 선택적으로 표시

## 7. 층 탐색 화면

### 7.1 기본 배치

- 배경 전체에 현재 2.5D 장면을 표시한다.
- 좌우 가장자리에 인접 장면 이동 영역을 둔다.
- 조사 물체는 화면 안의 실제 위치에서 반응한다.
- 상단 왼쪽에 현재 층과 공간명을 작게 표시한다.
- 상단 오른쪽에 기록, 설정과 일시정지 아이콘을 둔다.

### 7.2 조사 가능 상태

- 기본: 환경과 같은 밝기
- 시선 유도: 미세한 반사광 또는 반복되지 않는 작은 입자
- 터치/호버: 외곽선과 짧은 명칭 표시
- 조사 완료: 강조를 줄이되 다시 열람 가능
- 필수 진행: 관리국 표시등 또는 손 문양과 같은 세계관 안의 신호 사용

### 7.3 이동

- 화면 끝의 화살표만 두기보다 실제 문과 통로를 누르게 한다.
- 이동 가능한 방향에는 얇은 방향 아이콘을 보조로 표시한다.
- 장면 전환은 0.4~0.7초의 카메라 이동 또는 암전으로 처리한다.
- 전투 직전 이동은 취소할 수 있도록 진입 지점을 명확히 보여준다.

## 8. 전투 화면

### 8.1 기본 배치

```text
┌──────────────────────────────────────────────────────────┐
│ [플레이어 HP/방벽]       [적 이름·HP·방벽]   [다음 행동][Ⅱ] │
│                                                          │
│                     적 / 2.5D 배경                       │
│                                                          │
│             ┌────────────────────────┐                   │
│             │    원근형 드로잉 입력판   │                   │
│             │  가이드·현재 획·말소 구역 │                   │
│             └────────────────────────┘                   │
│ [마나·남은 획]      [주문 카드 최대 5장]        [턴 종료]    │
└──────────────────────────────────────────────────────────┘
```

기존 콘셉트 이미지의 중앙 적, 바닥 입력판, 하단 카드 구성을 유지한다. 왼쪽의 다인 파티 초상화 목록은 제거하고 플레이어 한 명의 HP, 방어막과 상태만 표시한다.

### 8.2 정보 우선순위

1. 현재 그리는 선과 다음 핵심점
2. 남은 마나와 획
3. 적의 다음 행동
4. 플레이어와 적의 HP·방어막
5. 주문 카드와 시전 가능 상태
6. 상태 메시지와 전투 기록

드로잉 중에는 중요도가 낮은 텍스트의 밝기를 줄여 시선을 입력판에 집중시킨다.

## 9. 플레이어 상태 영역

### 9.1 구성

- 익명 주인공을 나타내는 손 문양 또는 관리국 신원 오류 아이콘
- 현재 HP 바와 수치
- 초급 방벽 수치
- 상태 아이콘

### 9.2 피해 표시

- 실제 HP: 붉은 게이지
- 지연 HP: 밝은 적색 또는 흰색 잔상
- 피해 시 지연 게이지가 먼저 남고 0.4초 뒤 실제값을 따라간다.
- 방어막이 있으면 방어막 게이지가 먼저 깨진다.
- HP 25% 이하에서는 영역 가장자리가 천천히 경고하지만 계속 깜빡이지 않는다.

## 10. 적 상태 영역

### 10.1 구성

- 적 이름과 층 분류
- HP 바와 수치
- 일반 또는 절대 방어막
- 현재 특수 상태

### 10.2 방어막 표현

일반 방어막:

- 청백색 얇은 게이지
- 수치 표시
- 한 겹의 유리 또는 문서 모양 아이콘

절대 방어막:

- 금색 봉인 인장
- 남은 횟수 아이콘
- 적 모델 주변의 격자형 차폐막
- `절대`라는 짧은 라벨

색각 차이가 있어도 실루엣과 아이콘으로 구분할 수 있어야 한다.

## 11. 적 행동 예고

### 11.1 위치

상단 오른쪽에 적 상태 영역과 가까이 배치한다. 장식용 세로 아이콘 목록은 제거하고 현재 행동과 예약된 강공격만 보여준다.

### 11.2 표시 정보

| 행동 | 아이콘 형태 | 라벨 |
| --- | --- | --- |
| 일반 공격 | 칼날 또는 파편 | 공격 |
| 일반 방어막 | 한 겹 방패 | 방벽 |
| 절대 방어막 | 봉인 인장이 있는 방패 | 절대 방벽 |
| 강공격 예고 | 조준 렌즈 | 집중 |
| 강공격 | 붉은 광선 | 강공격 |

- 최초 등장 시 아이콘과 라벨을 함께 표시한다.
- 익숙해진 뒤에도 라벨을 숨기지 않는다.
- 구체적 피해량은 데모 기본 설정에서 표시하지 않는다.
- 강공격은 붉은 테두리, 사운드와 적 모델의 준비 동작을 함께 사용한다.

## 12. 마나와 획 표시

### 12.1 마나

- 화면 하단 왼쪽의 원형 또는 반원형 잉크통 형태
- 숫자를 표시하지 않는다.
- 선을 그린 실제 거리만큼 연속해서 감소한다.
- 25% 이하에서 중심광이 약해지고 가장자리에 균열이 생긴다.
- 말소 구역 안에서는 감소 속도가 빨라지는 것이 눈으로 보여야 한다.

### 12.2 획

- 마나 게이지 주변에 펜촉 아이콘 두 개를 배치한다.
- 사용 가능한 획: 밝은 펜촉
- 현재 사용 중인 획: 맥박 또는 흐르는 빛
- 사용 완료: 비어 있는 외곽선
- 2획 주문 선택 시 두 펜촉을 하나의 연결선으로 묶어 보여준다.

## 13. 주문 카드

### 13.1 기본 구성

- 하단 중앙에 최대 5장
- 중앙에 축소 문양
- 하단에 짧은 주문명
- 좌측 상단에 카테고리 아이콘
- 하단 또는 우측에 요구 획수
- 테두리와 인장에 주문서 등급색

### 13.2 상태

| 상태 | 표현 |
| --- | --- |
| 기본 | 문양과 이름 표시 |
| 선택 | 테두리 점등, 입력판과 빛으로 연결 |
| 사용 가능 | 정상 밝기 |
| 획 부족 | 펜촉 아이콘 적색, 카드 어둡게 |
| 마나 위험 | 마나 아이콘 경고, 선택 허용 |
| 대상 없음 | 기능 아이콘 경고, 선택 허용 |
| 사용 완료 | 해당 턴 동안 일시적으로 빛 감소 |

### 13.3 카드 선택

- 탭 한 번으로 선택한다.
- 같은 카드를 다시 눌러도 선택 취소하지 않는다.
- 다른 카드를 누르면 첫 획 시작 전에는 즉시 변경한다.
- 획 시작 뒤에는 현재 주문을 완료하거나 취소해야 변경할 수 있다.
- 길게 누르면 주문 효과와 요구 획을 보여주는 간단한 정보창을 연다.

## 14. 드로잉 입력판

### 14.1 영역

- 화면 중앙 하단의 바닥 원근에 맞춰 배치한다.
- 실제 입력 좌표는 원근을 제거한 논리 좌표로 변환한다.
- 손이 하단 카드를 가리지 않도록 카드 위쪽에 충분한 입력 높이를 확보한다.
- 입력판 밖의 UI에서는 선을 시작하지 않는다.

### 14.2 가이드 층

아래에서 위 순서로 렌더링한다.

1. 입력판 표면과 격자
2. 말소 구역과 환경 방해 요소
3. 다음 획의 옅은 경로
4. 핵심점과 시작·종점
5. 플레이어가 그린 선
6. Pencil 끝 글로우와 입자
7. 판정 및 오류 표시

### 14.3 드로잉 상태

- 대기: 시작점이 천천히 점등
- 입력 중: 다음 핵심점과 남은 마나 강조
- 획 완료: 선을 고정하고 다음 시작점 표시
- 검수: 입력을 잠시 잠그고 문양 전체 점등
- 성공: 문양이 적 또는 플레이어 쪽으로 발동
- 실패: 잘못된 구간만 붉게 표시한 뒤 선을 흐리게 제거

### 14.4 말소 구역

- 검은 잉크 얼룩과 붉은 말소 인장으로 표시한다.
- 가이드보다 아래, 입력판보다 위에 둔다.
- 선이 진입하면 해당 구간이 끊기듯 흐려진다.
- 영역이 핵심점과 겹칠 경우 핵심점은 가려지지 않도록 위에 표시한다.

## 15. 시전 판정 표시

### 15.1 위치와 시간

- 입력판 중심 위에 0.8~1.2초 표시한다.
- 적과 주문 발동을 완전히 가리지 않는다.
- 연속 시전 시 첫 결과는 작게 축소되어 전투 기록으로 이동한다.

### 15.2 등급 표현

| 등급 | 표현 |
| --- | --- |
| 시전 반려 | 붉은 검수선, 짧은 오류음 |
| 불완전 승인 | 불안정한 문양과 약한 점등 |
| 시전 승인 | 안정된 기본 글로우 |
| 정밀 승인 | 선 바깥의 정교한 보조 문양 |
| 완전 각인 | 전체 문양의 순간 각인과 강한 햅틱 |

### 15.3 실패 원인

등급 아래 한 줄만 표시한다.

- 핵심 지점 누락
- 획수 초과
- 시작점 불일치
- 교차점 불일치
- 마나 고갈
- 문양 미완성

한 번에 여러 문제가 있어도 가장 결정적인 원인 하나만 보여준다.

## 16. 턴 종료 버튼

- 하단 오른쪽에 배치한다.
- 원형 관리국 인장과 `턴 종료` 라벨을 함께 사용한다.
- 첫 주문 전에도 누를 수 있지만 확인을 한 번 요청한다.
- 주문 하나 이상 시전한 뒤에는 즉시 종료한다.
- 획 또는 마나를 모두 사용하면 버튼이 자동 진행 상태로 바뀐다.
- 적 행동 중에는 비활성화하고 진행 상태를 보여준다.

## 17. 주문 습득 화면

- 탐색 배경 위에 새 두루마리가 펼쳐진다.
- 주문명과 카테고리를 먼저 보여준다.
- 문양 전체가 획순에 따라 한 번 그려진다.
- 요구 획수와 핵심 효과를 짧게 표시한다.
- `등록`을 누르면 두루마리가 하단 카드 위치로 이동한다.
- 긴 설명은 주문 정보창에서 다시 확인한다.

## 18. 두루마리 보상 화면

### 18.1 배치

```text
┌──────────────────────────────────────────────┐
│              보존 기록 3건 감지               │
│                                              │
│       [두루마리 A] [두루마리 B] [두루마리 C]   │
│                                              │
│              하나만 복원할 수 있습니다          │
└──────────────────────────────────────────────┘
```

- 세 두루마리를 같은 크기로 나란히 배치한다.
- 선택 전에는 정확한 효과와 문양을 보여주지 않는다.
- 상단에 이름 일부와 `(공격)`, `(방어)`, `(해제)` 같은 카테고리만 표시한다.
- 외형과 빛으로 등급을 표현한다.

### 18.2 선택 과정

1. 두루마리를 누르면 앞으로 조금 이동한다.
2. 다시 누르거나 하단의 `복원` 버튼으로 확정한다.
3. 확정 전에는 다른 후보로 변경할 수 있다.
4. 확정하면 선택한 두루마리가 펼쳐진다.
5. 나머지 두 개는 글자가 지워지고 재처럼 사라진다.
6. 새 주문 정보를 공개하고 카드에 등록한다.

선택하지 않은 보상의 정체는 기록 메뉴에서도 공개하지 않는다.

## 19. 문 개방 화면

- 전투 HUD와 주문 카드를 모두 숨긴다.
- 문과 관리국 패널이 화면 상단 또는 배경 중심에 보인다.
- 입력판에는 해당 층의 하강 문양만 표시한다.
- 마나는 거의 제한하지 않고 획수만 문양 요구에 맞춘다.
- 판정은 `승인` 또는 `재제출`만 사용한다.
- 실패 시 문이 반응하지 않고 잘못된 구간을 보여준다.
- 성공 시 입력판 문양이 문 위로 이동해 봉인과 겹쳐진다.

## 20. 기록 열람 화면

- 층별 탭으로 발견 기록을 분류한다.
- 필수 기록과 선택 기록을 시각적으로 구분하지 않는다.
- 발견하지 않은 기록의 제목과 개수를 숨겨 수집 압박을 줄인다.
- 본문, 출처 층, 문서 상태와 관리국 분류만 표시한다.
- 전투 중에는 열 수 없고 탐색과 일시정지 상태에서만 연다.

## 21. 일시정지와 설정

### 21.1 일시정지

- 계속하기
- 현재 전투 다시 시작
- 층 시작부터 다시 시작
- 설정
- 타이틀로 이동

진행 손실이 있는 선택에는 확인 창을 사용한다.

### 21.2 설정

입력:

- Pencil 우선
- 손가락 드로잉 허용
- 선 떨림 보정 강도
- 왼손잡이 UI

화면:

- 화면 흔들림 감소
- 섬광 감소
- 마법 글로우 강도
- 피해 숫자 표시

음향과 햅틱:

- 음악
- 효과음
- 햅틱

접근성:

- 높은 대비
- 가이드 강화 고정
- 텍스트 크기
- 튜토리얼 초기화

## 22. 왼손잡이 모드

- 마나와 획 영역을 하단 오른쪽으로 이동한다.
- 턴 종료 버튼은 하단 왼쪽으로 이동한다.
- 주문 카드는 중앙을 유지한다.
- 적 행동 예고와 HP는 상단에 유지해 정보 위치가 과도하게 바뀌지 않게 한다.
- 입력판 자체는 이동하지 않는다.

## 23. 접근성 기준

- 색상만으로 상태를 전달하지 않는다.
- 주요 버튼의 터치 영역은 최소 44pt를 확보한다.
- 카드 이름이 한 줄에 맞지 않으면 두 줄을 허용하고 글자를 과도하게 줄이지 않는다.
- 화면 흔들림 감소 시 카메라 이동을 밝기와 파편 효과로 대체한다.
- 섬광 감소 시 완전 각인의 흰색 점멸을 짧은 외곽광으로 대체한다.
- 가이드 강화는 난이도를 수치로 낮추지 않고 시각 정보만 늘린다.
- 손가락 모드에서는 터치 지점보다 선의 시작을 조금 위에 표시해 손에 가리지 않게 한다.

## 24. 상태 메시지 규칙

- 화면에 동시에 하나의 주요 메시지만 표시한다.
- 문장은 한 줄 또는 두 줄 이내로 제한한다.
- 같은 경고는 한 주문 시도에 한 번만 보여준다.
- 중요한 메시지는 전투 기록에 짧게 남긴다.
- 관리국 문체를 유지하되 플레이어가 원인을 이해할 수 있어야 한다.

예시:

- `시전 반려: 핵심 지점 누락`
- `획 일부 말소됨`
- `절대 방어막: 공격 효과 무효`
- `남은 획 부족`
- `문양 불일치. 재제출 필요`

## 26. UI 검증 체크리스트

- 11형과 13형 iPad에서 주문 카드 5장이 겹치지 않는가
- Pencil을 쥔 손이 다음 핵심점과 마나를 동시에 가리지 않는가
- 적과 입력판이 서로 시각적으로 충돌하지 않는가
- 일반 방어막과 절대 방어막을 흑백에서도 구분할 수 있는가
- 남은 획을 숫자 설명 없이 이해할 수 있는가
- 드로잉 중 UI 요소가 레이아웃을 바꾸지 않는가
- 가장 긴 주문명이 카드 안에 안정적으로 표시되는가
- 말소 구역과 공격 가이드가 겹쳐도 둘 다 읽히는가
- 연속 시전 때 첫 판정 메시지가 다음 입력을 방해하지 않는가
- 왼손잡이 모드에서 턴 종료 오입력이 줄어드는가
