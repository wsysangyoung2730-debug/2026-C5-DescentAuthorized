### Changed

- 루트 문서를 항상 최신 기준으로 관리하도록 정책 확정
- 현재 구현을 먼저 정리한 뒤 출시 목표로 확장하는 갱신 순서 확정
- 출시 1.0의 상위 범위를 1층부터 10층까지의 완결된 진행으로 기록
- 7·6·5층 임시 초안은 구현 기준으로 사용하지 않고 사용자 확정 기획 이관 후 삭제하도록 관리 조건 명시
- 전투 시작 전 고정 설명을 화면 차단형 단계 안내로 교체하고, 재시작 시 완료한 설명이 반복되지 않도록 변경
- 동작 줄이기 설정이 튜토리얼 전환과 카메라 연출에도 적용되도록 범위 확장
