# 봉인된 주문 카드 UI

- 브랜치: `feat/#189-sealed-card-artwork`
- 기준: `5b39284` — 188번 선택창 및 187번 층 제목 이미지 작업 포함
- 이슈: #189

## 적용 범위

전투 공통 `BattleView.spellCard`가 실제 `lockedSpells` 상태를 읽는다. 3층 동의 보관 잔류체(선택 1턴), 자발 격리 관리자(선택 3턴), 5층 기억 원본 관리자(자동 1턴), 1층 관리자 2·3단계(자동 3턴)에 동일하게 적용된다. 앞으로 같은 봉인 상태를 사용하는 적도 공통 표시를 사용한다. 주문서 희귀도인 ‘봉인 주문서’와 일시적인 주문 봉인은 별개다.

## 표시

- `SealedCardChains`, `SealedCardEmblem`, `SealedCardTurnBadge` 투명 PNG 원본 등록. 표시 시 투명 여백만 제거한다.
- 기존 점선 X·기본 자물쇠·붉은 봉인 글자 대신 사슬과 보라색 봉인 인장을 문양 영역에 표시한다.
- 카드 테두리와 문양을 약하게 하고 주문명·효과는 계속 읽을 수 있게 유지한다.
- `봉인 · N턴`과 `시전 불가`를 실제 텍스트로 표시한다. 등급 배지를 작게 해 좁은 카드에서도 봉인 배지와 겹치지 않게 한다.
- 남은 기간은 만료되는 적 턴을 포함한다. 플레이어 입력 중에는 현재 턴을 포함하고 적 행동 및 다음 턴 준비 중에는 다음 플레이어 턴부터 센다.
- 봉인 만료·정화로 상태가 제거되거나 전투가 종료되면 장식이 사라진다. 주문 선택 차단 및 정화 등 전투 규칙은 그대로 유지한다.
- VoiceOver에 남은 봉인 턴과 시전 불가 상태를 전달한다. 장식은 터치를 받지 않는다.

## 최소 검증

- 봉인 선택/보호 카드 기존 테스트, 자동 봉인 기존 테스트, 선택·자동·예약 봉인의 남은 기간/만료 테스트 총 3건 통과.
- 기간 테스트는 1턴·3턴, 적 행동 표시, 전투 종료 및 봉인 제거 시 표시 해제를 포함한다.
- DEBUG `--preview-sealed-card`는 메모리 저장을 사용하는 하층 전투 미리보기에서 실제 후보 선택 및 턴 종료 명령으로 봉인 화면을 재현한다.
- 최종 iPad 시뮬레이터 Debug 빌드 성공, `git diff --check` 통과.
- 3층 관리자에서 실제 선택·턴 종료 명령 후 2턴의 ‘균열 절단’ 카드에 봉인 3턴, 사슬/인장, 시전 불가 및 주문 설명이 함께 표시되는 화면을 확인했다.
- 화면 기록: 작업 공간 `outputs/sealed-card-integration/boss-sealed.png` (시뮬레이터 원본 방향).

사용자 요청에 따라 여기서 검증을 종료했다. 다른 층의 개별 화면, 실기기 및 직접 터치 검증은 확대하지 않았다. 공통 표시 연결과 봉인 방식별 코어 테스트로 적용 범위를 확인했다.

## 사슬 크기 후속 수정

사슬을 76pt 문양 영역에서 카드 전체 영역으로 옮겼다. 사슬 끝이 카드 밖까지 이어진 뒤 카드 경계에서 잘려 카드 전체를 감싸는 형태가 되도록 확대했다. 봉인 인장은 44pt로 키웠으며, 주문명과 효과 뒤에는 얇은 어두운 바탕을 두어 사슬이 지나가도 읽을 수 있게 했다.

사용자가 직접 검증하기로 하여 이번 후속 수정의 최종 빌드·테스트·화면 검증은 수행하지 않았다.
