# #208 App Store 출시 준비 점검

**판정: 현재 상태 그대로의 제출은 보류 권장.** Release는 빌드되지만 필수 사유 API 선언과 앱 내 개인정보·지원 경로에 확정 미비점이 있다. 이 점검은 문제 분석과 증거 기록이며, 발견한 앱 동작·설정을 수정 완료한 작업이 아니다.

- 점검일: **2026-10-02 (KST)**
- 앱 코드 기준: 최신 원격 `fix/#207-acquisition-glyph-fidelity` / `57d03f0`
- [이슈 #208](https://github.com/wsysangyoung2730-debug/2026-C5-DescentAuthorized/issues/208)
- 전용 브랜치: `docs/#208-app-store-readiness` — 이슈 하나, 브랜치 하나, 분야별 세부 커밋
- 앱 소스·게임 에셋·배포 설정 변경 없음. 서명·스토어 업로드·심사 제출 없음.

## 우선 해결할 사항

| 순서 | 판단 | 현재 문제 | 다음 조치 |
| --- | --- | --- | --- |
| 1 | **제출 전 필수 · 확정** | Release에서 `systemUptime` 사용, 개인정보 명세에 SystemBootTime 사유 없음 | 실제 용도에 맞는 `35F9.1` 추가 후 새 아카이브에서 확인 |
| 2 | **제출 전 필수 · 확정** | 앱 안에 개인정보처리방침 링크와 지원·문의 경로 없음 | 운영자·실제 문의 수단·정책 확정 → 공개 페이지 → 앱 연결 → App Store Connect URL 대조 |
| 3 | **출시 전 수정 권장 · 확정** | 한국어 UI인데 Release 번들의 언어는 `en`, 한국어 선언 없음 | 한국어 지원을 정확히 선언. 영어 지원을 실제보다 넓게 표시하지 않음 |

| 5 | **출시 전 재현·보완 권장 · 화면 관측** | 새 iPad mini 시뮬레이터를 세로로 켜면 홈이 작은 가로 영역으로 표시 | 실기기 첫 실행·회전·복귀·창 모드 확인. 가로 전용 정책에 맞는 표시/회전 안내 |
| 6 | **출시 전 확인 필요** | 모델·UI·현재 18개 음원의 상업 배포 권리 증빙을 저장소에서 확인하지 못함 | 제작/구매/생성 근거와 상업 배포·크레딧 조건 확인. 침해가 확정됐다는 의미는 아님 |
| 7 | **출시 전 확인 필요** | Game Center 운영 업적 8개, 서명, 스토어 입력값 미검증 | App Store Connect 대조 및 서명된 TestFlight/실기기 인증·취소·업적 보고 확인 |
| 8 | **출시 전 확인 필요** | 지원하는 구형 iPad의 메모리·발열·전 층 장시간 플레이 미검증 | 최소 사양과 주력 실물 iPad에서 10→1층 및 종료·복원 검증 |

1번은 [필수 사유 API 규칙](https://developer.apple.com/documentation/bundleresources/describing-use-of-required-reason-api), 2번은 [App Review Guidelines 5.1.1(i), 1.5](https://developer.apple.com/app-store/review/guidelines/)와 직접 연결된다. 나머지 항목은 실제 결함·품질 위험·외부 증빙 미확인을 구분했으며 모두를 ‘확정 심사 거절’로 묶지 않는다.

## 확인된 결과

- **코어 테스트 235개 통과**.
- **기기용 Release 아카이브와 시뮬레이터 Release 빌드 성공**. 기기용 아카이브는 서명 제외.
- 아카이브 `.app` **1,598,904,526바이트(약 1.60GB)**. 현재 비압축 앱 크기 한도 초과 없음. 다운로드 크기·실기기 메모리 사용량과는 다름.
- Reality 리소스 **2,972개 해시 일치**, 누락·내용 차이·추가 0개.
- 아이콘 **1024×1024, RGB, alpha 없음**, 실제 아카이브 아이콘 참조 정상.
- 현재 Xcode 26.5 / SDK 26.5는 [Apple의 현재 최소 제출 요구](https://developer.apple.com/news/upcoming-requirements/) 충족.
- 일반 Release 앱에서 **홈 → 설정 → 미인증 Game Center 안내 → 10층 튜토리얼 → 백그라운드/종료 → 이어하기 → 10층 복원**을 직접 확인.
- Release 시작은 일반 홈이며 선택한 DEBUG 진단 인자 5개는 바이너리에 없음.
- 직접 확인한 코드에는 자체 계정·결제·광고·추적·이용자 게시물·카메라·녹음 기능이 없음. Game Center의 Apple 업적 전송은 존재한다.

## 추가 품질 점검

시스템 ‘동작 줄이기’와 일부 3D 연출 연결, 문양 입력판 VoiceOver 접근, 포인터 지원 범위, 체크포인트 복원 설명, 오래된 문서의 데모 표기는 보완 또는 정확한 안내가 필요하다. 내부 `Demo` 타입명, `0.1.0` 버전, 가로 전용이라는 사실만으로 심사 거절을 단정하지 않았다.

암호화 선언 키 부재도 곧바로 위반은 아니다. 실제 사용에 따라 [수출 규정 질문](https://developer.apple.com/help/app-store-connect/manage-app-information/overview-of-export-compliance/)을 완료해야 한다. 연령은 판타지 전투·무기·공포 분위기를 [현재 설문](https://developer.apple.com/help/app-store-connect/reference/app-information/age-ratings-values-and-definitions/)에 반영한 후 산정하며 여기서 숫자를 임의로 확정하지 않는다.

현재 개인정보 명세, 이용자용 처리방침, App Store 개인정보 라벨은 별개다. 자체 서버가 없다는 이유로 Game Center까지 ‘전송 없음’이라고 설명하면 안 된다. 로컬 저장만으로 개발자의 외부 수집을 단정하는 것도 부정확하다.

## 음향 및 추가 변경 후 재확인

번들 음원 추가는 그 자체로 새 개인정보 권한을 요구하지 않는다. 사용 권리, 실제 재생, 볼륨·무음·백그라운드·Bluetooth·인터럽션·중복 재생·용량·발열을 새 후보 빌드에서 확인한다. 원격 다운로드나 외부 SDK, 녹음, 결제·광고 기능이 추가되면 해당 개인정보·심사 항목도 다시 감사한다.

개발자 연락처, 정책 URL, 출시 지역, 가격, 연령 등급, 권리 보유 사실, 스토어 개인정보 응답을 이 점검에서 임의로 정하지 않았다. 앱 수정은 위 순서대로 진행하고 각 조치를 새로운 Release 후보의 증거와 연결하는 것이 적절하다.
