- 이 문서는 심사 승인, 서명된 배포본 검증 또는 실기기 검증을 대신하지 않는다.

## 점검 방법

1. 개인정보·권한·외부 SDK·데이터 흐름 정적 분석
2. 실제 Release 진입 경로, 저장·복원, 게임 완결성과 표시 문구 분석
3. iPad 기기용 Release 아카이브(서명·업로드 제외), 포함 리소스·아이콘·용량 검사
4. 현재 코어 테스트와 시뮬레이터에서 가능한 출시 경로 확인
5. 에셋 사용 권리, 지원·개인정보 URL, Game Center, 연령·지역·수출 관련 제출 항목 구분

## 판정 원칙

- **확정 문제**: 현재 저장소 또는 산출물에서 재현/입증한 결함
- **출시 전 확인 필요**: App Store Connect·권리 증빙·실기기 등 저장소 밖의 확인 필요
- **품질 권고**: 특정 심사 거절을 단정할 수 없는 사용성·유지보수 개선
- **확인됨**: 실제 수행한 검사 범위에 한정

음향 추가, SDK 변경, 권한·네트워크·결제 도입, 에셋 교체 후에는 해당 항목을 다시 검사해야 한다. 이 점검 중에는 출시 버전 번호, 배포 지역, 가격, 사업자·개인정보 연락처를 임의로 정하지 않는다.

상세 결과와 증거는 후속 커밋으로 이 디렉터리에 기록한다.
