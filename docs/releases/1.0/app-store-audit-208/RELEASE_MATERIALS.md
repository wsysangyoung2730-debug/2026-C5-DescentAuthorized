## 판정

아이콘과 iPad 타깃 구성에서 즉시 실패할 형식 문제는 확인하지 않았다. 다만 **앱 안의 개인정보 처리방침·지원 연락 경로가 없고, 한국어 UI와 번들의 언어 선언이 다르다.** 권리 증빙과 스토어 등록 상태도 확인되지 않아 현재 상태를 제출 준비 완료로 판정할 수 없다.

아래의 미확인 항목은 위반 확정을 뜻하지 않는다. 특히 라이선스 문서가 저장소에 없다는 사실만으로 에셋의 무단 사용이나 저작권 침해를 단정할 수 없다.

- 앱에 포함되는 파일/묶음과 버전 또는 해시
- 제작자 또는 제공 서비스, 원본 출처
- 직접 제작·구매·위탁·생성 중 취득 방식과 취득일
- 상업 앱 포함/재배포 허용 근거, 필요한 구독 플랜 또는 계약
- 크레딧/저작권 고지 의무 및 적용 위치
- 증빙 보관 위치와 최종 확인자

## Game Center

현재 소스는 8개 업적을 보고한다 (`Core/Game/GameAchievements.swift:3–11`). 앱 설정에는 로그인 상태, 재연결, 업적 보기와 동기화 오류 표시가 있다 (`Features/Settings/SettingsView.swift:412–458`). entitlement도 활성화되어 있다.

`docs/GAME_CENTER_SETUP.md:11–36`은 임시 ID와 App Store Connect 작업을 설명하지만, 해당 작업이 현재 계정에서 완료됐다는 증거는 아니다. 다음을 확인해야 한다.

- [ ] Bundle ID와 배포 프로필에 Game Center 구성이 일치한다.
- [ ] 8개 업적의 정확한 ID가 등록되어 있고 현재 게임에 맞는 이름·설명·이미지·점수를 사용한다.
- [ ] `spellArchive`의 현 코드 조건(전체 `SpellID` 수 기준)을 오래된 문서의 “데모 주문 5종” 설명과 혼동하지 않는다.
- [ ] `descentProcedure`/`demoCompleted` 등 기존 ID의 실제 달성 조건과 사용자가 보는 문구가 일치한다.
- [ ] Game Center 미로그인·인증 취소·오프라인 상태에서도 게임 진행과 저장을 계속할 수 있다.
- [ ] TestFlight 또는 적절하게 서명된 실제 iPad에서 업적 보고, 재시도, 계정 변경, 배너를 확인한다.

`demoCompleted`와 같은 내부 식별자는 그 자체로 출시 앱이 데모라는 근거가 아니다. 변경할 경우 이미 등록된 서버 ID와 저장 이력 영향을 먼저 확인해야 한다.

## App Store Connect에서 확인할 제출 목록

이 항목들은 현재 저장소에서 확정할 수 없다. 체크되지 않았다는 이유만으로 실제 콘솔에도 입력되지 않았다고 단정하지 않는다.

- [ ] 앱 이름·부제·설명·키워드·주요 언어가 현재 한국어 게임 내용과 일치한다.
- [ ] 지원 URL에서 실제 문의가 가능하며 공개 개인정보 처리방침 URL이 정상 동작한다.
- [ ] 개인정보 표시 내용이 로컬 저장, Game Center 및 실제 외부 전송 흐름과 맞는다.
- [ ] 저작권 표시, 가격, 출시 지역, 운영 주체 정보가 최종 확정되어 있다.
- [ ] 연령 등급 설문에 판타지 전투, 무기, 붕괴/처치 및 공포 분위기 등 실제 콘텐츠를 반영한다. 이 감사에서는 최종 등급 숫자를 정하지 않는다.
- [ ] 배포 지역에 따라 필요한 게임 등급·사업자/거래자 관련 정보를 확인한다. EU 배포 시 관련 콘솔 항목도 확인한다.
- [ ] 스크린샷은 제출할 앱의 실제 플레이 화면이며 요구 규격에 맞고 디버그 오버레이·오래된 UI를 포함하지 않는다.
- [ ] 설명과 스크린샷은 10층부터 1층까지의 실제 출시 범위, 손가락 입력 가능 여부, 현재 제공 기능과 일치한다.
- [ ] 리뷰 연락처와 심사 메모에 한국어 게임이라는 점, 손가락/Pencil 조작, Game Center의 역할, 주요 진행 방법을 설명한다.
- [ ] Game Center 설정, 수출 규정 질문, 해당 버전의 제출 상태를 확인한다.
- [ ] 접근성 표시 등 스토어에서 자발적으로 선언할 지원 기능은 실제 검증한 범위만 선택한다.
- [ ] 서명된 업로드를 Apple 검증 단계에 통과시키고 TestFlight에서 첫 실행과 저장 복구를 확인한다.

별도 앱 계정·유료 결제·광고·추적·사용자 게시 기능을 추후 추가한다면 현재 결과를 그대로 적용할 수 없다. 해당 기능의 코드·개인정보·심사 요구를 다시 점검해야 한다.

## 음향을 추가하거나 교체할 때

사용자는 음향을 더 추가할 예정이라고 밝혔다. 현재 포함된 파일은 18개이며 `App/GameFeedbackManager.swift:34–80`에 MP3/WAV 파일명이 매핑되어 있다. `docs/AUDIO_ASSET_MANIFEST.md:9–35`의 “실제 음원 없음”과 `.m4a` 목록은 현재 상태를 반영하지 않는다.

- [ ] 새 음원의 상업 배포 권리와 크레딧 조건을 위의 원장에 기록한다.
- [ ] 코드 이름·확장자·실제 번들 경로를 대조하고 모든 사건과 반복 배경음이 실제 기기에서 재생되는지 확인한다.
- [ ] 배경음/효과음 끄기와 볼륨 설정을 존중하고 중복 반복 재생·소리 겹침·루프 경계의 클릭을 확인한다.
- [ ] 일시정지·백그라운드·복귀·통화/시스템 음향 중단·헤드폰 전환 후 재생 상태를 확인한다.
- [ ] 긴 음원 때문에 시작/전투 프레임이 멈추거나 메모리·배터리 부담이 커지지 않는지 확인한다.
- [ ] 높은 피크 음량·클리핑·깜짝 효과의 세기가 의도에 맞는지 확인하고 시각 안내만으로도 필수 게임 정보를 이해할 수 있게 한다.
- [ ] 원격 음원 서비스, 음성 녹음 또는 새 SDK를 넣는다면 권한·네트워크·개인정보·매니페스트 점검을 다시 수행한다.

현재 재생 코드는 `.ambient`와 `.mixWithOthers`를 사용하고 (`GameFeedbackManager.swift:642–649`), 파일 누락/디코딩 실패 시 nil을 반환한다 (`:623–638`). 이는 누락 시 크래시를 피하는 구조를 확인한 것이며, 모든 음원이 들린다거나 실제 기기의 음향 인터럽트 처리가 완료되었다는 증거는 아니다.
