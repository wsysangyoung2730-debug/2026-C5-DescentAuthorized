# #201 전투 중 다음 방 사전 준비

## 변경 내용

- 다음 잔류체/보스방/하층을 진행 상태로 결정한다. 4~1층 잔류체 A→B→보스까지 포함한다.
- 전투 중에는 utility 작업으로 모델·텍스처 파일을 최대 1MB씩 읽는다. 입력/카메라 이동/공격 연출 중에는 다음 읽기를 기다린다.
- RealityKit 모델 디코딩은 전투 종료 및 처치 연출 종료 후 대화·보상 시간에 한 개씩 수행한다. 다음 방 템플릿 하나만 유지하며 저메모리 경고 시 비운다.
- 프레임 지연 뒤 2초, 입력 뒤 1.2초, 카메라 이동, 앱 비활성, 심각한 발열, 여유 메모리 부족 상태에서는 사전 작업을 기다린다.

## 검증

`warmup.json`: 4·3·2·1층 잔류체 A→B 실제 렌더링 중 측정. 모든 실행에서 전투 중 디코딩 없음, 공격 연출 중 시작 보류, 파일 준비 및 후속 방 준비 성공.

| 층 | 전투 중 파일 준비 | 전투 중 p95 / 최대 프레임 간격 | 종료 후 디코딩 | 준비된 방 전환 |
|---|---:|---:|---:|---:|
| 4 | 2.84s | 16.69 / 17.19ms | 1.05s | 0.325s |
| 3 | 2.93s | 16.70 / 16.78ms | 1.36s | 0.339s |
| 2 | 3.08s | 16.69 / 17.26ms | 2.57s | 0.347s |
| 1 | 3.29s | 16.69 / 17.26ms | 4.39s | 0.462s |

전투 중 전체 디코딩을 시도한 초기 측정에서 최대 155.6ms 지연이 보여 위의 두 단계 방식으로 변경했다. 준비된 방 전환 수치는 준비 완료 후 CPU ready까지이며 전체 로딩이 항상 이 시간이라는 뜻이 아니다. 대화/보상을 빠르게 넘겨 준비가 끝나지 않으면 남은 작업은 기존 로딩 화면에서 끝낸다. sourceColdReadySeconds는 다른 방이므로 직접적인 속도 개선 배수로 비교하지 않는다.
