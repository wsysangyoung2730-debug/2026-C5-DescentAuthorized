# #206 봉인 해제 조건과 예약 자동 취소

## 변경 내용

- 절대 방벽이 없으면 봉인 해제 주문을 사용할 수 없다. 일반 방벽만 있는 경우도 동일하다.
- 2획 예약 취소는 대상 선택 메뉴 없이 가장 빠른 집행 턴을 자동 선택한다. 동률이면 기존 등록 순서를 유지하며 집행 무효화는 해당 턴 최대 2건을 취소한다.
- 이전 수동 선택값이 남아 있어도 자동 취소의 선택/검증에 영향을 주지 않는다. 다른 대상 지정 주문은 기존 방식을 유지한다.
- 결과 말소는 예약이 없고 일반 방벽만 남은 경우 기존 의도대로 방벽을 대상으로 한다.

## 검증

핵심 테스트 235개 통과. 늦은 예약을 먼저 등록한 경우에도 빠른 예약을 먼저 취소하고, 이전 선택값은 무시하는 테스트를 포함한다. 절대 방벽 유무, 일반 방벽만 존재, 예약 우선순위, 방벽 대체 대상도 확인.

`issue-206-unavailable.png`: 8층에서 절대 방벽을 해제한 다음 봉인 해제 카드가 비활성인 실제 앱 화면. 자동 취소 메뉴 제거는 코드와 핵심 명령 테스트로 확인했으며 하층에서의 수동 터치 전체 플레이는 미실시.
