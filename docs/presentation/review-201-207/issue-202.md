- 파편 낙하/소멸 1.05초 뒤 안정 시간 0.35초를 더 확보한다.
- 전투 상태를 지우거나 동작 줄이기를 변경해도 처치된 모델을 복원하지 않는다.

`issue-202-no-resurrection.png`: 실제 8층 처치 후 대화 전환 상태에서 보스가 없는 화면.

핵심 타임라인 테스트에서 추가 안정 시간이 반영되었음을 확인했다. 이 장면 진단은 실제 전체 대화를 수동으로 넘기는 연속 플레이를 대체하지 않는다.
