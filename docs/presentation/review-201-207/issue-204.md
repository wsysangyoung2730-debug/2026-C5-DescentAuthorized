# #204 하강문 개구부와 고정 발판

## 변경 내용

- 모든 하강문 이펙트 메시를 원래 개구부 경계에 맞춘 사각 면으로 바꾸고 타원형 비네팅을 제거한다. 기존 문틀과 문짝 개폐는 유지한다. 2층의 원형 기계 문틀/조리개 형태 자체는 유지된다.
- 모든 문양 입력 상태(대기/입력/실패/승인)에서 발판 흔들림과 크기 변화 제거.
- 중앙문 목적지 텍스트 제거. 5층 잔류체→보스방 문 시점만 원래 카메라 방향으로 0.45m 전진.

## 검증

`issue-204-scenes.json`: 10~1층 전체 하강문과 5층 중앙문에서 입력·실패·승인 후 발판 transform 불변, 문 열림 완료 확인. 모든 층 열린 문 캡처를 확인했다.

`issue-204-middle-gate.png`: 5층 중앙문 접근 시야.
`issue-204-rectangular-veil.png`: 4층 전체 개구부를 채우는 사각 이펙트.

문틀 원형 여부는 원본 건축 형태이며 이펙트 메시와 별개다. 2층 원형 문틀의 금속 부분이 사각 이펙트를 일부 가린다.
