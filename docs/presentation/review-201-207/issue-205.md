# #205 최초 절대 방벽 안내와 금빛 효과

## 변경 내용

- 모든 층 절대 방벽에 기존 금색 와이어 구체 효과 복원. 일반 방벽은 유지.
- 8층 첫 절대 방벽에서는 봉인 해제를 비활성으로 시작한다.
- 첫 시전 또는 첫 턴 진행 후 연출이 끝나면 5층과 동일한 전투 규칙 안내를 표시한다. 확인하면 저장된 안내 플래그로 중복 노출을 방지한다.

## 검증

`issue-205-guide.json`: 격리된 저장 상태에서 실제 게임 명령으로 8층 첫 전투를 진행했다.

1. initial-disabled: 방벽 1, 안내 없음, 봉인 해제 불가.
2. after-first-action: 첫 공격을 막은 뒤 안내 표시, 봉인 해제 가능.
3. guide-confirmed: 안내 확인 기록, 안내 닫힘, 봉인 해제 가능.
4. released-disabled: 방벽 0, 안내 없음, 봉인 해제 불가.

`issue-205-gold-barrier.png`, `issue-205-first-action-guide.png` 실제 앱 캡처 확인. Mac 잠금으로 수동 클릭은 진행하지 못했으며 DEBUG 진단이 실제 명령을 수행했다. 사용자 저장 파일은 사용하지 않았다.
