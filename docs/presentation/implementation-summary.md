아래 브랜치는 순서대로 앞 브랜치의 변경을 포함한다. 전체 결과는 **add/#192-acquisition-glyph-assets**에 있다.

이미지 생성 대기 중 다른 구현을 진행했으므로, 획득 이미지 등록은 마지막 브랜치에서 별도 커밋했다. 앞 브랜치만 실행하면 최종 이미지·후속 보완이 모두 포함되지는 않는다.

## 구현 범위

- 공격은 붉은색, 방어는 청록색, 디버프는 보라색, 해제는 금색. 전투 입력 경로와 판정은 변경하지 않았다.
- 내 상태는 왼쪽, 적 상태는 오른쪽에 최대 2개 표시한다. 현재 턴 도래 예약을 우선하고 나머지는 상세 보기로 제공한다.
- 중앙 알림 대신 피해·효과와 적 행동을 양옆에 분리한다. 직접·다단·강공격, 방벽, 기록, 봉인, 예약 등의 아이콘을 연결했다.
- 중간문은 8~5층 각 1곳과 4~1층 각 2곳을 대상으로 했다. 문짝과 고정 테두리를 분리하고 기존 전투 이후 진행 경로를 유지했다.
- 중간문 미리보기는 해당 층의 로딩 아트를 문 표면에 보여준다. 다음 방의 실제 3D 장면을 실시간으로 렌더링하는 포탈은 아니다.
- 하강문에는 공통 다색 소용돌이와 맥동을 넣었다. 2층은 원형 표면을 8개 조리개 날개로 재분할했다.
- 적 표면은 원래 재질과 UV를 보존한 조각으로 나뉜다. 처치 시 각 조각이 별도로 이동·회전하고 사라진다. 공격은 기존 피해 적용 시점에 맞춘 찌르기·휘두르기·내려찍기·시전 동작이며 새 골격 애니메이션은 아니다.
- 움직임 줄이기에서는 반복 광택·포탈 맥동·파편 이동을 제한하고 페이드로 처리한다.

## 실행 확인

사용자 요청에 따라 빌드, 테스트, 시뮬레이터 실행은 하지 않았다. 실제 기기에서 문 개방 범위, UI 크기, 파편 표현과 성능은 아직 확인되지 않았다.

수정된 런타임 USD와 이미지가 저장소에 포함된다. 원본 Blender 파일과 프로젝트의 sources 참조 자료는 수정하지 않았다. 새 Swift 파일을 만들지 않아 Xcode 파일 목록 변경은 없다.
