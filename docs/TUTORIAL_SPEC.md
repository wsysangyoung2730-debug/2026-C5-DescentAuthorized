# 튜토리얼 명세

> 문서 상태: #76~#82 구현 반영
> 기준 구현: `feat/#82-tutorial-release-hardening`
> 출시 목표: 10층~9층 출시형 튜토리얼 기준, 8층 이하는 후속 확장
> 마지막 갱신: 2026-09-01

## 1. 문서 목적

이 문서는 플레이어가 탐색, 주문 선택, 문양 입력, 전투, 보상과 하강 절차를 학습하는 방법을 독립적으로 관리한다. `LEVEL_FLOW.md`는 안내가 등장하는 장면과 순서를 기록하고, 이 문서는 노출 조건, 표현 수단, 반복 정책과 완료 상태를 정의한다.

## 2. 설계 방향

튜토리얼은 한 가지 표현 방식으로 제한하지 않는다. 필요한 상황에 따라 환경 연출, UI 강조, 짧은 시스템 메시지, 안전한 연습, 실패 원인 표시와 직접 체험을 함께 사용한다.

- 기능을 사용해야 하는 시점에 안내한다.
- 설명보다 실제 행동과 즉각적인 결과를 우선한다.
- 장면의 긴장도와 조작 복잡도에 따라 안내 강도를 조절한다.
- 이미 이해한 내용을 불필요하게 반복하지 않는다.
- 필수 경고와 선택 안내를 분리한다.

## 3. 현재 구현 상태

현재 구현된 출시형 기반은 다음과 같다.

- 공통 집중 안내 오버레이와 실제 UI 위치 추적
- 안내 단계, 완료, 건너뛰기, 실패 횟수와 다시 보기 상태 저장
- 시스템 터미널 인트로와 쓰러진 시점에서 시작하는 10층 기상 연출
- 제한된 카메라 드래그와 환경 메모 2개·주문 단서 2개의 선택 조사
- 조사한 주문 단서에서 습득과 안전 훈련으로 이어지는 진행
- 실패 횟수에 따라 핵심점과 경로 안내가 강화되는 문양 훈련
- 하강 봉인문의 기록, 한 붓 입력, 하강 정보와 초기화 버튼 단계 안내
- 9층 첫 전투의 HP, 턴, 적 HP, 행동 예고, 자원, 주문, 입력판, 기록과 턴 종료 안내
- 전투 재시작 시 완료한 첫 전투 설명 반복 억제
- 설정에서 장면별 다시 보기 예약과 전체 튜토리얼 기록 초기화
- 시스템 및 앱의 동작 줄이기 설정을 반영한 전환

다음 항목은 출시 버전 설계와 구현이 필요하다.

- 1층부터 10층까지의 학습 순서와 복습 배치
- 8층 방벽, 잔류체와 봉인 해제의 장면별 집중 안내
- 실제 기기에서의 VoiceOver 읽기 순서와 글자 크기별 시각 검수
- 분석 이벤트에 기반한 단계별 이탈 및 반복 실패 조정

## 4. 공통 안내 규칙

### 4.1 안내 우선순위

1. 공간 안에서 무엇을 눌러야 하는지 보여준다.
2. 행동의 목적을 한 문장으로 알려준다.
3. 플레이어가 직접 행동하게 한다.
4. 성공 또는 실패 결과를 즉시 보여준다.
5. 필요한 경우에만 원인을 한 문장으로 설명한다.

### 4.2 안내 표현

- 관리국 시스템 메시지
- 입력판 위의 시작점과 가이드
- 주문 카드 또는 HUD의 짧은 강조
- 적 행동 예고의 아이콘과 애니메이션
- 환경 안의 문서, 표적과 장비

긴 튜토리얼 팝업과 캐릭터가 시스템을 대신 설명하는 방식은 필요한 장면에 한해 제한적으로 사용한다.

### 4.3 안내 단계

| 단계 | 표시 |
| --- | --- |
| 최초 노출 | 짧은 문구와 관련 UI 강조 |
| 첫 실패 | 실패 원인 표시 |
| 두 번째 실패 | 핵심점 또는 필요한 카드 강조 |
| 세 번째 실패 | 가이드 경로와 진행 방향 강화 |
| 반복 실패 | 건너뛰기보다 완화된 연습 조건 제공 |

### 4.4 튜토리얼 저장

- 기능별 최초 안내 확인 여부를 저장한다.
- 전투를 재시작해도 이미 본 기본 설명은 반복하지 않는다.
- 설정에서 튜토리얼 안내를 초기화하거나 다시 볼 수 있다.
- 필수 시스템 경고는 튜토리얼 확인 여부와 관계없이 표시한다.
