## 구현

9~1층 보스와 잔류체 21종이 사용하는 `frameBattleSubject`를 조정했다. 월드 좌표의 적 바닥 높이와 실제 모델 높이를 기준으로 배치하므로 9층을 포함한 모든 전투에 동일하게 반영된다.

| 항목 | 기존 | 변경 |
| --- | --- | --- |
| 카메라 높이 | 적 바닥 + 모델 높이 × 0.76 | 적 바닥 + 모델 높이 × 0.50 |
| 주시점 높이 | 적 바닥 + 모델 높이 × 0.70 | 적 바닥 + 모델 높이 × 0.48 |
| 수평 거리 | 모델 높이 × 2.65 | 모델 높이 × 2.90 |
| 좌우 시선 한계 | 각각 12도 | 각각 28도 |
| 화면 너비만큼 드래그 시 회전량 | 36도 | 48도 |

거리에는 기존 방 카메라까지의 수평 거리를 상한으로 유지한다. 시선 회전은 새 기본 시점의 위치를 고정한 상태에서 방향만 바꾼다. 기존 48도 시야각, 좌우 위치 보정, 위아래 회전 한계 및 줌 범위는 유지한다.

기본 시점 복귀·피격 연출 복귀는 기존 `resolvedCameraSnapshot`을 통해 새 전투 시점을 사용한다. 조사·보상·하강 카메라는 기존 구도를 사용한다. 10층은 적과 조우하는 전투가 없는 훈련 장면이므로 적 기준 높이·거리 조정 대상이 아니다.
