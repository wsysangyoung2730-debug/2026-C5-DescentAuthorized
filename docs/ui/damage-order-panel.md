# 피해 처리 순서 패널

2026-10-01 · `feat/#200-compact-damage-order-panel` · 기준 #199 (`858f655`)

사용자가 선택한 마지막 시안대로 검은 질감, 얇은 고금색 테두리, 작은 보라색 포인트를 적용했다. 설명은 세 단계와 작은 아이콘으로 구성하며, 번호 장식·단계별 박스·확인 버튼은 사용하지 않는다. 기존 질감 리소스를 재사용하고 글자는 SwiftUI로 표시한다.

- 적의 ‘위협 상세’ 버튼은 피해 처리 순서 패널을 바로 연다.
- 상태가 두 개보다 많을 때 전체 목록은 별도 `+N` 버튼으로 확인한다.
- 현재 행동의 이름·설명, 이번 적 턴에 도래하는 예약 피해 이름·수치·지연 여부를 실제 전투 상태에서 읽는다.
- 예약이 없으면 빈 상태를 표시하고, 내용이 길면 패널 내부를 스크롤한다.
- 패널이 열린 동안 입력·카메라 조작과 전투 연출 시간을 멈춘다. 닫기와 바깥 영역 탭으로 닫을 수 있다.
- 장식은 접근성 읽기에서 제외하고 닫기 버튼과 세 단계 제목을 제공한다.

## 확인

최종 iOS 시뮬레이터 Debug 빌드와 `git diff --check`가 통과했다. 2층 보스의 실제 전투 화면에서 동일 패널을 DEBUG 미리보기로 열어 문구, 테두리, 아이콘과 화면 배치를 확인했다. 시뮬레이터 UI 조작 연결 오류로 버튼 터치·닫기 자동화 검사는 이번 확인에 포함하지 않는다. 직접 진입과 닫기 연결은 코드에서 확인했다.

화면은 프로젝트 작업공간의 `outputs/damage-order-panel-20261001/floor02.png`와 `floor02-review.jpg`에 저장했다. 아래 실행 인수는 메모리 내 미리보기 저장소를 사용하므로 플레이어 저장 진행을 바꾸지 않는다.
