# 전투 시스템 및 밸런스 명세

> 문서 상태: 현재 구현 기준 정리 중
> 기준 구현: `develop @ dd2f8e2` (`#74` 포함)
> 출시 목표: 1.0 · 1층~10층 완결판(상세 범위 추후 확장)
> 마지막 갱신: 2026-09-01
> MVP 기준선: [`archive/mvp-baseline/COMBAT_SYSTEM.md`](archive/mvp-baseline/COMBAT_SYSTEM.md)

## 1. 문서 목적

이 문서는 `하강 승인: 제0균열` 데모의 턴 처리 순서, 자원, 시전 판정, 피해와 방어막, 적 패턴 및 초기 밸런스를 정의한다. 구현과 플레이 테스트는 이 문서를 기준으로 하며, 수치는 재미와 난이도를 검증하기 위한 첫 기준값이다.

## 2. 전투 설계 목표

- 적의 다음 행동을 읽고 공격, 방어, 해제를 선택하게 한다.
- 손으로 정확하게 그리는 능력이 전투 결과에 직접 반영되게 한다.
- 마나와 최대 2획을 함께 고려해 한 번의 강한 주문과 두 번의 연속 시전 사이에서 선택하게 한다.
- 실패가 억울하지 않도록 실패 원인을 즉시 보여준다.
- 처음 세 층은 새로운 규칙을 하나씩 안전하게 학습시키되, 정답을 자동으로 대신 선택하지 않는다.

## 3. 전투 상태 흐름

```text
전투 진입
→ 적 정보 공개
→ 턴 시작
→ 적 행동 예고
→ 플레이어 주문 선택
→ 드로잉 및 즉시 판정
→ 플레이어 효과 적용
→ 추가 시전 또는 턴 종료
→ 적 행동 실행
→ 턴 종료 정리
→ 승리/패배 확인
```

### 3.1 전투 진입

1. 공간 연출과 적 등장 애니메이션을 재생한다.
2. 적의 이름, HP, 방어막과 첫 행동을 공개한다.
3. 튜토리얼이 필요한 전투라면 최초 한 번만 짧은 시스템 메시지를 표시한다.
4. 플레이어 HP, 보유 주문과 전투 시작 상태를 불러온다.

### 3.2 턴 시작

- 한 턴의 드로잉 마나를 최대치로 회복한다.
- 사용할 수 있는 획을 2획으로 초기화한다.
- 적이 이번 플레이어 행동 뒤에 실행할 행동을 예고한다.
- 지속 중인 말소 구역과 방어막을 입력판과 HUD에 표시한다.
- 플레이어가 주문을 고르기 전까지 시간 제한은 없다.

### 3.3 주문 선택

- 하단 카드 한 장을 누르면 해당 카드가 활성화된다.
- 입력판에는 선택한 주문의 핵심 점, 시작점과 가이드 경로가 나타난다.
- 첫 획을 시작하기 전에는 다른 카드로 자유롭게 변경할 수 있다.
- 남은 획보다 요구 획수가 많으면 카드를 비활성화한다.
- 남은 마나가 권장 선 길이보다 부족하면 카드는 경고 상태가 되지만 선택 자체를 막지는 않는다.

### 3.4 드로잉과 즉시 판정

- Pencil 또는 손가락이 입력판에 닿은 순간 한 획을 시작한다.
- 실제 이동 거리에 따라 마나가 실시간으로 감소한다.
- 입력이 끝나면 해당 획을 고정하고 남은 획수를 줄인다.
- 주문에 필요한 모든 획을 제출하면 즉시 판정한다.
- 판정 결과를 먼저 보여준 뒤 공격, 방어 또는 해제 효과를 적용한다.

### 3.5 연속 시전

- 첫 주문 이후 획과 마나가 남으면 다른 주문을 선택할 수 있다.
- 데모에서는 같은 1획 주문을 한 턴에 두 번 사용하는 것도 허용한다.
- 2획 주문은 기본적으로 그 턴의 모든 획을 사용한다.
- 플레이어는 남은 자원을 사용하지 않고 턴 종료 버튼을 누를 수 있다.
- 획을 모두 사용하거나 마나가 완전히 소진되면 자동으로 턴 종료 단계로 이동한다.

### 3.6 적 행동

- 플레이어가 선택을 마치면 적이 예고한 행동을 실행한다.
- 플레이어 효과로 적 HP가 0이 되면 적 행동은 취소된다.
- 공격은 플레이어 방어막을 먼저 감소시키고 초과분만 HP에 적용한다.
- 방어막 생성 행동은 다음 플레이어 행동부터 효력이 생긴다.
- 강공격 예고는 피해를 주지 않으며 다음 적 행동이 강공격임을 예약한다.

### 3.7 턴 종료

- 이번 턴에만 유지되는 안내와 피격 표시를 정리한다.
- 일반 적 방어막의 지속 조건을 갱신한다.
- HP 50%와 같은 패턴 전환 조건을 확인한다.
- 승리 또는 패배가 아니면 다음 턴으로 이동한다.

## 4. 입력 예외 규칙

### 4.1 취소

- 첫 획 전: 비용 없이 카드 변경 가능
- 획을 시작한 뒤: 취소할 수 있지만 사용한 마나와 획은 복구하지 않음
- 시스템 인터럽트로 입력이 끊긴 경우: 해당 획을 취소하고 자원을 복구

### 4.2 마나 고갈

마나가 선을 그리는 도중 고갈되면 입력을 그 지점에서 종료하고 현재 형태로 판정한다. 핵심 점과 종점까지 도달하지 못했다면 `시전 반려`가 된다.

### 4.3 획 초과

주문이 요구하는 획보다 펜을 더 많이 떼면 즉시 `시전 반려`한다. 손바닥 접촉이나 입력판 밖의 터치는 획으로 계산하지 않는다.

### 4.4 입력판 이탈

- 선이 입력판 경계를 잠깐 벗어나면 경계 지점에서 좌표를 고정한다.
- 일정 거리 이상 벗어나면 획을 종료한다.
- 카드와 HUD 위에서 시작한 터치는 드로잉으로 처리하지 않는다.

### 4.5 Pencil과 손가락

- Pencil 입력 중에는 손바닥과 손가락 접촉을 무시한다.
- Pencil이 연결되지 않았거나 손가락 모드를 선택하면 단일 손가락만 드로잉에 사용한다.
- 압력과 기울기는 선 굵기, 입자와 글로우에만 반영하고 판정에는 사용하지 않는다.

## 5. 마나와 획

### 5.1 마나 원칙

마나는 숫자로 지불하는 MP가 아니라 이번 턴에 그릴 수 있는 선의 총량이다. 화면에는 숫자를 표시하지 않고 원형 또는 막대형 잔량으로만 표현한다.

개발 중에는 밸런스 비교를 위해 한 턴의 총 선 길이를 내부적으로 `100 마나 단위`로 정규화한다. 이 숫자는 플레이어에게 공개하지 않는다.

- 짧고 정확한 선은 적게 소모한다.
- 떨림, 되돌림과 우회도 실제 이동 거리만큼 소모한다.
- 말소 구역 안에서는 동일한 거리라도 1.75배 빠르게 소모한다.
- 턴이 끝나면 남은 마나는 이월하지 않는다.

### 5.2 권장 마나 구간

| 주문 | 권장 사용량 | 설계 의도 |
| --- | ---: | --- |
| 잔광 말소 | 30 이하 | 두 번 연속 사용 가능 |
| 균열 절단 | 42 이하 | 다른 짧은 1획 주문과 조합 가능 |
| 방벽 관통 | 75 이하 | 2획과 대부분의 마나를 사용하는 집중 주문 |
| 초급 방벽 | 32 이하 | 공격 주문과 조합 가능 |
| 봉인 해제 | 28 이하 | 해제 후 공격 연결 가능 |

권장량을 초과해도 마나가 남아 있다면 주문은 판정한다. 권장량 대비 실제 사용량은 정확도 평가의 보조 지표로만 사용한다.

### 5.3 획 규칙

- 매 턴 기본 2획
- 획 이월 없음
- 획을 추가하거나 회복하는 보조 주문은 만들지 않음
- 주문 요구 획을 임의로 합치거나 나눌 수 없음

## 6. 시전 판정

### 6.1 판정 요소

1. 필수 핵심 점을 지정 순서대로 통과했는가
2. 선이 허용 경로 안에 얼마나 오래 머물렀는가
3. 요구 획수와 획별 시작·종료 조건을 지켰는가
4. 불필요한 우회 없이 마나를 효율적으로 사용했는가
5. 주문별 교차점과 방향 조건을 충족했는가

### 6.2 내부 점수

기능 구현을 위한 초기 가중치는 다음과 같다.

| 항목 | 비중 |
| --- | ---: |
| 핵심 점 및 순서 | 40% |
| 경로 정확도 | 35% |
| 시작점·종점·교차 조건 | 15% |
| 마나 효율 | 10% |

필수 핵심 점을 하나라도 크게 놓치거나 요구 획수를 어기면 총점과 관계없이 `시전 반려`한다.

### 6.3 표시 등급

| 등급 | 점수 기준 | 공격 배율 |
| --- | ---: | ---: |
| 시전 반려 | 필수 조건 실패 또는 0~49 | 0% |
| 불완전 승인 | 50~69 | 70% |
| 시전 승인 | 70~84 | 100% |
| 정밀 승인 | 85~94 | 120% |
| 완전 각인 | 95~100 | 140% |

점수는 개발 로그에만 남기고 플레이어에게는 등급과 실패 원인을 보여준다.

### 6.4 카테고리별 적용

- 공격: 등급에 따라 최종 피해가 변함
- 초급 방벽: 불완전 승인 이상이면 고정 방어막 20 생성
- 봉인 해제: 불완전 승인 이상이면 절대 방어막 1회 제거
- 문 개방 문양: 성공/재제출만 사용하며 전투 등급은 표시하지 않음

## 7. 피해와 방어막

### 7.1 피해 처리 순서

1. 대상이 절대 방어막 상태인지 확인한다.
2. 절대 방어막이면 공격과 상태 효과를 무효화한다.
3. 일반 방어막이 있으면 방어막에 피해를 먼저 적용한다.
4. 방어막을 초과한 피해를 HP에 적용한다.
5. HP가 0 이하인지 확인한다.

### 7.2 일반 방어막

- 수치만큼 피해를 흡수한다.
- 일반 공격으로 파괴 가능하다.
- 남은 수치를 HUD에 표시한다.
- 9층 기록 관리자의 `문서 방벽`은 다음 플레이어 시전 단계가 끝날 때까지 유지된다.
- `방벽 관통`은 일반 방어막을 무시하고 HP에 직접 피해를 준 뒤 해당 방어막을 소멸시킨다.

### 7.3 절대 방어막

- 공격 피해 0
- 일반 방어막 관통 무효
- 상태 효과 무효
- 중첩 수치 대신 봉인 횟수 아이콘으로 표시
- `봉인 해제` 성공 시 1회 제거

### 7.4 플레이어 초급 방벽

- 고정 방어량 20
- 여러 번 사용하면 남은 방어량에 20을 더하되 최대 40
- 전투가 끝나면 제거
- 방벽이 깨질 때 청백색 파편과 별도 햅틱을 제공

## 8. 주문 초기 수치

| 주문 | 기본 효과 | 획수 | 비고 |
| --- | ---: | ---: | --- |
| 잔광 말소 | 피해 18 | 1 | 허용 오차가 넓은 안정형 |
| 균열 절단 | 피해 28 | 1 | 더 긴 경로와 좁은 허용 오차 |
| 방벽 관통 | 피해 34 | 2 | 일반 방어막 무시 및 소멸, 절대 방어막에는 무효 |
| 초급 방벽 | 방어막 20 | 1 | 성공 등급과 무관한 고정값 |
| 봉인 해제 | 절대 방어막 1회 제거 | 1 | 직접 피해 없음 |

공격 피해는 소수점이 생기면 반올림한다. 완전 각인 연출은 강하게 보여주되 추가 턴이나 숨겨진 보너스를 부여하지 않는다.

## 9. 플레이어 초기 수치

| 항목 | 기준값 |
| --- | ---: |
| 최대 HP | 100 |
| 턴당 마나 | 내부 단위 100 |
| 턴당 획수 | 2 |
| 초급 방벽 최대 누적 | 40 |

### 9.1 회복과 체크포인트

- 전투 패배 시 해당 전투 직전 체크포인트에서 재시작한다.
- 패배 재시작 시 HP를 최대치로 회복한다.
- 9층 처치 후 8층 진입 시 HP 30 회복
- 관측 잔류체 처치 후 HP 20 회복하되, 보스 진입 최소 HP를 60으로 보정
- 주문, 읽은 기록과 튜토리얼 완료 상태는 유지한다.

## 10. 적 상세 명세

### 10.1 9층 기록 관리자

#### 역할

첫 실전 전투에서 공격, 적 HP, 일반 방어막, 마나와 말소 구역을 학습시킨다.

#### 초기 수치

| 항목 | 수치 |
| --- | ---: |
| HP | 120 |
| 기록 찌르기 | 피해 14 |
| 문서 방벽 | 방어막 22 |
| 말소 구역 발동 | HP 60 이하 |

#### 기본 패턴

```text
기록 찌르기 → 문서 방벽 → 반복
```

- 전투 첫 예고는 `기록 찌르기`다.
- 방벽이 예고된 턴에도 플레이어는 방벽 생성 전에 공격할 수 있다.
- 생성된 문서 방벽은 다음 플레이어 시전 단계 동안 유지된다.
- HP 50% 이하가 되는 즉시 입력판 한쪽에 말소 구역 하나를 생성한다.
- 말소 구역은 전투 종료까지 유지하며 위치를 바꾸지 않는다.

#### 튜토리얼 안전장치

- 첫 공격은 플레이어를 처치할 수 없다.
- 말소 구역은 선택한 주문의 시작점을 덮지 않는다.
- 말소 구역 생성 직후 가이드를 잠깐 강조하지만 경로를 자동 변경하지 않는다.

#### 승리

- 적 행동을 중단하고 붉은 승인 핵이 깨진다.
- 주문서 3개 선택 화면으로 이동한다.
- 어떤 후보를 골라도 `방벽 관통`을 등록한다.

### 10.2 8층 관측 잔류체

#### 역할

초급 방벽, 강공격 예고와 `잔류체 → 관리자` 층 구조를 가르친다.

#### 초기 수치

| 항목 | 수치 |
| --- | ---: |
| HP | 72 |
| 유리 파편 | 피해 10 |
| 집속 파편 | 피해 26 |

#### 패턴

```text
유리 파편 → 초점 고정 → 집속 파편 → 반복
```

- `초점 고정`은 피해 없이 다음 강공격을 예고한다.
- 첫 강공격 예고 시 초급 방벽 카드와 플레이어 방어막 영역을 한 번 강조한다.
- 초급 방벽 없이 집속 파편을 맞아도 직전 HP가 정상이라면 즉시 패배하지 않는다.

#### 승리

- 렌즈 핵이 깨지며 잠금 문양 조각이 나온다.
- 주인공이 이를 해독해 `봉인 해제`를 습득한다.
- HP를 회복한 뒤 본실 잠금에 봉인 해제를 시험한다.

### 10.3 8층 관측 관리자

#### 역할

해제, 절대 방어막, 강공격과 공격·방어 조합을 종합 검증한다.

#### 초기 수치

| 항목 | 수치 |
| --- | ---: |
| HP | 165 |
| 파편 조사 | 피해 18 |
| 균열 조사광 | 피해 42 |
| 절대 방어막 | 공격과 상태 효과 전부 무효 |

#### 전투 시작

- 절대 방어막 1회를 가진 상태로 시작한다.
- 첫 플레이어 행동에서 공격 주문을 한 번 사용하도록 유도한다.
- 공격이 무효화되면 `절대 방어막: 공격 효과 무효`를 표시한다.
- 이후 봉인 해제 카드와 방어막 아이콘의 연결을 강조한다.

#### 기본 패턴

```text
절대 방어막 → 파편 조사 → 초점 고정 → 균열 조사광 → 반복
```

전투 시작 시 이미 절대 방어막이 있으므로 최초 주기는 `파편 조사`부터 이어진다. HP가 처음 50% 이하가 되면 다음 예정 행동보다 우선해 절대 방어막 1회를 다시 생성한다. 같은 전투에서 HP 조건 방어막은 한 번만 발동한다.

#### 행동 설명

- 관측 차폐막: 절대 방어막 1회 생성
- 파편 조사: 플레이어에게 일반 피해 18
- 초점 고정: 다음 행동이 균열 조사광임을 붉은 조준선으로 예고
- 균열 조사광: 플레이어에게 피해 42

#### 승리

- 관측 렌즈가 깨지고 창밖의 제0균열이 잠시 선명해진다.
- 보상 선택 연출을 거친다.
- 7층 하강문을 개방하면 데모 엔딩으로 이동한다.

## 11. 승리와 패배

### 11.1 승리 조건

- 적 HP가 0 이하가 되면 승리한다.
- 예고된 적 행동은 즉시 취소한다.
- 남은 마나, 획과 방어막은 다음 전투로 이월하지 않는다.

### 11.2 패배 조건

- 플레이어 HP가 0 이하가 되면 패배한다.
- 짧은 기억침식 연출 후 재시작 메뉴를 표시한다.
- `전투 재시작`과 `층 시작부터`를 제공한다.
- 패배 횟수에 따른 능력치 보정은 데모에 넣지 않는다.

## 12. 전투 피드백

### 12.1 적 피격

- HP의 붉은 현재값과 늦게 따라오는 지연 게이지
- 피해 숫자
- 등급에 비례하는 글로우, 파편과 화면 흔들림
- 일반 방어막 피격 시 청백색 차폐 효과
- 절대 방어막 피격 시 금색 격자에서 주문이 흩어지는 효과

### 12.2 플레이어 피격

- 방어막을 먼저 감소
- 초과 피해만 붉은 HP에 적용
- 화면 가장자리 붉은 충격과 짧은 흔들림
- 강공격은 일반 공격보다 무거운 사운드와 햅틱 사용
- 화면 흔들림 감소 설정이 켜지면 위치 이동 대신 밝기와 파편으로 표현

## 13. 플레이 테스트 조정 기준

다음 조건을 만족할 때 초기 수치가 적절한 것으로 본다.

- 9층 첫 플레이어가 평균 5~7턴 안에 승리한다.
- 관측 잔류체는 평균 3~5턴 안에 승리한다.
- 관측 관리자는 평균 7~10턴 안에 승리한다.
- 시전 승인 수준의 플레이어가 각 전투에서 한 번 이상 적 패턴에 대응해야 한다.
- 공격만 반복하면 8층 보스에서 높은 확률로 패배한다.
- 정밀 승인 이상을 꾸준히 달성하면 전투가 눈에 띄게 짧아진다.
- 한 번의 실수로 즉시 패배하지 않지만 같은 실수를 반복하면 위험해진다.

## 14. 미확정 및 테스트 항목

- 실제 기기 화면 크기에 따른 마나 정규화 방식
- 말소 구역 1.75배 소모가 체감상 적절한지
- 방벽 관통이 일반 방어막을 소멸시키는 규칙의 재미
- 같은 주문을 한 턴에 두 번 사용하는 전략의 과도함 여부
- 관측 관리자 HP 50% 방어막 재생 시점
- 층 사이 회복량과 데모 전체 난이도
- 판정 가중치와 등급 경계값
