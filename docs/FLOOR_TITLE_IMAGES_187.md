# 7~1층 상단 제목 이미지 교체

- 이슈: #187
- 브랜치: `add/#187-lower-floor-title-images`
- 기준 커밋: `18a3868` (전투 카메라 후퇴 작업 포함)

제작된 제1층~제7층 투명 PNG를 `FloorTitle1`~`FloorTitle7` 이미지 자산으로 등록했다. 공통 `FloorTitleAssetView`가 1~10층의 이미지 이름을 선택하도록 확장하여 일반 진행 화면과 전투 화면의 상단 제목에 모두 적용했다.

기존 제목 크기, 양옆 장식, 접근성 이름을 유지한다. 지원 범위 밖의 층 번호는 기존 텍스트 표시를 사용한다. 추가된 이미지는 모두 1536×1024 RGBA이며 생성 원본을 그대로 사용했다.

## 검증

- PNG 7개의 SHA-256이 생성 원본과 일치하고 투명 알파 채널이 있음을 확인했다.
- iPad Pro 13-inch (M5), iOS 26.5 시뮬레이터용 Debug 빌드 성공.
- 7층 일반 진행 화면과 4층 전투 화면에서 층 번호, 금색 글자, 투명 배경, 양옆 장식 배치를 확인했다.
- 실기기 확인 및 모든 층의 개별 화면 캡처는 수행하지 않았다.

화면 캡처는 작업 공간의 `outputs/floor-title-integration/floor7-standard.png`와 `floor4-battle.png`에 보관했다.
