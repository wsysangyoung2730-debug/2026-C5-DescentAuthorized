# 7~5층 확장 플레이 기획 기준안 v3

이 문서는 최근 대화의 사용자 지정 사항과 위임받은 나머지 기획의 권장안을 합쳐 정리한 현재 기준안이다. 구현과 기존 저장소의 기준 문서는 변경하지 않았다. 비주얼·공간·서사 연출은 범위에서 제외하며 수치는 아직 테스트용이다.

우선순위: 진행·장착·학습·패턴 구조는 이 문서, 주문 20종의 이름·등급·획수·효과·획득은 Spell_Catalog_20_Proposal_v2.md를 따른다. 초기 Floors_7_5_Gameplay_Proposal.md와 충돌하는 장착 규칙 및 6·5층 방어막 패턴은 이 문서로 대체한다.

## 1. 사용자 지정 사항

- 카테고리는 공격·방어·해제·디버프 네 가지.
- 5층까지 턴당 기본 2획. 획 추가·회복 주문은 넣지 않는다.
- 7·6·5층 하강문은 각각 2단계 승인.
- 잔류체 방에서 보스방으로 갈 때 기존 봉인 해제를 재사용.
- 7~5층의 임의 주문 드롭은 생략. 첫 디버프 학습은 6층에 배치 가능.
- 전투에 가져가는 주문은 최대 6종. 전투 시작 전 가방에서 선택하고 전투 중에는 교체하지 않는다.
- 봉인 해제는 반드시 포함하며 공격 1종 이상·방어 1종 이상을 포함한다.
- 신규 규칙 소개의 중심은 6층으로 둔다.

중요: 공격·방어의 특정 주문 이름을 고정하지 않는다. 잔광 말소 대신 균열 절단이나 다른 공격을, 초급 방벽 대신 다른 방어를 선택할 수 있다. 이전 안의 특정 기본 주문 3종 고정은 폐기한다.

## 2. 전체 범위와 성장

- 8층 클리어 이후 7·6·5층을 진행하고, 5층 보상 선택과 4층 하강문 개방까지가 이번 확장 범위다. 4층 전투는 없다.
- 층마다 잔류체 1회·관리자 1회로 신규 실전 전투 6회.
- 9·8·7·6·5층 관리자 보상은 각각 고정 후보 3종 중 1종 선택.
- 총 주문 20종, 기존 5종과 신규 15종. 한 진행의 최종 보유량 10종.
- 최대 HP·턴당 마나·턴당 획수는 이 구간에서 자동 성장시키지 않는다. 성장의 중심은 주문 획득과 구성 선택이다.
- 층별 목표 경험: 7층은 공격과 방어의 판단, 6층은 시간과 효과 대상의 판단, 5층은 주문 순서와 제한된 구성의 운용.

## 3. 가방과 장착 규칙

### 3.1 유효한 구성

- 고유 주문 최대 6종, 동일 주문 중복 장착 불가.
- 봉인 해제 1종 필수, 공격 최소 1종, 방어 최소 1종. 나머지는 원하는 카테고리로 구성.
- 디버프와 정화 각인은 필수 장착이 아니다.
- 여섯 칸을 반드시 채우게 강제하지 않는다. 최소 필수 조건을 만족하면 빈칸을 두고 시작할 수 있으나 보유 주문이 충분하면 6종 구성을 권장한다.
- 8층에서 방어와 봉인 해제를 배우기 전에는 아직 없는 주문을 요구하지 않는다. 학습을 모두 마친 이후, 7층부터 정상 장착 조건을 적용한다.
- 전투 중에는 장착한 주문 최대 6종을 계속 사용할 수 있다. 무작위 드로우, 턴마다 카드 교체, 가방에서 중간 교체는 없다.

### 3.2 전투 진입

1. 전투 직전 `들어가기`를 선택하면 출전 준비 단계로 간다.
2. 보유 주문과 현재 장착 구성을 확인하고 가방에서 교체한다.
3. 이번 전투의 알려진 특징을 짧게 확인한다. 예: 예약 피해, 모사. 아직 만나지 않은 모든 행동을 상세 공개할 필요는 없다.
4. 필수 조건을 만족하면 최종 전투 시작을 선택한다.
5. 시작 후 전투 종료까지 구성 고정.

매번 가방을 새로 편성할 필요는 없으며 직전 구성을 유지한다. 새 주문을 얻어도 기존 주문을 자동으로 빼지 않는다. 보상 후 다음 전투 준비에서 직접 교체한다. 새로운 공격·방어를 교체할 때에는 필수 역할 지정도 함께 변경한다.

### 3.3 5층 카드 봉인에 대한 기본 대응 보장

- 출전 준비에서 공격 1종과 방어 1종을 `기본 대응 주문`으로 지정한다. 공격·방어가 각각 하나라면 자동 지정.
- 봉인 해제와 이 두 지정 주문은 적의 카드 봉인 대상에서 제외한다. 플레이어가 선택한 공격·방어를 존중하면서 최소 대응을 보장한다.
- 나머지 최대 3종만 카드 봉인 대상이다. 보호되지 않는 주문이 부족하면 가능한 수만 봉인한다.
- 2획 공격만 가져가는 구성도 금지하지 않지만, 1획 공격과 1획 방어를 지정하는 구성을 권장한다. 별도 의무 조건을 추가하지 않는다.

## 4. 가방 튜토리얼의 시점

| 시점 | 보유 주문 | 처리 |
|---|---:|---|
| 8층 고정 학습 완료 | 5 | 기존 전투·학습 진행 |
| 8층 보상 획득 후 / 7층 잔류체 진입 전 | 6 | 첫 6칸 구성 안내. 여섯 주문이 모두 들어가므로 교체를 강요하지 않음 |
| 7층 보상 획득 후 / 6층 진입 | 7 | 처음으로 보유량이 장착량을 초과 |
| 6층 출력 저하 고정 습득 후 / 6층 잔류체 진입 전 | 8 | 본격적인 가방 선택 튜토리얼. 8종 중 최대 6종 선택 |
| 6층 보상 후 / 5층 진입 | 9 | 익숙한 출전 준비 반복, 추가 장문 안내 없음 |
| 5층 보상 후 | 10 | 이번 확장 종료 및 시험 각인 |

### 7층 안내는 짧게

처음 보유 주문이 6종이 된 전투 준비에서 `전투에는 최대 6종을 가져간다`, `봉인 해제와 공격·방어가 필요하다`, `교체는 시작 전에만 가능하다`를 한 번 알려준다. 실질적 선택지가 아직 없으므로 불필요한 빼기·넣기를 시키지 않는다.

### 실제 교체 학습은 6층

출력 저하 습득 직후 잔류체 방의 들어가기 단계에서 진행한다. 새 디버프를 넣기 위해 다른 주문 하나를 빼는 예를 안내하고, 기본 공격·방어를 지정한 뒤 구성을 확인한다. 출력 저하 장착은 권장하되 강제하지 않는다. 필요하면 출전 전 시험 각인에서 새 주문을 먼저 써볼 수 있다.

튜토리얼은 보유량과 첫 경험을 기준으로 발동한다. 이후 획득 순서가 바뀌더라도 첫 6종 안내와 첫 초과 보유 교체 안내가 적절한 전투 준비에 연결되도록 기획한다.

## 5. 새 규칙 학습의 배치

`6층에서 소개한다`는 버프·디버프와 예약 피해라는 신규 시스템의 본격 소개를 뜻한다. 7층은 이미 배운 방어막을 활용하고, 5층의 모사·카드 봉인은 해당 층에서 필요한 시점에 소개한다. 5층 규칙까지 모두 6층에서 미리 설명하지 않는다.

| 전투 | 소개하거나 확인할 것 | 설명을 미룰 것 |
|---|---|---|
| 7층 잔류체 | 교정 방벽이 남으면 강공격 강화. 기존 방벽의 새로운 활용 | 버프·디버프 분류 전체 |
| 7층 관리자 | 방벽 파괴와 방어 선택, 단계 전환 시 기존 봉인 해제 활용 | 신규 효과 분류 추가 |
| 6층 잔류체 | 증폭 버프 → 예약 확정 → 피해 감소 디버프를 순서대로 경험 | 여러 예약 동시 관리 |
| 6층 관리자 | 서로 다른 시점의 예약과 해제·감소 선택 | 별도 신규 카테고리 |
| 5층 잔류체 | 모사 기록과 같은 주문 재사용의 결과 | 카드 봉인 |
| 5층 관리자 | 모사에 더해 선택 주문 일부 봉인 | 추가적인 새 자원 체계 |

### 6층 잔류체 첫 주기의 안내

1. 첫 증폭 행동에서 `적에게 걸린 강화 상태`를 소개한다. 아직 예약 수치와 모든 상태를 한꺼번에 설명하지 않는다.
2. 예약이 등록될 때 `언제 얼마의 피해가 오는지`와 증폭의 결과가 예약 수치에 반영되었음을 알린다.
3. 집행 직전 플레이어 턴에 출력 저하와 방어의 대응을 짧게 안내한다. 출력 저하를 장착하지 않았다면 방어 안내로 대체한다.
4. 실제 피해에서 방어·감소 결과를 확인한다.

학습 때문에 특정 주문을 강제하거나 적을 무적으로 만들어 처치를 막지 않는다. 먼저 처치했다면 관련 안내는 다음 해당 상황에서 이어간다. 이미 본 안내는 매번 반복하지 않는다.

## 6. 7층 패턴 기준

### 좌표 표류 잔류체

`표류 충돌 → 임시 좌표 고정 → 축선 돌진 → 좌표 붕괴 → 반복`

- 표류 충돌: 약한 일반 공격.
- 임시 좌표 고정: 일반 교정 방벽 생성, 다음 강공격 예고. 피해 없음.
- 축선 돌진: 방벽이 남으면 강공격, 깨졌거나 제거됐다면 약한 공격. 집행 후 남은 교정 방벽 소멸.
- 좌표 붕괴: 피해 없는 빈틈.
- 단계 전환 없음. 핵심은 공격으로 위협을 낮추거나 방어로 받아내는 선택 하나다.

### 좌표 교정 관리자

`기준점 타격 → 축선 고정 → 강제 교정 → 재측량 → 반복`

- 1단계는 잔류체의 규칙을 더 높은 압력으로 사용한다.
- HP 50% 이하에서 다음 주기부터 2단계. 기존에 예고한 공격을 즉시 강화하지 않는다.
- 2단계 첫 주기의 기준점 타격 대신 절대 방어막 1회를 생성한다. 이 행동에는 피해가 없다. 이 절대 방어막 생성은 전투 중 한 번만 실행한다.
- 다음 플레이어 턴에 봉인 해제 기회를 주고, 이후 축선 고정에서 일반 교정 방벽을 생성한다. 그다음 플레이어 턴에 일반 방벽 파괴·자기 방어를 선택한다.
- 이후 2단계 주기는 절대 방어막 반복 생성 없이 일반 패턴을 강화해 사용한다.
- 해제·일반 방벽 파괴·방어를 같은 턴에 모두 강제하지 않는다.

## 7. 6층 패턴 기준

일반 방어막과 절대 방어막을 기본 패턴에 넣지 않는다. 핵심은 증폭 버프와 이미 등록된 예약 피해의 차이다.

### 결과 지연 잔류체

`잔류 증폭 → 결과 각인 → 늦은 잔격 → 지연 충돌 → 반복`

- 잔류 증폭: 다음 예약 등록을 강화하는 해제 가능한 버프. 즉시 피해 없음.
- 결과 각인: 4행에서 집행할 피해 1건 등록. 증폭이 남아 있으면 강화된 수치로 확정하고 버프 소모.
- 늦은 잔격: 작은 일반 공격.
- 지연 충돌: 예약 피해만 집행. 별도 추가 일반 공격 없음.
- 예약 전 정화 각인으로 증폭 제거 가능. 예약 후에는 결과 말소 또는 방어·출력 저하로 대응한다.
- 정화 각인이나 출력 저하가 없는 구성도 기본 방어로 생존·공략 가능해야 한다.

### 인과 검증 관리자

`인과 증폭 → 집행 등록 → 원인 추궁 → 제1결과 집행 → 기록 정리/제2결과 집행 → 반복`

- 1단계: 집행 등록에서 4행의 예약 한 건을 생성. 5행은 피해 없는 빈틈.
- 2단계: 다음 주기부터 집행 등록에서 4행의 큰 예약과 5행의 작은 예약을 함께 생성. 두 시점·수치를 미리 공개.
- 증폭은 해당 등록 행동의 예약 묶음에 적용한 뒤 소모한다. 생성 후에 증폭을 제거해도 기존 예약 수치는 바뀌지 않는다.
- 원인 추궁은 작은 즉시 공격이므로 출력 저하가 큰 예약에 도착하기 전에 소비될 수 있다. 사용하는 턴을 판단한다.
- 예약 하나를 취소해도 다른 예약은 유지하며, 취소된 자리에 공격을 새로 채우지 않는다.
- 처치 시 남은 예약 모두 소멸한다.

## 8. 5층 패턴 기준

기본 패턴에 일반 방어막이나 절대 방어막을 추가하지 않는다. 모사 기록은 해제 가능한 적 버프, 카드 봉인은 플레이어 디버프로 구분한다.

### 기억 누락 잔류체

`기억 붙잡기 → 모사 할퀴기 → 기록 압축 → 기억 파열 → 반복`

- 기억 붙잡기: 바로 앞 플레이어 턴의 마지막 성공 주문을 기록. 성공 주문이 없으면 기록하지 않는다. 피해 없음.
- 다음 플레이어 턴에서 같은 주문을 한 번 이상 성공시키면 모사 할퀴기에 추가 공격 한 번 발생한다. 여러 번 반복해도 추가 공격은 한 번.
- 기록은 모사 할퀴기가 끝나면 소멸. 정화 각인으로 먼저 지우거나 다른 주문을 써서 회피 가능.
- 기록 압축은 다음 행에 집행할 강공격을 예약하고 피해를 주지 않는다.
- 기억 파열은 예약 피해만 집행. 6층 보상의 지연·예약 피해 방어·조건부 공격을 여기서 활용한다.
- 카드 봉인은 사용하지 않는다. 굵은 팔의 공격을 중심으로 단순한 모사 규칙을 학습한다.

### 기억 원본 관리자

`원본 채취 → 원본 대조 → 보관 명령 → 기억 압착 → 반복`

- 원본 채취: 잔류체와 동일하게 마지막 성공 주문을 기록.
- 원본 대조: 기본 공격 후 기록 주문을 재사용했다면 카테고리별 모사 효과 한 번 실행. 재사용하지 않거나 정화했으면 추가 효과 없음.
- 보관 명령: 보호되지 않은 선택 주문 1장을 다음 플레이어 턴 동안 봉인하고 다음 행의 압착 피해 예약. 즉시 피해 없음.
- 기억 압착: 예약 피해 집행. 이 행의 적 행동 종료에 카드 봉인 해제.
- 2단계는 다음 주기부터 봉인 대상을 최대 2장으로 늘리고 공격 수치를 조정한다. 기본 대응으로 지정한 공격·방어와 봉인 해제는 보호한다.
- 카드 봉인 대상은 예고 시 확정하며 시전 도중 바꾸지 않는다. 보호되지 않는 주문 중 최근 성공 사용 순, 이력이 없으면 장착 순서로 선정한다.

### 관리자 모사 효과의 방향

| 기록 주문 | 재사용했을 때의 추가 효과 |
|---|---|
| 공격 | 추가 타격 한 번 |
| 방어 | `원본 보존` 버프: 다음 플레이어 공격 한 번의 피해 감소. 방어막 수치는 만들지 않으며 한 번 적용 후 소멸 |
| 해제 | 플레이어의 일반 방어막 일부 제거. HP 직접 피해로 전환하지 않음 |
| 디버프 | 플레이어 다음 공격 한 번을 약화하는 디버프 |

원본 보존과 공격 약화는 다음 플레이어 행동 단계 종료까지 사용되지 않으면 소멸한다. 정화 각인으로 해당 버프·디버프를 제거할 수 있다. 같은 이름의 효과는 중첩하지 않는다. 주문 원본을 그대로 실행하는 복제는 아니며 카테고리별 고정 반응으로 제한한다. 수치는 테스트 단계에서 확정한다.

## 9. 공통 예외와 공정성

- 모든 신규 필수 대응은 기본 2획 안에서 가능하거나, 이전 턴에 준비할 시간을 제공해야 한다.
- 해제·디버프는 선택적인 이득이다. 특정 선택 보상을 놓쳤다는 이유로 보스를 통과하지 못하게 하지 않는다.
- 5층은 보호 주문 덕분에 봉인 상태에서도 기본 대응이 남는다. 모사 기록 때문에 특정 주문을 쓰면 추가 피해가 나더라도 추가 피해를 받아내는 선택은 가능하게 한다.
- 시전 실패는 기록 갱신·모사 재사용으로 세지 않는다.
- 예약 시점과 수치는 생성 때 확정하고 공개한다. 지연은 같은 예약에 한 번만 가능하며 바뀐 시점을 즉시 반영한다.
- 도래한 예약이 일반 공격 턴으로 지연되면 둘 다 집행될 수 있다. 그 결과를 지연 선택 전에 공개한다.
- 단계 전환은 다음 패턴 주기에만 적용하고 이미 예정된 행동을 기습적으로 바꾸지 않는다.
- 플레이어가 적을 처치하면 남은 예약·모사·적 행동은 모두 취소된다.
- 효과 종류·지속 시간이 정리된 뒤 최종 피해량과 HP를 맞춘다. 이전 초안의 수치를 새 주기에 그대로 확정 적용하지 않는다.

## 10. 보상·회복·재도전·종료

- 보상은 고정 세 후보, 효과·등급·획수·문양을 선택 전에 공개하고 시험 가능.
- 최종 선택 전에는 자유롭게 비교. 확정 후 해당 진행에서는 재선택·중복 획득 불가.
- 잔류체 처치 후 HP 회복과 보스 진입 최소 HP 보정 적용. 초기 제안은 HP +20, 결과 최소 60, 최대 100.
- 보스 이후 다음 층 진입 시 HP +30, 최대 100을 초기값으로 둔다.
- 전투 실패 시 해당 전투 직전부터 HP 100으로 재시작. 들어가기 단계에서 주문 재구성 가능.
- 습득 주문·확정 보상·완료된 학습은 유지한다. 전투 중 임시 상태와 사용 제한은 새 전투 시작 시 초기화한다.
- 전투 도중 종료 후 재개는 전투 직전 준비부터 시작하는 안으로 둔다. 매 턴 복원 기능은 이번 범위에 포함하지 않는다.
- 잔류체 이후 보스방 문은 봉인 해제 재사용. 하강문은 별도의 2단계 승인. 문양 실패에 HP·마나 손실 없음.
- 하강문 2단계 실패 시 1단계 성공 유지.
- 5층 보상 선택 → 2단계 하강 승인 → 4층 문 개방에서 확장 구간 종료. 5층 보상 주문의 시험 각인은 제공한다.

## 11. 분량과 검토 기준

- 잔류체는 기본적으로 4~6턴, 1~2주기 내 처치를 목표로 한다. 관리자는 7~10턴을 우선 목표로 하되 두 단계 경험 여부와 반복 피로를 보고 조정한다.
- 신규 실전 전투 6회 외에 필수 학습 전투를 추가하지 않는다.
- 초반에는 안내를 읽을 시간을 주고 전투 중 생각하는 시간을 제한하지 않는다. 문양 판정은 속도보다 정확도 중심이다.
- 7층에서는 공격적·방어적 대응이 모두 성립하는지 확인.
- 6층에서는 정화/결과 말소/출력 저하를 각각 보유하거나 보유하지 않아도 대응 가능한지 확인.
- 5층에서는 어떤 유효한 기본 대응 지정에서도 봉인 때문에 행동이 막히지 않는지 확인.
- 9층 방벽 관통을 고르지 않은 진행, 8층 정화를 고르지 않은 진행, 디버프를 장착하지 않은 진행을 반드시 검토한다.
- 최종 목표는 피해량 증가보다 `상태를 읽고, 시점을 고르고, 주문 구성을 활용하는 능력`이 성장했다고 느끼는 것이다.

## 12. 아직 테스트·세부 확정이 필요한 범위

- 주문별 등급 배정과 신규 문양의 실제 경로·허용 오차.
- 새 패턴 주기에 맞춘 HP·피해·감소율·회복 초기값 조정.
- 5층 카테고리별 모사 효과의 수치와 한눈에 이해되는 명칭.
- 1획 공격·방어 추천 구성과 2획 공격을 기본으로 지정한 구성의 공략 차이.
- 금서 대가와 다른 등급 후보의 실제 선택 가치.

공간·서사·비주얼 효과는 이 플레이 구조를 기준으로 후순위 작업에서 연결한다.
