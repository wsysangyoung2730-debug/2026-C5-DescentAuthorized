## 7층 복층 구조

기존 복층 바닥의 안쪽 경계는 ±8.15m인데, 마스트와 받침은 ±7.6m에 있어 바닥 바깥에 떠 있었다. 마스트·조명·받침을 복층 중앙 ±9.7m의 동일 위치로 정렬했다. 16단 계단의 마지막 높이를 복층 상단 4.15m에 맞추고, 지지대 상단을 바닥 하부까지 연결했다. 앱용 USDC의 고·중·저품질 자산 모두 수정했다.

재생성: `docs/reality-assets/repair_floor07_structure.py`를 Blender의 pxr 포함 Python으로 실행한다. 원본 Blender 파일은 덮어쓰지 않았으며, 향후 재내보내기 후에도 같은 스크립트로 앱용 자산에 보정을 적용할 수 있다.

## 공용 보상 장치

기존 5~7층은 프레임 1의 두루마리 기준점에 작은 공용 두루마리를 붙이고 단순 상승만 재생했다. 8층 장치 전체를 `Reality/Interactables/RewardDevice`로 분리하여 5~7층에서 재사용한다.

- 장치와 두루마리의 고·중·저품질 모델, 텍스처, 모션 JSON을 함께 저장.
- 8층의 30fps·66프레임·13트랙(뚜껑/승강 장치/등장/부유 기준점) 재사용.
- 8층 방의 절대 좌표를 제거하고 각 방의 실제 받침대 위치·방향에 장치를 배치.
- 기존 방 장치를 숨기고 공용 장치의 두루마리 기준점에 보상 선택·확정 연출 연결.
- 기존 8·9층과 동일한 `AuthoredRewardPlayer` 사용.

재생성: `docs/reality-assets/extract_shared_reward_device.py`.

## 방벽

장식용 방벽 기물이 없는 방에서는 기존 공용 방벽 이펙트 생성이 중단되었다. 기물이 없으면 실제 적 크기를 기준으로 기존 8·9층 방벽 셸을 전개한다. 일반방벽은 청색, 절대방벽은 금색이며, 절대방벽 우선순위와 파괴 시 해제 흐름은 유지한다.

## 재시작·회복·6층 학습

- 사망 후 재시작 버튼을 누르면 공용 로딩 화면을 즉시 표시한다.
- 로딩 작업을 전투 화면이 아닌 상위 진행 화면에서 유지하여 화면 교체로 취소되지 않도록 한다.
- 같은 전투방을 다시 로드하고 준비 화면으로 돌아가며 HP를 100으로 회복한다.
- 8→7, 7→6, 6→5층 신규 진입 시 기존 +30 회복을 HP 100 초기화로 변경한다.
- 기존 층의 진행 재개만으로는 추가 회복하지 않는다.
- 6층 조사 종료 후 입장 화면을 먼저 보여주지 않고 새 두루마리 발견·학습을 진행한다.
- 학습 완료 후 잔류체 구역 입장 화면을 표시하며, 기존 조사 완료 기록은 유지한다.
- 조사와 출전 준비 사이에 화면 상태를 유지해 입장 버튼을 중복으로 누를 필요가 없도록 한다.
