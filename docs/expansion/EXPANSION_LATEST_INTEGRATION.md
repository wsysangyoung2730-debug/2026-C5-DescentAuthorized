- 최신 자산·카메라: `fix/#110-floor10-materials-camera` (`5d5dede`)

#105가 #104가 아닌 #96에서 분기하여 확장과 최신 자산 수정이 형제 브랜치로 분리되어 있었다. 두 계열을 병합하여 8층 하강 뒤 7층 입구와 7→6→5→4 진행을 다시 연결했다.

## 의미 단위 병합 처리

- 공통 보상 화면의 `floor`를 확장 버전의 `floorNumber`에 맞췄다. 8·9층은 실제 두루마리 상승 완료를 기다리며, 7~5층은 임시 무대에서 선택 화면으로 진행한다.
- 화질별 3D 자산 이름 결정은 Reality 레이어로 이동했다. 코어 설정이 앱 전용 `FloorSceneID`에 의존하여 Swift 코어 테스트를 빌드하지 못하던 문제를 해결했다.
- 8층 하강 애니메이션 후 기존 승인 명령이 확장 입구로 연결되는 경로를 유지했다.
- 10층 CTA 및 정면 카메라, 8층 보상 연출, 최신 3D 자산·재질·조명·품질별 로딩은 보존했다. #110 대비 Reality 자산 파일 변경 없음.
- 확장 저장 버전 5, 기존 보상 이행, 편성·보호 주문·2단계 하강 승인 저장을 유지한다. 구버전의 8층 완료 저장은 7층 입구로 연결하며, 이미 확장이 기록된 저장은 해당 단계를 복원한다.

## 검증

- 진행·저장·설정·확장 전투 관련 선택 테스트 55개 통과.
- 추가로 실제 10~8층 기준 전투 진행을 마친 뒤 7층 입구 → 출전 준비 → 실제 잔류체 전투까지 연결하는 회귀 검사 통과.
- 확장 통합 검사는 7·6·5층 보상 학습, 1차 하강 승인 후 저장·복원, 2차 승인과 4층 도달을 포함한다.
- iPad Pro 13-inch (M5), iOS 26.5 시뮬레이터 Debug 앱 빌드 성공.
- 실제 시뮬레이터에서 5층 출전 준비(보유 9종·편성 6종·보호 주문) 및 전투 시작 버튼을 통한 기억 누락 잔류체 전투, HUD·6개 카드·문양 입력판 표시 확인.
- 테스트 변경 후 해당 연결 검사만 재실행했다. 무관한 전체 테스트는 반복하지 않았다.

실기기 장시간 플레이·밸런스·성능 측정은 이번 병합 검증에 포함하지 않았다. 7~5층 3D 방과 전용 애니메이션은 기존 #104와 같은 임시 무대 범위다.
