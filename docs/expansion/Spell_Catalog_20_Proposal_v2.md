# 5층까지의 전체 주문 20종 제안 v2

> 가방 구성·필수 역할 지정·튜토리얼 시점·최신 적 패턴은 `Floors_7_5_Gameplay_Design_v3.md`와 함께 읽는다. 공격·방어는 특정 이름을 고정하지 않고 플레이어가 선택한다.

상태: 검토용 제안. 카테고리 4종과 5층까지 턴당 기본 2획을 전제로 한다. 주문별 등급 배정·신규 효과·수치는 사용자 확정 전이다. 기존 게임 데이터에는 반영하지 않았다.

이 목록은 앞선 Floors_7_5_Gameplay_Proposal.md의 주문 표를 보완한다. 특히 정화 각인의 적 버프 제거, 축선 절단의 버프 보유 적에 대한 추가 피해, 모사 금지의 금서 효과·대가가 변경되었다. 보스 패턴 자체의 최신 확정본을 뜻하지 않는다.

## 공통 기준

- 카테고리: 공격·방어·해제·디버프.
- 5층까지 매 턴 기본 2획. 획 추가·획 회복 주문은 없다.
- 숫자 범위는 성공한 시전의 판정 등급에 따른 최소~최대 효과다. 실패는 효과가 없고, 이미 그린 선과 획은 소비한다. 단일 수치로 적힌 부가 효과는 성공 시 고정이다.
- 주문서 등급과 시전 판정 등급은 별개다. 높은 주문서 등급이 기본 주문을 항상 대체하지 않도록 문양 길이·조건·부담을 함께 둔다.
- 마나는 실제 선 길이로 소비된다. 아래 권장 마나는 문양 제작용 내부 길이 예산이며 고정 MP 가격이 아니다. 턴당 기준 예산은 100.
- 일반 방어막은 플레이어 기준 누적 최대 40이며 피해로 소진되거나 전투 종료 시 제거된다.
- 같은 이름의 강화·약화는 별도 표기가 없으면 중첩하지 않고 갱신한다. 피해 처리 시 비율 감소 → 고정 감소 → 0 이상 제한 및 반올림 → 방어막 → HP 순서다.
- 해제는 이미 존재하는 효과를 제거한다. 디버프는 적의 이후 행동에 제약을 부여한다. 절대 방어막이 활성화된 적에게는 일반 공격·일반 해제·디버프를 적용할 수 없으며 봉인 해제가 우선이다.
- 9·8·7·6·5층 보스 보상은 각 3종 중 1종 선택. 전부 실제 획득 가능한 고유 주문이다. 이름·효과·등급·문양·획수·제약을 선택 전에 공개하고 시험 각인을 허용한다.
- 고정 획득은 특정 진행을 완료하면 선택 없이 등록한다는 뜻이다. 7~5층의 별도 고정 습득은 6층 출력 저하 1회뿐이다.
- 아래 모든 신규 수치는 테스트용이며 확정 밸런스가 아니다.

## 등급의 제안 역할

| 등급 | 역할 |
|---|---|
| 낡은 주문서 | 기초 효과, 낮은 문양 부담, 안정적인 반복 사용 |
| 각인 주문서 | 완성된 특화 문양, 연계·조건부 보너스 또는 향상된 효율 |
| 봉인 주문서 | 강력하거나 복합적인 효과, 긴 문양·두 획·사용 제한 등의 부담 |
| 금서 | 규칙에 개입하는 효과와 명시적인 대가. 이번 범위에서는 5층 보상 1종 |

봉인 주문서라는 등급이 획득 후 추가 해제를 요구한다는 뜻은 아니다. 이번 제안에서는 선택하면 즉시 사용 가능하다. 봉인 해제 주문의 이름 및 전투 중 카드 봉인 상태와도 구분한다.

## 10층 — 고정 기본 습득

### 01. 잔광 말소 — 기존

- 획수 / 권장 마나: 1획 / 30
- 획득: 10층 첫 공격 학습 완료 시 자동 등록. 선택 두루마리 아님.
- 효과: 피해 18~25.
- 특징: 짧고 허용 오차가 넓은 기본 공격. 해제·방어·디버프 뒤에 연결하기 쉽다.

- 카테고리 / 등급: 공격 / 낡은 주문서
- 획수 / 권장 마나: 1획 / 42
- 획득: 10층 후속 공격 학습 완료 시 자동 등록. 선택 두루마리 아님.
- 효과: 피해 28~40.
- 특징: 잔광 말소보다 길고 정밀하지만 높은 피해. 획수가 같아도 문양 부담으로 구분한다.

## 9층 — 관리자 처치 후 세 두루마리 중 하나 선택

### 03. 방벽 관통 — 기존
- 카테고리 / 등급: 공격 / 각인 주문서
- 획수 / 권장 마나: 2획 / 75
- 획득: 9층 관리자 보상 선택 두루마리.
- 효과: 일반 방어막을 무시하여 HP에 피해 34~48을 준 뒤 해당 일반 방어막을 소멸시킨다.
- 제약: 절대 방어막에 막힌다. 한 턴의 두 획을 전부 사용한다.

### 04. 연쇄 각인 — 신규
- 카테고리 / 등급: 공격 / 낡은 주문서
- 획수 / 권장 마나: 1획 / 36
- 획득: 9층 관리자 보상 선택 두루마리.
- 효과: 피해 14~20. 이번 턴의 다음 성공 공격 주문 피해 +12, 1회.
- 제약: 공격 강화는 중첩하지 않으며 턴 종료 시 소멸한다. 실패 공격은 강화를 소비하지 않는다. 같은 주문을 재사용하면 기존 강화를 먼저 소비하고 새 강화를 등록한다.
- 특징: 단독 피해는 낮지만 다른 1획 공격과 연계한다. 낮은 등급도 별도의 전술적 역할을 가진다.

### 05. 응축 방벽 — 신규
- 카테고리 / 등급: 방어 / 각인 주문서
- 획수 / 권장 마나: 1획 / 48
- 획득: 9층 관리자 보상 선택 두루마리. 선택 즉시 사용 가능.
- 효과: 방어막 28~36 생성. 누적 최대 40.
- 제약: 초급 방벽보다 문양이 길어 같은 턴 후속 주문의 마나 여유가 줄어든다.
- 특징: 8층 이전에 방어를 먼저 선택하는 경로. 8층의 초급 방벽 고정 학습은 그대로 진행하고 두 주문을 함께 보유한다.

## 8층 — 고정 습득 두 종과 관리자 선택 보상

### 06. 초급 방벽 — 기존 / 고정
- 카테고리 / 등급: 방어 / 낡은 주문서
- 획수 / 권장 마나: 1획 / 32
- 획득: 8층 보호 절차 학습 완료 시 자동 등록. 선택 두루마리 아님.
- 효과: 방어막 20~30 생성. 누적 최대 40.
- 특징: 기본 방어 수단. 응축 방벽을 선택했어도 적은 선 길이라는 장점이 남는다.

### 07. 봉인 해제 — 기존 / 고정
- 카테고리 / 등급: 해제 / 낡은 주문서
- 획수 / 권장 마나: 1획 / 28
- 획득: 8층 잔류체 처치 후 기존 해독·학습 절차로 자동 등록. 세 후보 중 고르는 보상은 아님.
- 효과: 시전 판정에 따라 절대 방어막 1~2회 제거.
- 탐색 용도: 7·6·5층의 잔류체 방에서 보스방으로 넘어갈 때 같은 문양을 재사용한다.
- 제약: 일반 버프·개인 약화·예약 피해를 모두 지우는 만능 해제 주문으로 확장하지 않는다.

다음 08~10 중 하나를 8층 관리자 처치 후 선택한다.

### 08. 정화 각인 — 신규
- 카테고리 / 등급: 해제 / 각인 주문서
- 획수 / 권장 마나: 1획 / 32
- 획득: 8층 관리자 보상 선택 두루마리.
- 효과: 자신에게 걸린 해제 가능한 약화·카드 봉인 1개, 또는 적에게 걸린 해제 가능한 버프 1개를 선택하여 제거한다. 한 번에 하나만 제거한다.
- 예시: 6층 인과 증폭, 5층 모사 기록을 제거할 수 있다. 이미 생성된 예약 피해는 제거하지 못한다.
- 제약: 일반 방어막·절대 방어막·보스 단계 전환은 대상이 아니다. 앞선 제안의 일반 방어막 18 제거 기능은 삭제한다.
- 보충: 대상이 없는 경우 선택 불가. 정화 각인 자체가 카드 봉인 상태면 사용할 수 없다. 기본 공격·방어는 봉인하지 않으므로 정화 부재가 진행 불능을 만들지 않게 한다.

### 09. 잔류 방벽 — 신규
- 카테고리 / 등급: 방어 / 각인 주문서
- 획수 / 권장 마나: 1획 / 38
- 획득: 8층 관리자 보상 선택 두루마리.
- 효과: 즉시 방어막 14~20을 얻고 다음 플레이어 턴 시작에 방어막 10 추가. 누적 최대 40.
- 제약: 예약된 추가 방어막은 1건만 유지한다. 반복 사용 시 즉시 방어막은 더하지만 예약 추가분은 중첩하지 않는다. 전투 종료 시 예약도 소멸한다.
- 특징: 여러 턴을 보고 방어를 분산하는 주문.

### 10. 집속 파열 — 신규
- 카테고리 / 등급: 공격 / 봉인 주문서
- 획수 / 권장 마나: 2획 / 85
- 획득: 8층 관리자 보상 선택 두루마리.
- 효과: 피해 62~82.
- 제약: 일반 방어막을 관통하지 않으며 절대 방어막에 막힌다. 높은 선 길이와 두 획을 소비해 같은 턴 다른 대응이 어렵다.

## 7층 — 관리자 처치 후 세 두루마리 중 하나 선택

### 11. 축선 절단 — 신규
- 카테고리 / 등급: 공격 / 각인 주문서
- 획수 / 권장 마나: 1획 / 46
- 획득: 7층 관리자 보상 선택 두루마리. 잔류체에서는 얻지 않는다.
- 효과: 피해 28~40. 시전 효과 적용 시 적이 일반 방어막 또는 해제 가능한 버프를 보유했다면 피해 +12를 더한 뒤 일반 피해 순서로 처리한다.
- 제약: 일반 방어막을 먼저 깎고 초과분이 HP에 들어간다. 절대 방어막에는 무효. 조건이 여럿이어도 추가 피해는 한 번만 적용한다. 버프 자체를 제거하지 않는다.
- 역할: 강화 상태의 적을 공격적으로 공략하는 1획 주문. 6층 인과 증폭이나 5층 모사 기록에도 보너스를 얻으므로 후속 보스에게 방어막을 억지로 넣을 필요가 없다. 증폭을 지우기 전에 공격할지, 즉시 정화할지 선택하게 한다.

### 12. 기준점 수호 — 신규
- 카테고리 / 등급: 방어 / 봉인 주문서
- 획수 / 권장 마나: 1획 / 42
- 획득: 7층 관리자 보상 선택 두루마리.
- 효과: 방어막 18~26 생성 + 이번 적 행동 단계의 다음 피해 1건에서 6 감소.
- 제약: 고정 감소는 한 번만 적용하고 중첩하지 않는다. 해당 적 행동 단계에 피해가 없으면 감소 효과는 사라진다.
- 특징: 한 번의 강한 공격에 특화. 방어막만 제공하는 초급 방벽과 구별한다.

### 13. 결과 말소 — 신규
- 카테고리 / 등급: 해제 / 봉인 주문서
- 획수 / 권장 마나: 2획 / 58
- 획득: 7층 관리자 보상 선택 두루마리.
- 효과: 이미 등록된 예약 피해 1건 취소, 또는 적 일반 방어막 1개 소멸 중 선택.
- 제약: 둘을 동시에 지우지 않는다. 절대 방어막·예약 전 인과 증폭·아직 등록되지 않은 미래 공격·단계 전환은 취소하지 못한다.
- 특징: 정화 각인은 예약 전 버프를, 결과 말소는 이미 등록된 피해를 처리한다. 취소 후 빈 행동에 다른 공격을 대체하지 않는다.

## 6층 — 첫 디버프 고정 습득과 관리자 선택 보상

### 14. 출력 저하 — 신규 / 고정
- 카테고리 / 등급: 디버프 / 낡은 주문서
- 획수 / 권장 마나: 1획 / 30
- 획득: 6층 초입 학습용 두루마리 1개를 고정 제공. 짧은 시험 각인 완료 후 자동 등록. 세 후보 선택 아님.
- 효과: 적이 다음에 가하는 피해 1건을 25% 감소시킨다.
- 지속: 이번 적 행동 단계부터 2회의 적 행동 단계 안에 발동하지 않으면 소멸. 중첩 없이 갱신.
- 제약: 첫 작은 공격에 소모되면 이후 강공격에는 적용되지 않는다. 이미 걸린 인과 증폭 자체를 지우지 않으며 피해에 감소를 적용한다.
- 특징: 7~5층 구간에서 보스 보상 외에 새로 추가하는 유일한 주문 습득이다.

다음 15~17 중 하나를 6층 관리자 처치 후 선택한다.

### 15. 집행 지연 — 신규
- 카테고리 / 등급: 디버프 / 봉인 주문서
- 획수 / 권장 마나: 1획 / 42
- 획득: 6층 관리자 보상 선택 두루마리.
- 효과: 선택한 적 예약 피해 1건의 집행을 1턴 미룬다.
- 제약: 같은 예약은 한 번만 지연 가능. 피해를 없애거나 줄이지 않는다. 일반 즉시 공격·단계 전환은 지연 불가.
- 보충: 다른 예약과 같은 턴에 겹칠 수 있으며 변경된 목록을 선택 전에 보여준다. 5층의 예약 강공격에도 사용 가능하다.

### 16. 선행 판결 — 신규
- 카테고리 / 등급: 공격 / 각인 주문서
- 획수 / 권장 마나: 1획 / 48
- 획득: 6층 관리자 보상 선택 두루마리.
- 효과: 피해 26~36. 이번 적 행동 단계에 도착할 예약 피해가 남아 있으면 피해 +12.
- 제약: 시전 시 조건을 판단한다. 앞선 시전으로 예약을 말소하거나 다음 턴으로 지연했다면 보너스가 없다.
- 특징: 위험이 닥치는 턴에 공격하는 보상. 5층 예약 강공격에도 대응한다.

### 17. 인과 완충 — 신규
- 카테고리 / 등급: 방어 / 봉인 주문서
- 획수 / 권장 마나: 1획 / 40
- 획득: 6층 관리자 보상 선택 두루마리.
- 효과: 방어막 16~24 생성 + 이번 적 행동 단계의 첫 예약 피해 1건을 30% 감소.
- 제약: 일반 즉시 공격에는 추가 감소가 없다. 감소 효과는 중첩하지 않고 해당 적 행동 단계가 끝나면 소멸한다. 방어막은 통상 규칙대로 남는다.

## 5층 — 관리자 처치 후 세 두루마리 중 하나 선택

### 18. 기억 절단 — 신규
- 카테고리 / 등급: 공격 / 각인 주문서
- 획수 / 권장 마나: 1획 / 44
- 획득: 5층 관리자 보상 선택 두루마리.
- 효과: 피해 28~38. 이번 전투의 직전 성공 주문이 자신과 다르면 피해 +10.
- 제약: 전투 첫 성공 주문에는 보너스가 없다. 직전 성공 주문에는 공격·방어·해제·디버프가 모두 포함된다. 같은 턴에도 연계 가능하며 실패는 기록을 갱신하지 않는다.

### 19. 기억 봉합 — 신규
- 카테고리 / 등급: 방어 / 봉인 주문서
- 획수 / 권장 마나: 1획 / 50
- 획득: 5층 관리자 보상 선택 두루마리.
- 효과: HP 8 회복 + 방어막 12~18 생성.
- 제약: 전투당 성공 사용 2회. 실패는 제한 횟수를 소비하지 않는다. HP·방어막 최대치를 넘지 않는다. 전투 종료 후 사용 횟수 초기화.
- 특징: 회복은 방어 카테고리에 포함하며 별도 보조 카테고리는 만들지 않는다.

### 20. 모사 금지 — 신규
- 카테고리 / 등급: 디버프 / 금서
- 획수 / 권장 마나: 1획 / 38
- 획득: 5층 관리자 보상 선택 두루마리. 이번 범위의 첫 금서 후보.
- 효과: 적의 현재 모사 기록·반격 준비처럼 반응형으로 지정된 준비 효과를 제거하고, 이번을 포함한 적 행동 단계 2회 동안 모사·반격 발동을 차단한다.
- 대가: 성공 시 자신의 HP 6 소모. 방어막과 피해 감소로 막을 수 없으며 HP가 6 이하라면 선택 불가. 실패 시 HP 대가는 없지만 사용한 선과 획은 소비한다.
- 제한: 일반 공격·예약 피해·카드 봉인·단계 전환은 막지 않는다. 중첩 없음. 재사용 시 대가를 다시 지불하고 지속 시간만 갱신한다. 절대 방어막이 있으면 먼저 해제해야 한다.
- 분류: 주효과가 이후 반응을 금지하는 지속 제약이므로 디버프다. 모든 적 버프를 정화하는 주문은 아니다.
- 후속 조건: 4층 이후에도 모사·반격 적이 등장해야 선택 가치가 유지된다. 수치와 HP 대가는 특히 테스트가 필요한 제안이다.

## 수량과 획득 요약

| 항목 | 수 |
|---|---:|
| 고유 주문 전체 | 20 |
| 기존 주문 | 5 |
| 신규 주문 | 15 |
| 고정 자동 등록 주문 | 5 |

| 한 진행에서 얻는 보스 선택 주문 | 5 |
| 한 진행 최종 보유 주문 | 10 |
| 낡은 / 각인 / 봉인 / 금서 | 6 / 7 / 6 / 1 |
| 공격 / 방어 / 해제 / 디버프 | 8 / 6 / 3 / 3 |

2획 주문은 방벽 관통·집속 파열·결과 말소 세 종이다. 7~5층 잔류체는 주문서를 떨어뜨리지 않는다. 하강 승인 문양 6개는 주문서 20종에 포함하지 않는다.

5층 보상은 보스 처치 후 얻으므로 해당 5층 보스의 최초 공략 수단으로 계산하지 않는다. 이번 확장 종료 후 시험 각인은 가능하게 하고, 4층 이후 실전 활용은 후속 기획에서 검증한다.

## 남은 조정 항목

- 등급이 다른 후보도 역할·부담이 달라 실제 선택이 성립하는지 확인한다. 금서가 무조건 정답이 되어서는 안 된다.
- 6·5층에 일반 방어막을 억지로 추가하지 않는다. 축선 절단의 추가 피해 조건에 버프 보유를 포함하는 수정으로 후속 층의 선택 가치를 확보한다.
- 기본 주문의 기존 문서 고정값과 실제 코드의 판정별 범위를 통일할 필요가 있다. 여기의 기존 주문 수치는 현재 코드에 기록된 범위를 기준으로 한다.
- 신규 문양의 좌표·허용 오차와 등급별 시각 표현은 별도로 설계한다. 이 문서만으로 최종 밸런스가 확정된 것은 아니다.
